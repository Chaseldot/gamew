# Art Assets Index

用途：按章节整理现有美术资源，并锁定章节地图、章节主视觉、地点概念图、场景图和战斗图的归档口径。

## 命名规则

文件名使用：

`章节-资源类型-地点或画面说明.扩展名`

资源类型固定为：

| 类型 | 用途 |
|---|---|
| 章节地图 | 每章大区总览图。 |
| 章节主视觉 | 每章情绪、色调和核心冲突的主视觉。 |
| 地点概念 | 地图上地点的概念图。 |
| 场景 | 地点内可发生戏的具体画面。 |
| 战斗 | encounter 或冲突画面。 |
| 任务图 / 副本 / 终局 | 任务、地下空间、终局节点或强剧情图。 |
| 旧设参考 | 不再严格对应 ground truth 地点，但仍可作为风格或构图参考。 |

## 地点概念图口径

`02-地点概念图` 只放严格对应 `canon/03-map-design.md` 的地点级概念图。旧有地点概念图已经按具体画面迁入 `03-场景图`，不再占用地点概念图位。

地点概念图统一要求：

| 项 | 要求 |
|---|---|
| 尺寸 | 3840x2160。 |
| 画幅 | 4K landscape / 16:9。 |
| 质量 | high quality。 |
| 风格参考 | 每章 `01-章节主视觉`。 |
| 命名 | `章节-地点概念-地点名.png`。 |

本轮地点概念图已使用 `imagegen` 内置工具补齐，生成结果已复制到各章 `02-地点概念图`。源图由工具保留在 `$CODEX_HOME/generated_images/...`，项目内资产统一为 3840x2160 PNG。

可选重生成脚本：

```bash
uv run assets/generate_location_concepts.py
```

脚本会读取 `OPENAI_API_KEY`，使用每章主视觉作为参考图，并只生成缺失文件；需要走 CLI/API 重生成时加 `--overwrite`。
