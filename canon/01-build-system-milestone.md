# 01 Build System Milestone

状态：milestone
日期：2026-04-25
用途：记录当前已经拍板的等级系统、流派、传承和旁修结论。本文是 active ground truth；`history/` 中的历史方案不再自动生效。

## 1. 设计方法

| 项 | 已确定 |
|---|---|
| 系统参照 | 参考 D&D / BG3 的成熟职业、子职业和 multiclass 结构。 |
| 流派定位 | 流派是能力领域，不是具体职业。 |
| 传承定位 | 传承是流派内部的成熟玩法底盘，不硬性凑数量。目前仍在开发中，不作为现有设定 WIP |
| 旁修定位 | 旁修是低阶接入，不获得另一套完整主身份。 |
| 命名原则 | 先定玩法底盘，再做武侠化命名。 |
| 幻想资源 | 武侠幻想库用于压测构筑表达，不直接等同于传承。 |

## 2. 八大流派

八大流派固定，不改名。八个流派代表八个能力方向
游锋应变于招，破军承压于线，拳掌制衡于身，射艺制距于远，影踪通隐于见，药师调命于伤病，音律调心于节奏，奇门改局于场域。

| 流派 | 要素 | 代表能力 |
|---|---|---|
| 游锋 | 近身兵刃、读招、游斗 | 应变、招式与反制 |
| 破军 | 阵线、冲阵、护卫、重压 | 承压、阵线与推进 |
| 拳掌 | 贴身制身、擒拿、身体破绽 | 控制、身体与行动 |
| 射艺 | 投射、射线、标记、追击 | 制距、距离与射线 |
| 影踪 | 藏形、潜入、暗袭、脱战 | 通隐、视线与敏捷 |
| 药师 | 医毒、药性、救急、侵蚀 | 药性、伤病与调命 |
| 音律 | 节奏、鼓舞、稳心、扰拍 | 控场、节奏与意志 |
| 奇门 | 布局、阵法、机关、符禁 | 创意、场域与规则 |

## 3. 九级构筑规则

| 项 | 已确定 |
|---|---|
| 等级上限 | 9 级 |
| 主修锁定 | 1-3 级必须投入主修 |
| 传承选择 | 主修 3 级选择传承 |
| 自由修习 | 4-9 级可继续主修，也可旁修 |
| 满级主修下限 | 主修不得低于 6 |
| 旁修数量 | 最多旁修 2 个流派 |
| 单旁修上限 | 单个旁修最高 3 级 |
| 旁修限制 | 不获得流派高级技、传承高级技或传承身份 |

主修成长：

| 主修等级 | 获得内容 |
|---:|---|
| 1 | 基础技能包 + 流派初级技 |
| 2 | 流派中级技 |
| 3 | 选择传承，获得传承初级技 |
| 4 / 5 | 中级技 / 属性 / 被动提升 |
| 6 | 流派终局 |
| 7 / 8 | 中级技 / 属性 / 被动提升 |
| 9 | 传承终局，获得 1 个传承高级技 |

旁修成长：

| 旁修等级 | 称号 | 获得内容 |
|---|---|---|
| 1 | 入门 | 获得该流派基础技能包 + 流派初级技池 |
| 2 | 大成 | 流派初级 / 中级技池 |
| 3 | 通达 | 流派初级 / 中级技池 |

## 5. 当前不处理

以下内容不进入当前 milestone，不得用来证明传承成立：

| 不处理内容 | 说明 |
|---|---|
| loadout / 装备矩阵 | 不定义携带技能数、装备槽、武器矩阵或最终装配限制。 |
| 具体数值技能 | 不写伤害、冷却、命中率、持续回合等数值。 |
| 完整状态系统 | 不细化所有状态、豁免、叠层和行动经济。 |
| 出身 / 身份系统 | 不用身份、门派权限或社会地位解决战斗系统问题。 |
| 剧情章节 / 势力系统 | 本文只定构筑系统骨架；政治阵营 ground truth 见 `04-political-faction-restructure.md`。 |
