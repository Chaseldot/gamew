# 03 Map Design

状态：ground truth
日期：2026-04-26
用途：定义《山水照影录》三章地图的大区、地点清单和地点气质。旧剧情蓝本、章节细稿、网站内容和 `history/` 中的历史方案与本文冲突时，以本文为准。

## 1. Scope

本文只锁定地图层级中的大区和地点。

本文处理：

- 三章各自使用哪个大区；
- 每个大区包含哪些可写在地图上的地点；
- 每个地点的一句气质描述；
- 地点命名的标准口径。

本文不处理：

- 地点内的细分空间；
- 单个任务剧本、对白、场景卡；
- 具体战斗 encounter、检定 DC 或数值；
- 网站页面、图片生成或美术资产名；
- 政治阵营结构，相关 ground truth 见 `04-political-faction-restructure.md`；
- 主线任务骨架，相关 ground truth 见 `05-mainline-quest-skeleton.md`。

## 2. 地图命名规则

- 只使用三层信息：大区、地点、简短描述。
- 大区是章节级空间，例如 `山水县境`、`槐安古道`、`照影城`。
- 地点是地图上可标注的点，例如 `清河渡`、`龙门驿`、`武籍区`。
- 简短描述只写地点气质和叙事压力，不扩写成任务、细分空间或玩法标签。
- 第二章大区标准名为 `槐安古道`，不得用 `黄沙古道` 作为主名。

## 6. Consistency Checks

- 三章大区必须保持 `山水县境 -> 槐安古道 -> 照影城` 的递进。
- 地点表不得反向改写主线章节功能；主线骨架以 `05-mainline-quest-skeleton.md` 为准。
- 地点描述可以提供气质，但不得替代任务设计。
- 后续新增地点必须先说明它属于哪个大区，以及是否会挤压现有地点的章节职责。
