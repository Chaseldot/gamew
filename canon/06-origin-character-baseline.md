# 06 Origin Character Baseline

状态：ground truth
日期：2026-04-26
用途：定义《山水照影录》的自定义主角、无名煞、普通起源、非起源队友和关键 NPC 的设计顺序与筛选基线。旧剧情蓝本、章节细稿、网站内容和 `history/` 中的历史方案与本文冲突时，以本文为准。

## 1. 核心结论

《山水照影录》采用 BG3-like 的主角结构作为生产参考，但不搬运具体人物、任务或桥段。结构分为：

| 类型 | 定义 | 设计功能 |
|---|---|---|
| Tav / 自定义主角 | 默认完整主角，不设固定旧债、固定门派身世或专属个人线。 | 作为所有主线、任务、阵营和结局的基线测试角色。 |
| 无名煞 | Dark Urge 式独立特殊起源，不是普通队友。 | 提供顺煞、压煞、引煞、抵抗、恐惧和断因房后果。 |
| 普通起源 | 从角色池筛选出的作者视角；可被玩家占用，也可在未选择时作为队友或外部角色存在。 | 提供固定人物的内视、旧债、个人任务和终局立场。 |
| 非起源队友 | 可入队、可参与战斗和营地戏，但不适合被玩家占用为主角。 | 保留队伍互动、任务解法和人物线，不破坏主线外部支点。 |
| 关键 NPC / 盟友 | 承担阵营锚点、审判压力、导师、反派或地区代表功能。 | 保持世界和阵营对玩家的外部压力，不强行转为起源。 |

核心规则：

- Tav 是默认主角，不是缺内容版本。
- 无名煞是特殊规则层，不是“真正主角”。
- 普通起源不是重要角色的同义词，必须通过筛选。
- 非起源队友和关键 NPC 同样重要，不应因为不能当主角而被降级。

## 2. Tav / 自定义主角基线

Tav 是所有任务设计的默认基线。玩家不选择任何普通起源或无名煞时，仍必须完整体验三章主线：

> 求生解除牒针 -> 争夺真相解释权 -> 裁决母局制度。

Tav 只锁定以下开场事实：

- 体内有照影牒针；
- 暂时无法安全拔除；
- 必须查清真相并活着离开山水县；
- 可以通过构筑、队友关系、阵营选择、证据归属和结局立场形成个人故事。

Tav 不锁定以下内容：

- 固定门派出身；
- 固定旧债；
- 隐藏身世谜底；
- 专属个人任务链；
- 必须选择的政治立场。

Tav 基线检查表：

- 不选任何普通起源，只用 Tav，任务是否仍然成立？
- Tav 是否至少有武力、系统、社交或阵营中的多类解法？
- 关键真相是否不依赖某个起源才能发现？
- 队友是否能给 Tav 提供不同视角，而不是替 Tav 做主角？
- Tav 是否能获得足够证据进入第二章和第三章？
- Tav 是否能在终局对母局作出完整裁决？
- 起源专属内容是否只是增量视角，而不是主线必需钥匙？

## 3. 无名煞设计顺序

无名煞应放在 Tav 基线之后、普通起源筛选之前设计。

原因：

- 不能早于 Tav。否则主线容易被写成“真正主角其实是无名煞”，削弱自定义主角体验。
- 不能晚于普通起源。无名煞会改变任务模板、失败推进、队友恐惧、断因房接触和终局诱导，必须先成为所有任务设计都能识别的特殊规则层。
- 它不是普通队友，也不是普通起源。它回答的问题是：如果体内已经有一套杀戮判断系统，玩家是否仍然自由。

无名煞基线只先锁规则，不急于写完整剧情：

- 顺煞：接受杀意，以最快方式消除证人、风险或未来祸端。
- 压煞：抵抗杀意，保留证据、人命或公开审判可能。
- 引煞：利用杀意反查断因房、照影局旧令或隐藏敌人。
- 后果：记录杀戮、抵抗、队友恐惧、断因房接触和终局诱导。

无名煞不能只是坏人按钮。每次触发都应同时提供诱惑、抵抗、利用和后果。

## 4. 普通起源筛选规则

普通起源从角色池中筛选，不默认旧八人全上。

筛选时依次判断：

| 标准 | 问题 |
|---|---|
| Tav 基线 | 不选该角色时，主线是否仍完整？ |
| 主角内视价值 | 玩家扮演他，是否显著改变任务理解？ |
| 外部角色价值 | 他作为队友、NPC 或阵营锚点是否更有价值？ |
| 占用代价 | 选中他后，失去一个队友版本是否可承受？ |
| 个人线转写 | 他的队友任务能否自然改成主角个人线？ |
| 统一开场 | 他是否能合理从山水县牒针危机进入主线？ |
| 终局答案 | 他对母局裁决是否有独特立场？ |

普通起源规则：

- 普通起源统一从山水县牒针危机开场。
- 普通起源有默认 canon 主修、传承和武侠幻想，但玩法允许玩家重修；剧情仍按身份能力识别。
- 起源被玩家选择后，不再作为队友重复出现。
- 起源内容只提供增量内视、个人压力、专属入口、营地回收和终局立场，不承担主线必需钥匙。
- 如果某个角色作为外部 NPC / 队友比作为玩家主角更有价值，应保留为非起源。

## 5. 设计顺序

主角与起源设计必须按以下顺序推进：

1. 确认 Tav 基线大纲。
2. 定义无名煞特殊规则层。
3. 盘点角色池并分档。
4. 筛选普通起源。
5. 深化普通起源任务、队友任务和支线任务。

不得跳过 Tav 基线直接锁定普通起源名单。不得因为某角色重要，就自动把他列为起源。

## 6. 旧八人初筛基线

旧稿中的八名角色只作为初筛对象，不自动成为起源。

| 角色 | 初步处理方向 | 说明 |
|---|---|---|
| 谢停云 | 强起源候选 | 旧错、封剑、是否再拔剑适合玩家内视；山水县酒楼可自然接入第一章。 |
| 桑芷 | 强起源候选 | 牒针药引、救人和控制边界高度贴合主线；若选她，需要另有医脉 NPC 承担外部诊断功能。 |
| 唐小砚 | 强起源候选 | 机关责任、百工坞和母局硬件适合主角线；需要补足统一开场理由。 |
| 任无踪 | 强起源候选 | 牒钥、鬼市、潜入和身份交易适合重玩；需要避免提前掌握过多关键筹码。 |
| 柳听弦 | 强起源候选 | 复仇曲被铃阵利用，适合形成复仇与护心之间的主角内视。 |
| 韩霜铁 | 边界候选 | 护送旧案很强，但更像外部守护者；是否适合起源需继续评估。 |
| 裴照 | 倾向关键 NPC / 非起源队友 | 他承载缉武司公开律法路线和外部法理压力，玩家占用后可能削弱阵营锚点。 |
| 霍青鸢 | 倾向非起源队友 / 第二章关键角色 | 核心价值在槐安古道和边地政治；除非重写第一章入口，否则不适合统一开场起源。 |

该名单是初筛基线，不是最终锁定名单。后续可按 Tav 基线、无名煞规则层和角色池分档继续调整。
