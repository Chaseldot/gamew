# Character Production

本目录是 GameW 的角色生产一级工作区。

它用于维护可复用的人物幻想、构筑测试、NPC / 队友 / 敌人概念，以及后续人物资产生产所需的角色设计材料。

## Active Files

| 文件 | 用途 |
|---|---|
| `wuxia-character-archetypes.md` | 武侠人物原型主表：当前人物原型与构筑的主要维护入口。 |
| `wuxia-fantasy-suite.md` | 旧幻想库来源表：高质量条目已筛选并入主表，后续仅作溯源参考。 |
| `wuxia-character-archetypes-100.md` | 旧补充来源表：高质量条目已筛选并入主表，后续仅作溯源参考。 |

## Boundary

- 游戏整体定调见根目录 `00-game-introduction.md`。
- 等级、流派、传承和旁修规则见 `canon/01-build-system-milestone.md`。
- 人物图片资产目前归档在 `assets/00-人物/`；其中官方人物设定版位于 `assets/00-人物/04-人物设定版/`，本目录负责角色设计源材料。
