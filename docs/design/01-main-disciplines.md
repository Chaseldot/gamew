# 01 Main Disciplines

状态：iteration-loop canon baseline（流派固定）
Owner：canon systems designer（current loop: worker-2）
Schema source：`docs/design/00-rule-bible.md`

> 按 5 字段主修模板填写；本文件只定八大主修本体，不重定义 schema，不偷渡 loadout / meridian 定数，也不把“武僧 / 琴魔 / 侠盗”等熟悉称谓反向提升为职业根节点。

## 游锋
- 基础职责一句话：以近身兵刃节奏、游斗换位与见招拆招为核心的贴身压迫主修。
- 主资源循环：**锋势** 来自贴步试锋、连续命中、借步避招与抓到敌方空门；消耗锋势可把优势转成追击、截击、显锋爆发或更高质量的连段收束。
- 三段式动作骨架：**起手**靠贴近、试探、换位与逼出破绽拿到第一层锋势；**推进**靠连斩、反击、断招与持续贴身把锋势滚高；**收束**把累积的锋势转成一轮高价值追击、断势反斩或显锋重斩，然后回到能继续压步的身位。
- 纯主修终局落点：纯游锋应能不借外部门类独立完成“贴近 → 滚势 → 收束 → 再贴”的完整兵刃闭环，并在终局获得“双层型”回报：一项代表性的宗师级显锋绝技，加上一套让高锋势与完整动作链更稳定成立的体系完成奖励。
- 旁修影响范围 / 主修核心保留区 / 非目标：旁修可影响贴近效率、短控接口、换位方式与出手时机；但**锋势经营、兵刃节奏博弈、近身追击与断招反制**必须保留为主修核心。游锋的非目标是：不吞掉破军的阵线控制，不吞掉影踪的潜入伏击，不被写成“所有近战都能归到游锋”的万能近战总类。

## 破军
- 基础职责一句话：以冲阵破围、改写阵线、拦截护线为核心的前压型主修。
- 主资源循环：**冲势** 来自向前推进、顶住来敌、打出击退/贯穿与成功守住关键线位；消耗冲势可把站位优势转成破阵突进、强制位移、护线反打或震场重压。
- 三段式动作骨架：**起手**靠起冲、立线、探枪或压步抢到阵面主动；**推进**靠穿位、横扫、拦截、反推与持续站线累积冲势；**收束**在敌阵失衡或试图越线时，以高冲势打出破围、震退、定线反击或重势压场，并重置下一轮阵面。
- 纯主修终局落点：纯破军应能在没有固定副修税的情况下独立成立“立线 / 破线 / 守线”三位一体的主循环，终局既有能一口气改写局部阵形的宗师级重招，也有让冲势在推进与护阵之间稳定切换的体系完成奖励。
- 旁修影响范围 / 主修核心保留区 / 非目标：旁修可影响起冲稳定性、近身惩罚、援护接口与局部聚敌手段；但**冲势滚动、阵线改写、拦截护线与强制位移**必须保留为主修核心。破军的非目标是：不沦为“更笨重的游锋”，不只剩数值肉坦或单挑爆发，不用高魔式范围震荡解决身份问题。

## 拳掌
- 基础职责一句话：以贴身拆招、经脉干预、身体控制与正面雄掌破势为核心的近身制压主修。
- 主资源循环：**经脉破绽** 来自精准命中、贴身试探、拆手入怀与持续读取对手身位 / 气路；消耗经脉破绽可把局部优势转成封招、锁拿、摔投、断劲或迟发内伤。
- 三段式动作骨架：**起手**靠近身试探、拨架、截手与点到即止的轻击摸出破绽；**推进**靠持续贴身、连点连拿与控制对手重心把破绽越攒越深；**收束**把破绽定向转成封穴、缴械、摔制、重掌或运劲反噬，再压着对手回到贴身节奏。
- 纯主修终局落点：纯拳掌应能不靠外部位移或副修控制税，独立完成“贴上去 → 读破绽 → 转成功能压制 / 重创”的闭环；终局既要有能把经脉理解推到极致的宗师技，也要有让贴身容错、破绽转化与动作链稳定性的体系完成奖励，并明确容纳“重掌破势、朴拙雄浑、正面压垮对手”的高阶掌路落点，让掌劲既正大如山又能压住敌势。
- 旁修影响范围 / 主修核心保留区 / 非目标：旁修可影响贴脸入口、命中修正、短时牵制与追身节拍；但**经脉破绽生成、贴身读招、封招 / 擒拿 / 摧心的转化权，以及正面重掌破势的终局表达**必须保留为主修核心。拳掌的非目标是：不成为万能近战控制合集，不靠玄幻化隔空封脉成立，不让旁修补完本该由拳掌自己完成的贴身起手与控制链，也不把雄浑掌路外包给破军。

## 射艺
- 基础职责一句话：以视野经营、距离压迫、投射触发与标记收束为核心的远距主修。
- 主资源循环：**准星** 来自稳定视线、屏息瞄准、移动中保持角度、命中反馈与目标标迹；消耗准星可把远程优势转成定点穿透、连射压头、追猎补射或关键环境触发。
- 三段式动作骨架：**起手**靠抢视野、找射线、挂标记与试射校准建立准星；**推进**靠持续换位、远距触发、连发压制或追踪补线维持准星质量；**收束**在对手暴露、失位或试图脱离时，用高价值定点射击、连珠压制或追猎揭示完成收束。
- 纯主修终局落点：纯射艺应能不绑影踪 / 奇门就独立成立完整的“看见 → 锁定 → 压制 / 点杀”循环，终局既有代表性的宗师级要害射术，也有让准星在视线经营、连射节奏与环境触发间稳定循环的体系完成奖励。
- 旁修影响范围 / 主修核心保留区 / 非目标：旁修可影响侦查入口、换位效率、短控铺垫与地形互动；但**准星经营、远距投射、视野压迫与标记收束**必须保留为主修核心。射艺的非目标是：不滑成站桩炮台，不滑成西幻射手 / 法术炮台，不把“投射 / 投掷 / 远程触发”偷换成纯数值远程输出。

## 影踪
- 基础职责一句话：以隐蔽接敌、伏击收割、脱战重开与错位压迫为核心的潜袭主修。
- 主资源循环：**藏机** 来自未暴露位移、背侧起手、借遮挡换位、成功脱战与伏击得手；消耗藏机可把隐蔽优势转成处决爆发、连续暗袭、伏点回收或再隐身窗口。
- 三段式动作骨架：**起手**靠切断视线、借烟借影、绕背接敌与锁定孤立目标建立藏机；**推进**靠侧袭、换位、短脱战、伏点触发与连续背侧命中把藏机滚动起来；**收束**以高价值伏杀、收网式暗袭或伏击连锁完成目标处理，并迅速回到新的藏形位置。
- 纯主修终局落点：纯影踪应能不借别家主修代打，就独立完成“藏形 → 接敌 → 收割 → 抽身 → 重开”的刺客闭环；终局既有体现影踪杀机的宗师级收割手段，也有让藏机、现身时机与再隐蔽节奏稳定衔接的体系完成奖励。
- 旁修影响范围 / 主修核心保留区 / 非目标：旁修可影响起手标记、烟毒 / 地形交互、追击窗口与脱离路线；但**藏机经营、视线切割、伏击时机与收割后重开**必须保留为主修核心。影踪的非目标是：不沦为纯工具人，不靠不可互动的超自然隐身成立，不把伏杀 / 暗袭 / 设伏写成同一条 burst 线换皮。

## 药师
- 基础职责一句话：以药、针、毒、蛊的双向运用来进行救治、调压与侵蚀的医武型主修。
- 主资源循环：**药性** 来自施药有效、生效中的治疗 / 解毒 / 施毒反馈、对症处理与药理回收；消耗药性可把准备好的药理储备转成急救、针路强干预、毒性爆发或持续调压。
- 三段式动作骨架：**起手**靠识症、下药、飞针试探或基础施毒建立药性方向；**推进**靠持续调理、针药联动、毒伤运营与状态管理把药性滚成可控储备；**收束**在关键窗口把药性转成救场、封络、爆毒或逆转式处理，再依结果回收药性进入下一轮判断。
- 纯主修终局落点：纯药师应能独立成立“诊断 → 调理 / 侵蚀 → 关键处置”的完整战斗循环，终局既有代表性宗师级医武手段，也有让药性在救人、制敌、针路与药方之间更稳定周转的体系完成奖励。
- 旁修影响范围 / 主修核心保留区 / 非目标：旁修可影响送药 / 送毒方式、贴近或退身节拍、安全施治空间与目标暴露；但**药性经营、医毒双向判断、针药转换与战中优先级决策**必须保留为主修核心。药师的非目标是：不成为万能奶妈，不无成本同时包揽顶级治疗 / 顶级控制 / 顶级持续伤害，不把药、针、毒、蛊写成纯法术效果。

## 音律
- 基础职责一句话：以节拍牵引、士气提振、心神扰动与群体节奏改写为核心的节奏型主修。
- 主资源循环：**节拍** 来自演奏中的行动呼应、命中反馈、队友跟拍、敌方错拍与持续维持曲势；即便没有队友即时跟拍，音律也能通过自身体位转换、压拍命中、逼出敌方失手与稳住自身呼吸来持续产拍。消耗节拍可把乐势转成冲锋压迫、稳态校正、扰心压制或战场节奏重组。
- 三段式动作骨架：**起手**靠立拍、定调、先声夺势或柔拍安神建立第一轮节拍，并立刻给自己或战场中心制造一个“必须回应的拍点”；**推进**靠持续演奏、跟拍共振、扰敌错拍与队形呼应把节拍滚成高点，单人时则靠压拍扰步、逼招与自稳续拍完成 2-4 回合的节奏价值；**收束**在关键拍点把节拍转成强拍压锋、清音稳场或魔音裂拍，并在余韵中重新抓回下一轮节奏。
- 纯主修终局落点：纯音律应能在单人和组队两种语境下都独立成立“起拍 → 共振 / 扰拍 → 强拍收束”的主循环；终局既有一项代表性的宗师级终曲，也有让节拍在压制、护持与扰心之间持续转场的体系完成奖励。其短遭遇价值必须清楚到：即使无人配合，音律也能用拍点压迫、错拍惩罚与自稳续行赢下回合交换。
- 旁修影响范围 / 主修核心保留区 / 非目标：旁修可影响贴身安全、节奏承接、压线窗口与异常管理接口；但**节拍生成、演奏维持、心神 / 士气作用、敌方可读的打断 / 断拍窗口与关键拍点转化**必须保留为主修核心。音律的非目标是：不只剩 buff 工具功能，不被写成法师吟唱系统，不只有组队时才成立，也不变成缺乏反制点的无解心控。

## 奇门
- 基础职责一句话：以阵法、机关、符禁与香术改写局部战场规则的布置型主修。
- 主资源循环：**阵机** 来自阵眼存续、器具部署、符印生效、敌我踏入关键位与成功触发连锁；首回合就可通过落下小阵、贴出短符或放置单件机关取得直接价值，而不是空过一拍等待完整 setup。消耗阵机可把已布条件转成局部封线、步位偏转、连锁触发或短时规则压制。
- 三段式动作骨架：**起手**靠落点、贴符、布小阵、设机关或香术引线建立第一批阵机，并立即迫使敌人面对“绕路、拆解、硬闯或吃触发”四选一；**推进**靠诱导敌我走位、持续触发、回收重布与局部联动把阵机做成稳定循环；**收束**在关键时机消耗阵机完成封步 / 封势 / 改线 / 连锁爆发，然后迁阵或回收残局准备下一轮经营。
- 纯主修终局落点：纯奇门应能不借高魔表现、不依赖具体 `LOADOUT_INTERFACE_PENDING` 数值，就独立成立“布置 → 诱发 → 规则偏转 → 回收重布”的闭环；终局既有体现奇门主权的宗师级局部改场手段，也有让阵机在阵法、机关、符禁之间稳定流转的体系完成奖励。其 2-4 回合收益必须可读：首拍布置拿位置价值，中段靠触发与迁阵滚起阵机，收束时才换来真正的局部改场。
- 旁修影响范围 / 主修核心保留区 / 非目标：旁修可影响诱敌方式、远端触发、局部站位利用与异常搭桥；但**阵机经营、布置判断、场域偏转、敌方可读的拆阵 / 绕阵 / 破器具窗口与器具 / 符印触发链**必须保留为主修核心。奇门的非目标是：不滑向西幻法师，不成为泛用解题器，不把阵法 / 机关 / 符禁写成三套换皮法术框架，也不做无解长 setup 控场。
