## 游锋
### 连锋
- 定位一句话：以连续贴身追击把锋势滚高的兵刃压制传承。
- 核心战斗幻想：刀光不断、步不停、人不离，一口气把对手逼进自己的连段节奏里。
- 核心循环：靠贴身换位、连续命中与追击窗口累积连锋层数，把锋势维持在高位后转成追加斩击或延长压制；一旦节奏中断，循环就会明显回落。
- 资源关系：锋势主要来自连续近战命中与不断链，花费方式偏向“续段”和“加段”，而不是一次性爆发清空。
- 代表动作 / 机制：贴身追锋、回身连斩、压步追击、连段不断时的额外收刀补斩。
- 边界定义：它不是爆发刺客，也不是靠格挡反伤吃饭的反制流；不会吞掉断势的断招定位，也不会走成影踪式潜入刺杀。
- 旁修影响面：旁修可提供更稳的贴近、位移或短控入口，让连段更容易续上；但连锋的成立前提始终是自身近战连续命中与锋势维持，不能靠旁修代打主循环。

### 断势
- 定位一句话：专门切断敌方节奏、把对手破绽反转成己方锋势的反制传承。
- 核心战斗幻想：你先动，我先看；哪怕只余一臂、只守残式，也能凭独臂残式、步法与一口不乱的剑理截断来招，把强敌整套攻势斩成两截。
- 核心循环：通过招架、闪避、侧移或故意露出半拍诱发敌人重手落空来制造断点，在断点上获得锋势并立刻打出截击、破架、打断式追斩，把对手重新压回失衡区；越是以少招应多招、以后发破先手，断势的价值越清楚。
- 资源关系：锋势更多从“对手出错”而非“我方连击”中获得，消耗则集中在断招、破势、反击窗口的精准爆发上。
- 代表动作 / 机制：截锋反斩、借步让招、残式换手、破架抢手、敌方重击落空后的断势追击。
- 边界定义：它不是纯防御龟缩，也不是守阵式护队拦截；断势的重点是斩断敌方动作链、以残招应变和破招为尊，而不是替队友吃线或长期站桩。
- 旁修影响面：旁修可帮它制造更稳定的失衡、减速或位移误差，好让断点更常出现；但真正的锋势收益仍必须来自看破与截断，不能把旁修控制直接写成主核。

### 藏锋
- 定位一句话：把锋势藏成潜压，等待最值钱的一次显锋斩决的伏势传承。
- 核心战斗幻想：不急着亮刀，不急着抢拍，像浪子剑客一样把锋芒敛进步法、眼神与持势里；等你自以为占尽上风时，才以最省的一剑见真章，真正把残招应变练成孤剑风骨。
- 核心循环：以拉扯、试探、佯退、藏手和短暂蓄势保存潜锋层，等到敌方露出路径、背身或回招空窗时一次性显锋爆发，再重新退回藏势节奏；招数越少、判断越准，藏锋的压迫感越强。
- 资源关系：锋势可以被“压住不花”，转化为潜伏的威慑与显锋倍率；资源节奏偏慢，但每次释放都更看重时机与位置价值。
- 代表动作 / 机制：藏锋步、佯退蓄势、敛手探路、出鞘斩、显锋后短时提高追击或破防权重。
- 边界定义：它不是影踪的潜行暗杀，也不是远离近战的消耗流；藏锋依然是正面兵刃博弈，只是把锋势管理从“连着打”改成“忍着不打”，走的是少招高判、见招定输赢的孤剑路线。
- 旁修影响面：旁修可补充试探、脱离或重新贴回的接口，也可提供一次更稳的显锋铺垫；但其主闭环不能依赖隐身、陷阱或 `LOADOUT_INTERFACE_PENDING` 才成立。

## 破军
### 冲阵
- 定位一句话：以正面穿透和阵线撕裂为核心的先锋突入传承。
- 核心战斗幻想：长兵起手、撞开人墙、一路把前排捅穿，把敌阵从“站着”打成“散开”。
- 核心循环：向前推进、突刺贯穿、击退破围都会积累冲势；当冲势上来后，连用破阵冲、贯线横扫与追击踏步，把原本整齐的敌线打出缺口。
- 资源关系：冲势主要奖励“向前打穿”的动作，越是成功推进、穿位、冲破阻挡，资源越充足；花费则偏向直线爆发和强制位移。
- 代表动作 / 机制：破阵突刺、撞锋前压、贯线横扫、冲破后追加踏阵一击。
- 边界定义：它不是守阵那种守点护线，也不是震岳那种慢拍重压；冲阵的身份是主动改写阵形，而非稳住阵形或靠单次重击定胜负。
- 旁修影响面：旁修可增加起冲稳定性、补充短控或给出更好的进场角度；但冲阵的成立仍要靠自身前压、贯穿与冲势滚动，不能把外部拉扯当成本体。

### 守阵
- 定位一句话：以拦截、顶线和阵地反打为核心的护阵传承。
- 核心战斗幻想：你若想冲过来，就得先撞上我；我不急着追人，但谁敢踏线，谁就会被顶回去。
- 核心循环：站住关键点位后，通过拦截、格住突入、替友截线与反推回位累积冲势，再把冲势转成守线横扫、强制止步或护阵反击，形成“守住—反推—再守住”的闭环。
- 资源关系：冲势更多从承压不退、成功拦截和稳定站位中获得，花费方式侧重区域压制、护友反打与强制停步。
- 代表动作 / 机制：截线架枪、反推横扫、护阵踏步、敌方闯线后的迎头震退。
- 边界定义：它不是纯挨打的坦克壳，也不会变成点穴式单体控场；守阵的核心是守住局面并把对方赶回去，而不是只靠肉度拖时间。
- 旁修影响面：旁修可补充更稳的控足、援护或贴线惩罚，但不能把守阵写成依赖治疗、召物或固定槽位配置才能站住的体系。

### 震岳
- 定位一句话：把冲势压成沉重一击与大范围失衡的重兵震场传承。
- 核心战斗幻想：每一步都像砸在地上，先逼人不敢近，再用一记重压把整片近身圈打得东倒西歪。
- 核心循环：靠重兵蓄压、硬顶小幅控制与稳定站位叠高冲势，等到敌人被逼近或阵形挤在一起时，打出震地式重击、横抡扫荡或压顶震退，再回到下一轮蓄压。
- 资源关系：冲势更偏向慢积累、高阈值、高回报；它不追求频繁小消耗，而追求把资源攒成一次决定战场呼吸的重击。
- 代表动作 / 机制：震岳下砸、横抡开圈、压顶破势、重击后附带的群体失衡或短暂畏退。
- 边界定义：它不是奇门式地形法术，也不是冲阵式高机动穿透；震岳仍是纯武学重势压人，只把破军的冲势推向“重压震场”这一端。
- 旁修影响面：旁修可让它更容易聚人、定人或补出一段短追击，但不能把震岳改写成依赖陷阱、机关或远程爆破的伪范围职业。

## 拳掌
### 点穴
- 定位一句话：以精准打穴把经脉破绽转成封招、迟滞与功能剥夺的精密控制传承。
- 核心战斗幻想：别人是把人打伤，你是把人“打坏”——封手、闭气、锁步，全靠一指一掌落在该落的位置。
- 核心循环：先以轻快近身连点制造局部破绽，再把破绽聚焦到特定穴位，触发封招、慢拍、失手或短时失衡，接着继续贴身寻找下一个穴位窗口。
- 资源关系：经脉破绽来自精准命中与连续试探，资源花费偏向“定向转化”——把散乱破绽收束成特定功能封锁。
- 代表动作 / 机制：封脉点、锁腕截手、闭息掌、穴位命中后触发的招式冷却或动作迟滞。
- 边界定义：它不是擒拿那种抓投位移，也不是摧心那种重掌内伤；点穴的强项是精确功能压制，而不是摔人或一掌定生死。
- 旁修影响面：旁修可提供更好的贴身、打断或命中修正，让点穴更容易找准窗口；但它的控制权重必须来自经脉破绽的精准转化，不能直接借旁修替代封穴本体。

### 擒拿
- 定位一句话：以锁肢、拿身、反关节与摔投换位为核心的近身制服传承。
- 核心战斗幻想：一旦被你贴上，对手就不再是在“打架”，而是在拼命挣脱你的手、肘、肩和身位控制。
- 核心循环：靠近身试探、拆招入怀和连续控手累积经脉破绽，随后把破绽转成锁拿、缴械、拖拽或摔投，让敌人在位置与姿态上持续吃亏。
- 资源关系：经脉破绽既代表身体被摸透，也代表关节与重心被你拿住；资源消耗偏向位移控制、肢体锁定和缴械收益。
- 代表动作 / 机制：拿腕反关、擒身拖步、别臂摔、贴身缴械、锁住后追加寸打。
- 边界定义：它不是纯数值肉搏，也不会像守阵一样站线护友；擒拿的身份是“把人拿住并挪走”，不是硬吃伤害或做广域控制。
- 旁修影响面：旁修可补冲脸入口、短暂定身或地形互动，让擒拿更容易抓到第一下；但一旦进入主循环，控制深度仍必须由自身锁拿与摔投链完成。

### 摧心
- 定位一句话：把经脉破绽压进体内，转成正面重掌破势与迟发气机崩坏并存的重掌传承。
- 核心战斗幻想：掌力既可雄浑正大、当场震退强敌，也可在你回气、转身、再出招时让深层掌劲一层层翻上来；它不是阴狠偷伤，而是把厚重掌路练到能里外同伤。
- 核心循环：先用沉掌、震击和贴身重手打出深层破绽，再把这些破绽灌成掌劲印记；在正面硬撼时可立刻转成破架、震退与压步重掌，在敌方继续运劲、试图反打或撤离时又能引爆余劲造成断劲、重创或大幅失衡。
- 资源关系：经脉破绽更偏向“深度”而非“数量”，攒够后才能打出真正的摧心效果；资源消费集中在迟发爆发与运劲惩罚。
- 代表动作 / 机制：透劲沉掌、破势重掌、摧心印、回气反噬、敌方强行动作触发的二段内伤。
- 边界定义：它不是药师的毒伤，也不是奇门的咒禁；摧心仍是拳掌近身打进去的武学结果，既能以雄浑掌力当场压垮敌势，也能把杀伤落点留在体内回响，而不是只会阴狠迟发伤人。
- 旁修影响面：旁修可帮它更稳贴近、拖慢敌人回气或补一次追身，但不能把持续伤害、标记叠层或远程引爆写成主闭环来源。

## 射艺
### 穿杨
- 定位一句话：把准星推到极致，以单发定点破防与要害打击为核心的精射传承。
- 核心战斗幻想：屏息、看风、定线，一箭一镖都像裁好的刀口，只在最值得出手的那一瞬离弦。
- 核心循环：通过拉开距离、稳定视野、持续瞄准与目标标记积累高质量准星，随后用穿透性强的定点射击击穿护具、打断关键动作或直接点掉核心目标。
- 资源关系：准星越稳定、越专注，单次消耗价值越高；它更偏向“攒满打一发准的”，而不是频繁散射。
- 代表动作 / 机制：定线瞄准、破甲穿杨、要害标记、屏息后提高暴露惩罚或穿透权重。
- 边界定义：它不是连珠那种持续泼射，也不是猎踪那种追迹控场；穿杨的身份是高价值单点处决，不是范围压制或长期追猎。
- 旁修影响面：旁修可补侦查、短控或更好的视线经营，让高质量出手更稳定；但穿杨的强度核心仍来自准星经营与定点释放，而非旁修先把人控死。

### 连珠
- 定位一句话：以高速连射、压头封位与节奏型准星回转为核心的速射传承。
- 核心战斗幻想：不是一发定生死，而是箭箭相接、石子连出、飞刀不断，让对手永远抬不起头也走不出线。
- 核心循环：用快速投射和连续命中维持准星回转，每次稳定命中都会让下一发更顺、更快或角度更刁；当节奏起来后，可打出多连发、压制射和转角补射。
- 资源关系：准星在这里更像节拍轮，而非蓄力槽；你越能连续命中、持续移动、不断换位，资源就越不会掉。
- 代表动作 / 机制：连珠快射、压头封步、移步补箭、连续命中后触发的多重追射。
- 边界定义：它不是穿杨式静态狙击，也不是奇门式布置机关火网；连珠的压制来自人本身的手上速度与节奏管理。
- 旁修影响面：旁修可提供换位、起手标记或一次地形互动，让连珠更容易接上第一轮节奏；但后续资源回转仍必须靠自身连续投射维持。

### 猎踪
- 定位一句话：以标迹追猎、视野压迫与移动惩罚为核心的追踪传承。
- 核心战斗幻想：你未必要马上射死对手，但你会让他无处可逃、越跑越暴露，直到每一步都踩进你的准线里。
- 核心循环：先用标迹箭、听风判位或环境触发给目标挂上踪迹，再凭视野优势与位移修正持续刷新准星；当对手转移、躲藏或试图脱离时，立刻以追踪射、减速射或揭示射收束。
- 资源关系：准星不仅来自瞄准，还来自“知道对方会往哪走”；越能维持目标可读性，越能低成本地持续追猎与补射。
- 代表动作 / 机制：标迹箭、揭影射、追身补射、利用油灯/阵眼/香炉等环境点做远程揭示或逼位。
- 边界定义：它不是影踪式潜入刺客，也不默认携带兽伴；猎踪的核心是人对地形、视线与目标路径的判断，而不是召物协战或陷阱职业化。
- 旁修影响面：旁修可补潜行入口、地形利用或短控，让追踪第一拍更稳；但其主闭环不能依赖宠物、长期布阵或 `MERIDIAN_SLOT_COUNT_PENDING` 等未定规则。

## 影踪
### 伏杀
- 定位一句话：以高隐蔽起手和定点收割为核心的单体处决型传承。
- 核心战斗幻想：黑衣刺客先借烟雾、阴影与视线死角逼近，锁定要害后在一瞬之间完成致命一击，再于敌阵回神前抽身藏形。
- 核心循环：藏形积累藏机 → 标记孤立或失衡目标 → 消耗高额藏机打出伏杀收束 → 借处决后的位移或再隐蔽重开下一轮。
- 资源关系：藏机主要来自未暴露位移、背袭起手与成功脱战；伏杀系招式以高额消耗换取穿防、增伤与再隐蔽窗口，若成功击溃目标则返还部分藏机维持滚动刺杀。
- 代表动作 / 机制：伏身绕背、封喉一击、烟遁换位、处决后隐线回收。
- 边界定义：它不是持续缠斗型近战，也不是依赖机关/毒药才能成立的爆发职业；其生态位是“选定目标并迅速斩断”，不会吞掉暗袭的中盘游斗，也不会吞掉设伏的地形经营。
- 旁修影响面：射艺可强化远距起手标记，药师可加强刀刃药性与失血压力，奇门/音律可帮助制造视线或时机；但伏杀的成立前提始终是影踪自身的藏形、接敌与处决链条。

### 暗袭
- 定位一句话：以频繁切入、错位连段和连番破绽打击为核心的游斗型传承。
- 核心战斗幻想：刺客不追求一击即走，而是在敌人反应边缘反复切入死角、割裂阵形，用多次短促而毒辣的暗袭把对手拖入失衡节奏。
- 核心循环：侧袭或借遮挡入场 → 通过连段命中与换位累积藏机 → 消耗藏机追加追击、穿插到敌侧后方或取消后摇 → 以再切入维持压迫。
- 资源关系：藏机由背侧命中、脱离敌正面与连续未受击的进攻节奏产生；暗袭分支更倾向把藏机拆分为多次中额消耗，用于追击步、移形、压制反应与短脱战，而非一次性重押。
- 代表动作 / 机制：影步切角、抹喉追击、借尸换位、残影脱手。
- 边界定义：它不是游锋式正面连击，也不是伏杀式豪赌处决；其身份是“以错位和阴影维持连续输出”，不会因为高机动而改写影踪必须依赖死角、遮挡和时机差的本质。
- 旁修影响面：拳掌可放大近身控制后的追击稳定性，射艺可补远距牵制与起手，音律可改善切入节拍；但暗袭的招牌仍是背侧换位、连段拆解与藏机滚动，不由旁修提供主循环。

### 设伏
- 定位一句话：以烟幕、假身、伏点和延迟触发为核心的伏击经营型传承。
- 核心战斗幻想：影踪高手先把战场切成看得见与看不见的两层，再诱使敌人踏入错位、惊惧与暴露交织的伏击网，于看似平静的一拍后突然收网。
- 核心循环：布置烟幕/伏点 → 诱导敌人穿越关键路径或暴露视线 → 触发伏点取得现身窗口与藏机返还 → 利用敌方混乱完成下一轮转场布伏。
- 资源关系：藏机主要由成功隐藏伏点、敌人踩入圈套、以及借烟幕切断追踪获得；其消耗集中在提前埋下的伏击强化、延迟引爆与连锁错位上，使影踪把资源投入“先手布局”而非纯即兴爆发。
- 代表动作 / 机制：烟幕封线、假身诱步、绊索惊袭、暗器连伏。
- 边界定义：它不是奇门式长期区域控场，也不是纯陷阱职业；设伏仍然服务于影踪的伏击与收割，只是把“何时现身”前移为“何时收网”，不会吞掉奇门对稳定阵地与器具循环的主权。
- 旁修影响面：奇门可增强伏点交互与局部地形读写，射艺可放大诱敌与远端触发，药师可附加烟毒或迟效药性；但设伏不以任何固定 loadout 数量为前提，且其核心仍是藏机经营与伏击收网。

## 药师
### 济世
- 定位一句话：以战中急救、稳态续航与逆转伤病为核心的救场型传承。
- 核心战斗幻想：白衣医者穿行刀光之间，以止血、续气、解毒和稳脉把将倒之人拉回战线，让队伍在最险的一拍里重新站住。
- 核心循环：识别重伤/异常目标 → 用低耗药方先稳住伤势与药性流失 → 关键时机消耗高阶药性完成急救、解毒或续命 → 借成功救场回收药性并重整下一轮施治顺序；其 2-4 回合价值集中在“救回一个要倒的人并稳住队伍”，而不是顺手包办输出与硬控。
- 资源关系：药性来自施药成功、解毒命中与预判性防护的有效生效；济世更强调把药性存成“应急储备”，在濒危窗口用高消耗换取大幅稳态恢复，救治正确目标后再获得返还。
- 代表动作 / 机制：金疮止血、回阳续气、护心汤、应手解毒。
- 边界定义：它不是万能奶妈，更不是无代价群体复活；济世的身份是“把人从崩盘边缘抢回来”，而非持续覆盖全队全部需求，也不会取代清音的情绪稳定、拳掌的硬控处置或破军的前线承伤。
- 旁修影响面：音律可强化救场节拍与团队稳态，拳掌/影踪可帮助贴近高危目标，奇门可提供安全施治区；但济世的主循环始终建立在药性管理、优先级判断与战中施治，而不是外部职业替它完成站场。

### 针脉
- 定位一句话：以针灸走穴、经脉调压与精确点状干预为核心的医武一体型传承。
- 核心战斗幻想：针师以飞针、走穴与逼脉在敌我经脉间游走，一面打通己方闭塞、一面截断对手气路，用极细微却致命的经络操作掌控战局。
- 核心循环：通过针刺命中建立经脉读数 → 根据敌我状态选择疏通、镇痛、封滞或逆冲 → 消耗药性引爆针路获得强控、强救或强破防中的一种高价值结果 → 回收已布针势准备下一轮走穴。
- 资源关系：药性既是药理储备也是针路驱动，来自成功刺入穴位、完成对症调理与回收旧针；针脉把药性转成“点状高精度支出”，比济世更主动、更讲究连点成线。
- 代表动作 / 机制：飞针定穴、疾针压拍、走脉回气、逆络封痛、连针逼宫。
- 边界定义：它不是拳掌的贴身擒控翻版，因为核心载体是针路与经脉调压，不靠裸手近身硬控；也不是纯治疗分支，因为其价值同样来自对敌经络破坏与节奏切断。但它也不包办济世的整队救场或蛊毒的长期侵蚀主权。
- 旁修影响面：拳掌可放大封穴后的近身惩罚，射艺可延伸远距飞针与抛射精度，音律可帮助维持针路节拍；但针脉是否成立，取决于药师自身对穴位、药性和连针次序的经营。

### 蛊毒
- 定位一句话：以持续侵蚀、毒性转化与险招换血为核心的消耗型传承。
- 核心战斗幻想：毒医把药箱翻成蛊匣，在看似克制的施药节奏里悄悄累积蚀骨之势，等敌人察觉时，毒、蛊、伤口与恐惧已经连成一条催命线。
- 核心循环：投放毒性或蛊印 → 通过多次命中/扩散累积病灶层数 → 消耗药性触发爆毒、转移或借毒续命 → 借敌方毒发、传播或成功收割回收药性；其 2-4 回合价值是持续压迫与逼对方交出解法，不承担济世式救场。
- 资源关系：药性由施毒成功、毒伤跳动、以毒换血以及回收蛊体产生；蛊毒分支允许把药性从“治疗储备”转为“侵蚀资本”，但高压输出通常伴随自损或准备成本。
- 代表动作 / 机制：封喉散、蚀骨蛊、逆血催毒、毒发牵连。
- 边界定义：它不是远程法术 DOT 职业，也不是比济世更全能的药师上位；蛊毒必须依托接触、投放、病灶经营与风险换血，不能在低魔边界外凭空施放大范围诡术，也不负责稳定团队节奏或精密单点救治。
- 旁修影响面：影踪可提升投毒潜入与收割时机，射艺可拓展飞针送毒与远距播散，奇门可制造扩散路径；但蛊毒的核心闭环是药性向毒性的转换和病灶经营，不以其他流派替代其主轴。

## 音律
### 战鼓
- 定位一句话：以冲锋鼓点、集体压迫和战线提速为核心的进攻统率型传承。
- 核心战斗幻想：鼓手立于阵前，以急促而沉重的鼓点把己方胆气与步法拧成一股前压之势，让冲锋、追击与集火在同一拍上爆发。
- 核心循环：通过推进、命中、自己踩出的重拍与友军响应累积节拍 → 用强拍把节拍转成冲锋、追击或士气爆发 → 在短暂高潮后重新收拍整队，准备下一轮集体压迫；若暂无队友跟拍，战鼓也能靠自身前压、震步与压锋维持拍点。
- 资源关系：节拍主要来自主动推进、重击共振与队友跟拍成功；战鼓倾向于把节拍做成“大开大合”的团队消耗品，集中投入关键回合以换取位移、行动效率或压制收益。
- 代表动作 / 机制：擂鼓振阵、齐步压锋、破胆重拍、自震续拍、追击号令。
- 边界定义：它不是站在后排挂机上 buff 的乐师，也不是破军的前排肉盾分支；战鼓必须靠自身进入战场中心制造共振，其身份是“以节拍推动全队进攻窗口”，而非替代任何人的主输出循环。敌方若能逼停鼓点、切断站位或抢先打乱强拍，战鼓就会明显掉速。
- 旁修影响面：破军可强化压线与冲锋收益，游锋可放大追击连段，奇门可帮助布置更适合跟拍的站位；但战鼓是否成立，仍取决于音律自身的节拍维持、强拍判断与团体共振。

### 清音
- 定位一句话：以稳心、解乱、续拍和柔性控场为核心的守稳型传承。
- 核心战斗幻想：琴箫轻起，混乱中的同伴逐渐找回呼吸与步法，恐惧、躁乱与疼痛被一点点压平，队伍在清音牵引下重新组织节奏并反守为攻。
- 核心循环：通过护持、净心、对位响应与自我稳拍累积节拍 → 在关键失序时消耗节拍完成稳态恢复、异常压制或行动重整 → 以重新建立的整齐节奏回补节拍并持续守住队形；单人时则以“先稳自身、再扰敌节奏”的方式完成回合交换。
- 资源关系：节拍来自成功安定异常、接住关键失误与维持连续柔拍；清音分支更擅长把节拍储存在“低噪稳流”中，换取净化、抗压与节奏校正，而非爆发式倾泻。
- 代表动作 / 机制：平心调息、清弦止惧、回拍续行、和声护脉、自守稳拍。
- 边界定义：它不是济世式纯医疗，也不是无脑全队常驻增益；清音的主权在于“让队伍不崩拍”，通过节奏校正抵消混乱，而不是把所有生存问题都包办。敌方若能持续逼近、打断演奏或制造多点异步压力，清音就必须在保人和保拍之间做取舍。
- 旁修影响面：药师可加强稳态恢复与异常应对，拳掌/破军可受益于更稳定的近身节奏，奇门可提供更安全的演奏位置；但清音的核心闭环仍是节拍净化、柔拍续行与队形再组织。

### 魔音
- 定位一句话：以扰心、乱拍、威压和精神裂口为核心的压制型传承。
- 核心战斗幻想：琴声不再抚人，而是像细针一样钻进心神与呼吸，让敌人的步法、胆气与判断在连续错拍中崩裂，最终于惊乱里露出致命空门。
- 核心循环：先以噪拍或异响给敌方叠加乱拍印记 → 消耗节拍引爆迟疑、错步、失手或互扰 → 借敌方心神受挫继续扩散压迫，形成连锁失衡；即使单人作战，也能靠一拍打断、一拍逼位、一拍追惩建立自己的短遭遇压制价值。
- 资源关系：节拍来自成功制造惊惧、打断、互扰与敌方错拍反应；魔音把节拍变成“施压弹药”，高频用于精神压迫、动作扭曲与集体失序，但仍需通过持续演奏维持压力。
- 代表动作 / 机制：裂拍惊魂、夺心泛音、乱弦压魄、回声追惩、断拍逼步。
- 边界定义：它不是西幻魅惑法师，也不是永久精神控制职业；魔音仍受听闻、距离、掩体与目标心志约束，其强处在于制造错拍和心理破绽，而不是剥夺敌人完整人格与行动权。敌方若能脱离听闻范围、利用掩体隔绝声路或强行抢拍近身，就能逼魔音失去连续压制。
- 旁修影响面：影踪可放大惊乱后的处决时机，奇门可结合局部封线制造听觉压迫区，药师可把乱拍转成更易命中的毒/针窗口；但魔音的核心身份仍是节拍施压与心神破口，不由旁修定义其主轴。

## 奇门
### 阵法
- 定位一句话：以阵眼经营、步位牵引和局部规则偏转为核心的阵地型传承。
- 核心战斗幻想：奇门术者不靠凭空放法，而是在有限空间里摆开阵眼、引导敌我步位，让一小片战场的顺逆、生克与进退都偏向自己这一边。
- 核心循环：布下阵眼与引线 → 借己方站位和敌方闯入累积阵机 → 消耗阵机改写局部区域的推进、视线、攻防或回收节奏 → 阵势收束后再迁阵重布；首回合至少要先拿到一块值得争夺的位点，而不是白白铺场。
- 资源关系：阵机来自阵眼存续、连线成势、敌我踏入关键位与成功触发阵式；阵法分支更强调把阵机投入“场域转向”，用一次中高额消耗换来短时但明确的区域优势。
- 代表动作 / 机制：落阵定宫、移宫换位、借势回环、封路偏锋、阵眼争位。
- 边界定义：它不是西幻大范围法阵轰炸，也不是设伏式纯伏击网；阵法的主权是让地形与步位暂时服从奇门规则，仍需阵眼、站位与时间经营，不会吞掉影踪或机关的身份。敌方若能绕阵、拔阵眼或逼奇门离开关键宫位，阵法收益就会明显下滑。
- 旁修影响面：破军可更好利用阵线偏转，音律可强化团队跟位节奏，射艺可扩大阵眼价值与远端触发；但阵法本体始终建立在阵机经营与布阵判断，而非依赖外部职业替它维持场域。

### 机关
- 定位一句话：以器具部署、连锁触发和可回收战场装置为核心的工巧型传承。
- 核心战斗幻想：机关师在短兵相接前后迅速摆出弩匣、翻板、绞索与火油匣，让敌人每一步都可能踩进被设计好的连锁反应中。
- 核心循环：部署低中型器具 → 诱发敌方触碰或主动远端触发 → 通过成功连锁积累阵机并刷新关键部件 → 把旧机关回收改造后投入下一轮布局；首回合即可用单件器具封角、逼位或抢一次交换，不必等满盘成型。
- 资源关系：阵机来自器具上膛、成功触发、回收重装与多装置联动；机关分支擅长把阵机拆成频繁的小额投入，用于缩短准备、强化连锁和维持装置在线，而不是只赌单次大爆发。
- 代表动作 / 机制：袖弩暗发、翻板绊敌、机簧连锁、回收改装、拆件转位。
- 边界定义：它不是召唤流工程师，也不是无限库存的现代火器职业；机关必须受器具体量、布置时间与可见物理载体约束，其优势在“工巧连锁”而非无中生有的远程轰炸。敌方若能提前识破载体、拆件或强闯未成链的装置，机关就只能换到有限的首拍收益。
- 旁修影响面：射艺可提升远端点火与机关联动，影踪可加强诱敌踩机与暗处布置，药师可把机关转成药烟/毒雾载体；但机关的主循环仍然是器具部署、触发链与阵机回收，不由旁修代替。

### 符禁
- 定位一句话：以符印压制、封脉禁行和短时驱邪破势为核心的封控型传承。
- 核心战斗幻想：术者挥符成禁，在门槛、兵刃、身位与呼吸间贴下看不见的约束，让敌人的身法、胆气与借势之路一层层被收紧，直到露出被封死的破口。
- 核心循环：先以符印标定人物、兵器或区域 → 累积阵机维持禁制强度 → 于关键时机消耗阵机触发封步、封势、驱散或反制 → 禁制消散后回收残符再定下一轮；首拍即可用一纸短符制造明确限制，但后续强度仍取决于是否守住媒介与位置。
- 资源关系：阵机来自贴符成功、禁制生效时长、破除敌方借势以及回收残符；符禁比阵法更重“单点强约束”，常用中额资源换取关键封锁、驱散或反制窗口。
- 代表动作 / 机制：镇煞黄符、封脉禁步、破势驱秽、残符回引、揭符断禁。
- 边界定义：它不是随手抛射的元素法术，也不是无限制的硬控职业；符禁依赖符印媒介、接触/定点条件与短时禁制，不会越界成高魔施法，也不会取代阵法的区域经营或药师的异常处理。敌方若能避开贴符条件、扯断媒介或迫使奇门分心，符禁就会失去连续封控。
- 旁修影响面：拳掌可放大封步后的近身惩戒，音律可强化压制窗口中的节奏错乱，影踪可借禁制制造更稳定的刺杀入口；但符禁能否成立，仍取决于奇门自身的贴符节奏、阵机管理与封控判断。
