# 05 Archetypes — Player Fantasy Presentation Layer

日期：2026-04-24  
状态：archetype active; identity deferred
Owner：canon systems designer

## Purpose
本文件定义“角色形象（捏脸及 NPC）”如何接入武侠 build 系统。

核心原则：**职业名不是系统根节点**。熟悉的武侠幻想最终可以由流派、传承、旁修、角色形象，以及未来恢复后的出身 / 身份共同包装出来；但系统入口不能先落成固定职业。

本轮约束：**出身 / 身份层先不用考虑**。因此当前 loop 里，玩家幻想只能由**流派、传承、旁修、角色形象**四层解释；资深游戏设计师 / CRPG systems reviewer 负责在玩家幻想、传承、旁修之间做综合取舍，不得把 deferred 身份层拿回来补职业根。

## Layer boundaries

### 出身 / 身份
Deferred。本轮不使用出身 / 身份解决玩家幻想。

本节仅保留为未来恢复时的 parked reference；本轮 reviewer、ticket 与 canon rewrite 都不得把下面的例子当作当前问题的解法。

可承载：
- 开局资源、初始关系、声望偏置；
- 对话、门派、官府、江湖势力反应；
- 剧情钩子与身份冲突；
- 少量起步便利或推荐 build。

不得承载：
- 锁死唯一流派；
- 锁死唯一传承；
- 提供无法由战斗系统解释的职业特权；
- 把身份奖励做成必选数值税。

示例身份：
- **僧人**：戒律、寺院关系、清修声望、武僧幻想入口。
- **捕快**：官府权限、缉捕线索、江湖合法性压力。
- **医谷**：医术声望、药材渠道、救人与毒术的道德张力。
- **杀手楼**：暗线委托、仇家、隐秘身份、背叛风险。
- **门派弟子**：师承关系、门规、同门网络、门派冲突。

### 角色形象（捏脸及 NPC）
角色形象负责让玩家和 NPC 被一眼理解，也是玩家幻想输入层。

可承载：
- 捏脸 / 服饰 / 姿态 / 武器展示预设；
- NPC 模板；
- 推荐 build 标签；
- 剧情称谓与江湖传闻。

不得承载：
- 唯一职业规则；
- 无法替换的核心数值；
- 传承成立前提。

## Archetype build grammar

每个熟悉幻想在**当前 round**都应写成：

```text
角色形象 = 流派主轴 + 传承倾向 + 旁修工具 + 表现标签
```

当前 round 的 canon rewrite 只允许在三处解决幻想压力：
1. **传承倾向**：当幻想缺的是主修内部专精的动作、资源或收束锚点时，改传承。
2. **旁修工具**：当幻想缺的是横向入口、接口、小循环或表现手感时，改旁修。
3. **表现标签**：当幻想已经由战斗层成立、只缺玩家一眼读懂的包装时，改角色形象。

不得用出身 / 身份补当前 round 的战斗缺口；也不得因一个熟悉名称就新增职业根节点。若一个 archetype 需要固定身份才能通过测试，应判为 revise / block，并回到传承或旁修层找真实缺口。

若未来重新启用出身 / 身份层，它也只能作为**战斗层已经成立后的额外包装标签**：

```text
熟悉武侠幻想 = 已成立的战斗层组合 + 出身 / 身份包装
```

它不能把上式改写回职业选择，也不能倒逼当前 round 借身份层补战斗缺口。

示例：

| 角色形象 | 可行组合方向 | 设计含义 |
|---|---|---|
| 武僧 | 拳掌主轴 + 点穴 / 擒拿 / 摧心倾向 + 药师或音律旁修接口 + 清修 / 护法表现标签 | “武僧”是结果，不是固定职业。它既可以是拳掌宗师，也可以是破军守阵 + 拳掌旁修的护法型变体。 |
| 游侠 | 游锋主轴 + 断势 / 藏锋倾向 + 影踪或射艺旁修接口 + 江湖行走表现标签 | 强调行走江湖、机动、义气与探索；不需要额外未定义的轻功 / 暗器子系统。 |
| 毒医 | 药师主轴 + 针脉 / 蛊毒倾向 + 影踪或音律旁修接口 + 医毒表现标签 | 毒医应先由药师主轴成立，再决定是偏单点针脉、偏病灶经营，还是借旁修补出切入 / 稳场手感。 |
| 机关师 | 奇门主轴 + 机关 / 阵法倾向 + 射艺或音律旁修接口 + 器具表现标签 | 机关是横向工具与布置权的放大器，不取代主修闭环；“机关师”不能偷换成独立工程职业。 |
| 琴魔 | 音律主轴 + 魔音倾向 + 奇门或影踪旁修接口 + 孤绝 / 压迫表现标签 | “魔”来自节拍施压、心神破口与角色气质，不要求高魔解释，也不允许越界成无解魅惑职业。 |
| 侠盗 | 影踪或游锋主轴 + 暗袭 / 设伏 / 藏锋倾向 + 奇门或射艺旁修接口 + 义盗 / 夜行表现标签 | 侠盗是行为方式与战术组合，不是固定职业，也不依赖出身 / 身份层成立。 |
| 独臂剑侠 | 游锋主轴 + 断势或藏锋倾向 + 影踪旁修接口或纯主修精修 + 孤剑 / 残式表现标签 | 该幻想依赖断招、残式应变与少招高判，不需要额外为“残式身份”再造职业根或背景补丁。 |
| 白衣琴医 | 音律主轴 + 清音倾向 + 药师旁修接口；或药师主轴 + 济世 / 针脉倾向 + 音律旁修接口 + 白衣 / 稳场表现标签 | 该幻想必须由音律 ↔ 药师的双向接口成立，不能把音律降格为纯 buff，也不能把药师写成无代价全能奶。 |
| 铁枪护法 | 破军主轴 + 守阵倾向 + 拳掌或音律旁修接口 + 护法 / 守门表现标签 | 护法感来自立线、拦截、稳场与近身处置，不是单独再造一个“圣骑士式”职业根。 |
| 扫地僧 | 任一主修主轴 + 对应传承倾向 + 精修 3 或极轻旁修接口 + 返璞归真 / 宗师表现标签 | 扫地僧型优先证明“纯主修练深”成立；旁修只能锦上添花，不能成为宗师幻想的隐藏税。 |
| 黄药师 | 音律 / 奇门 / 药师三者之一为主轴 + 对应传承倾向 + 另外两者作为旁修接口 + 杂学宗师 / 島主表现标签 | 黄药师型是多工具拼图，但必须有一个主修闭环；旁修负责地形、节拍、药理接口，不能把角色写成全能职业。 |
| 东方不败 | 影踪或药师主轴 + 暗袭 / 针脉倾向 + 药师↔影踪旁修接口 + 飞针 / 高速压迫表现标签 | 东方不败型的手感来自飞针、步法、切入和再压迫的小循环，不诉诸超自然瞬移，也不把身份或性别表达写成战斗规则。 |

上表所有 archetype 都必须先由战斗层组合成立，再决定未来是否追加 deferred 的出身 / 身份包装。


### Companion and named-organization boundary

本轮角色形象可以临时承载“帮派称谓、江湖外号、身边鹰犬”等**可见包装**，但这些包装不得倒逼战斗层新增职业、帮派权限、兽伴行动经济或隐藏资源。

- `丐帮 / 帮主 / 打狗棒` 之类称谓：当前只作为草莽号令、护众、掌棒表现与未来身份包装暂存；战斗层仍必须由拳掌、破军、音律、游锋等既有层级解释。
- `鹰 / 犬 / 灵兽` 之类同伴：若只提供外观、侦查氛围、剧情陪伴或 NPC 叙事，可以作为表现标签；若要求在战斗中独立侦查、夹击、承伤、触发资源或占用行动经济，则必须标记为 future companion system，当前 round 判为 deferred / block，不能偷塞进射艺、影踪或奇门。

## Wuxia fan loop input format

武侠幻想 reviewer 提出幻想时必须输出：
1. 幻想名；
2. 期望玩家感受；
3. 需要哪些层级表达；
4. 当前系统缺口；
5. 建议 ticket；
6. 通过条件；
7. 优先级。

不得只提出“我想要某某职业”。必须反推它由哪些层级组合达成。

资深游戏设计 / CRPG reviewer 必须对每个幻想做取舍判断：
- 哪些部分应该落在传承；
- 哪些部分应该落在旁修；
- 哪些部分只应该是表现标签；
- 哪些幻想会制造 mandatory tax、无 counterplay、或吞掉其他角色形象。

## Exit condition for archetype loop
角色形象 loop 在以下条件同时成立时停止：
1. 核心样例（武僧、游侠、毒医、机关师、琴魔、侠盗）都能由多层组合表达；
2. 没有样例要求新增职业根节点；
3. 没有样例强制某个旁修成为 mandatory tax；
4. CRPG reviewer 判定这些组合有战术选择与 counterplay；
5. leader 接受当前版本进入下一阶段。
