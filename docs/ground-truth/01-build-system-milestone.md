# 01 Build System Milestone

状态：milestone
日期：2026-04-25
用途：记录当前已经拍板的等级系统、流派、传承和旁修结论。本文是 active ground truth；`docs/reference/` 中的历史方案不再自动生效。

## 1. 设计方法

| 项 | 已确定 |
|---|---|
| 系统参照 | 参考 D&D / BG3 的成熟职业、子职业和 multiclass 结构。 |
| 流派定位 | 流派是能力领域，不是具体职业。 |
| 传承定位 | 传承是流派内部的成熟玩法底盘，不硬性凑数量。 |
| 旁修定位 | 旁修是低阶接入，不获得另一套完整主身份。 |
| 命名原则 | 先定玩法底盘，再做武侠化命名。 |
| 幻想资源 | 武侠幻想库用于压测构筑表达，不直接等同于传承。 |

## 3. 九级构筑规则

| 项 | 已确定 |
|---|---|
| 等级上限 | 9 级 |
| 主修锁定 | 1-3 级必须投入主修 |
| 传承选择 | 主修 3 级选择传承 |
| 自由修习 | 4-9 级可继续主修，也可旁修 |
| 满级主修下限 | 主修不得低于 6 |
| 旁修数量 | 最多旁修 2 个流派 |
| 单旁修上限 | 单个旁修最高 3 级 |
| 旁修限制 | 不获得流派高级技、传承高级技或传承身份 |

主修成长：

| 主修等级 | 获得内容 |
|---:|---|
| 1 | 基础技能包 + 1 个流派初级技 |
| 2 | 选 1 个流派中级技 |
| 3 | 选择传承，获得 1 个传承初级技 |
| 4 / 5 | 共获得 1 个中级技 + 1 个属性 / 被动提升 |
| 6 | 流派终局 |
| 7 / 8 | 共获得 1 个中级技 + 1 个属性 / 被动提升 |
| 9 | 传承终局，获得 1 个传承高级技 |

旁修成长：

| 旁修等级 | 获得内容 |
|---:|---|
| 1 | 获得该流派基础技能包 |
| 2 | 从该流派初级 / 中级技池选 1 个 |
| 3 | 再从该流派初级 / 中级技池选 1 个 |

## 6. 当前不处理

以下内容不进入当前 milestone，不得用来证明传承成立：

| 不处理内容 | 说明 |
|---|---|
| loadout / 装备矩阵 | 不定义携带技能数、装备槽、武器矩阵或最终装配限制。 |
| 经脉槽 / 运功位 | 不定义槽位数量、经脉装配或功法运转格。 |
| 具体数值技能 | 不写伤害、冷却、命中率、持续回合等数值。 |
| 完整状态系统 | 不细化所有状态、豁免、叠层和行动经济。 |
| 出身 / 身份系统 | 不用身份、门派权限或社会地位解决战斗系统问题。 |
| 独立傀儡 / 召唤物 | 机括可以有傀儡表现，但不定义独立行动、承伤、占格或共享行动经济。 |
| 剧情章节 / 势力系统 | 本文只定构筑系统骨架；政治阵营 ground truth 见 `02-political-faction-restructure.md`。 |
