# 02 World Setting

状态：ground truth
日期：2026-04-26
用途：定义《山水照影录》的世界客观规则，尤其是黑线、照影牒针、稳心验脉、引脉和显影归档的真实机制。旧剧情蓝本、章节细稿、网站内容和 `docs/reference/` 中的历史方案与本文冲突时，以本文为准。

## 1. Scope

本文只锁定世界设定中的客观事实。

本文处理：

## 2. 黑线定义

黑线不是疾病本身，而是 **已被暗植牒针 / 影纹载体后的显影反应**。

公众可以把它称为黑线怪病、疫症、疯症、腕疾或失控征兆，但这些都不是准确解释。黑线显现时，患者可能出现幻听、错拍、杀意、共感、昏厥、狂乱、脉象异常或局部皮肤纹路变化。

黑线的叙事功能不是制造普通瘟疫，而是让玩家逐步发现：

> 身体异常背后连接的是记录、预测、控制和裁决武人的权限系统。

## 3. 真实机制链条

黑线事件的真实链条为：

> 暗植种针 -> 稳心验脉 -> 引脉 -> 显影归档

| 环节 | 定义 | 公开表象 |
|---|---|---|
| 暗植种针 | 秘密前置植入牒针 / 影纹载体。 | 稳心治疗、止痛针、安神药、押送前镇定、医馆药引、战后救治、黑市秘药等。 |
| 稳心验脉 | 公开或半公开的读数 / 复核接口。它不负责种针。 | 检查走火、疯症、腕疾、疫症、封境风险。 |
| 引脉 | 对已被暗植者进行触发或诱发。 | 铃声、药引、问讯、脉法、机关频率或情绪压迫。 |
| 显影归档 | 将黑线反应写入记录系统。 | 案牍、封境记录、武籍、待验名单、风险等级。 |

核心锁定：

> 种针是前置暗植；稳心验脉是官方读数；引脉是秘密触发；显影归档是制度化证据。

## 4. 暗植种针

暗植种针必须保持秘密性。它不能被设计成一个所有人都能看懂的公开流程，也不能让玩家在第一章过早确认完整真相。

可用伪装包括：

- 稳心治疗；
- 止痛针；
- 安神药；
- 押送前镇定；
- 医馆药引；
- 战后救治；
- 黑市秘药；
- 机关针刺；
- 赈灾、疫检或复核过程中的辅助治疗。

暗植种针可以发生在开场之前，也可以在玩家调查中发现局部痕迹，但早期证据应呈现为不合规医疗、异常针孔、药性残留、账目缺口或押送记录，而不是完整解释。

## 5. 稳心验脉

稳心验脉不是种针。

它是一个可被公开解释的复核流程，用于判断某人是否存在走火、疯症、腕疾、疫症或封境风险。它可以被县衙、医馆、押送流程或武籍流程借用，但其表层身份始终是检查和复核。

稳心验脉的设计边界：

- 它可以读出异常；
- 它可以被包装成合理医疗或司法程序；
- 它可以为后续记录提供依据；
- 它不能公开承担植入功能；
- 它不能让普通见证者直接理解牒针和母局真相。

## 6. 引脉

引脉是对已被暗植者进行触发或诱发的动作。

可用触发源包括：

- 照影铃；
- 药引；
- 问讯节奏；
- 脉法压迫；
- 机关频率；
- 情绪诱导；
- 档案关键词；
- 断因旧令。

引脉可以制造局部失控、幻听、共感、昏厥、错拍或杀意。它的作用是把潜伏的牒针 / 影纹载体变成可观察、可记录、可归档的反应。

## 7. 显影归档

显影归档是黑线从身体异常转化为制度证据的过程。

显影归档可以写入：

- 案牍；
- 封境记录；
- 待验名单；
- 武籍；
- 风险等级；
- 押送文书；
- 医馆病录；
- 牒录残片。

显影归档的危险在于：它把一次被诱发的身体反应包装成可治理、可追捕、可审判的证据。第二章和第三章必须围绕这种证据是否可信、是否可被滥用、是否有资格裁决武人命运继续升级。

## 8. 章节揭示边界

第一章只能让玩家看到黑线怪病、封境复核、失控伤亡和局部触发异常。第一章不应完整解释暗植种针、显影归档和母局权限。

第二章可以让玩家发现显影结果正在被交易、篡改、灭证或制度化为武籍证据。

第三章才进入最终问题：这套记录、预测、控制和裁决武人的系统，是否有资格继续存在。
