# 03 Political Faction Restructure

状态：ground truth
日期：2026-04-26
用途：定义《山水照影录》的政治阵营结构、阵营内部分裂和机构认知边界。剧情蓝本、章节细稿、网站内容和旧 `script.md` 与本文冲突时，以本文为准。

## 1. 核心原则

《山水照影录》的政治结构不使用多个平级阵营。公开争夺江湖秩序的是 **缉武司** 与 **同尘盟**；**照影局** 是寄生暗线，潜伏在制度、医术、机关和黑市背后，第三章才完整显形。

慈心医脉、百工坞和鬼市不是独立政治终点，而是所有路线都必须争夺的关键中间势力。山水县百姓、边地部族、商队和牒针宿主不是背景板，而是检验每种政治方案代价的人。

黑线、牒针、稳心验脉、引脉和显影归档的客观机制见 `02-world-setting.md`。本文只处理不同机构、层级和派系对这些机制知道多少，以及他们如何使用或误用这些机制。

## 2. 阵营层级

| 层级 | 势力 | 叙事功能 |
|---|---|---|
| 核心政治轴 | 缉武司 | 国家秩序、武人入册、合法暴力、预防治安。 |
| 核心政治轴 | 同尘盟 | 江湖自治、门派义气、反抗滥权、复仇风险。 |
| 寄生暗线 | 照影局 | 预测、诱导、提前处置；隐藏在多方制度和技术接口背后。 |
| 关键中间势力 | 慈心医脉 | 掌握牒针药理、治疗合法性和医脉罪证。 |
| 关键中间势力 | 百工坞 | 掌握铃阵硬件、机关图和母局改造可能。 |
| 关键中间势力 | 鬼市 | 掌握身份、证词、牒录交易、地下入口和灭证渠道。 |
| 被治理者 | 百姓、边地部族、商队、牒针宿主 | 检验每种政治方案的真实代价。 |

## 3. 内部分裂

| 阵营 | 温和 / 正当面 | 激进 / 阴影面 |
|---|---|---|
| 缉武司 | 裴照：公开律法、可质询、可翻案。 | 沈照微：预防处置，把风险当作准罪名。 |
| 同尘盟 | 楚横山：江湖自救、护乡护路。 | 陆行舟：清算革命，把复仇写成新秩序。 |
| 照影局 | 白微尘：少数牺牲，避免更大灾祸。 | 司命：风险账本，提前剪断所有祸端。 |

支持缉武司不等于支持照影母局；支持同尘盟不等于支持暴动清算；利用照影局也不等于必须继承司命。

## 4. 机构认知边界

机构认知必须分层。知道可以触发黑线反应，不等于知道暗植种针真相；知道显影可以作为风险证据，也不等于知道照影母局。

| 层级 | 代表人员 | 已知内容 | 未知内容 |
|---|---|---|---|
| 普通基层 | 守卒、差役、临时医工、押送杂役。 | 封境复核、疫检、武籍入册、待验人犯、黑线怪病。 | 暗植种针、引脉机制、显影归档用途、照影局和母局。 |
| 稍高阶一线人员 | 验脉手、铃吏、案牍承办、押解队长。 | 某些铃声、药引、问讯、脉法或机关频率可以偷偷引出反应，并需要记录。 | 多数不知道种针从何而来，也不知道完整控制链条和母局真相。 |
| 缉武司强硬派中层 | 风险治理派、封境承办高阶、武籍改革执行者。 | 显影结果可以接入武籍，成为预防处置、隔离、追捕或审判的风险证据。 | 他们通常把它理解成新式治理技术，不掌握照影局古老来源和母局权限。 |
| 照影局核心 | 白微尘、司命及核心外勤。 | 暗植种针、稳心验脉、引脉触发、显影归档、权限控制的完整链条。 | 无。 |

设计规则：

- 缉武司不是整体全知机构。它被照影局利用，但不能被写成所有成员都知道牒针真相。
- 普通基层只能表现为执行封境、押送、疫检、入册和看守，不能直接解释黑线技术。
- 稍高阶一线人员可以秘密引脉和记录，但其认知应停留在“照流程能引出反应”。
- 缉武司强硬派中层可以推动显影证据制度化，但他们的政治罪责是滥用风险治理，不是完全继承照影母局。
- 照影局利用缉武司的合法外壳扩大采样、筛选和控制范围。

## 5. 三章政治问题

| 章节 | 政治问题 | 章节功能 |
|---|---|---|
| 第一章《封境》 | 局部崩坏时，谁有权决定牺牲？ | 用山水县封境、水患、疫病、县衙、山寨和隐藏照影局建立政治选择模板。 |
| 第二章《黄沙照影》 | 真相出现后，谁有权解释真相？ | 围绕山水县证据、牒录、石窟旧史和盟会话语权，决定玩家入城政治身份。 |
| 第三章《司命》 | 掌握母局后，谁有权书写未来？ | 通过城市识别、戒严、三钥争夺、武籍大审和母局裁决回收前两章选择。 |

## 6. 照影局出场规则

照影局不是常规公开投靠路线。

| 阶段 | 出场方式 |
|---|---|
| 第一章 | 外勤、铃阵、灭证、断因暗号；不承认完整组织存在。 |
| 第二章 | 潜伏在失卷、客栈密室、石窟旧史、盟会失控和楼坞档案背后。 |
| 第三章 | 完整显形，要求玩家决定是否继承、公开、改造或摧毁母局。 |

## 7. 任务设计要求

每个主线任务都必须回答一个政治问题，而不只是提供战斗、潜入或谈判路径。

任务至少应记录：

- 玩家把证据交给谁；
- 真相被如何解释或扭曲；
- 哪个阵营获得资源或失控；
- 照影局痕迹是否被发现；
- 被治理者承担了什么代价。

## 8. 变量要求

第二章变量至少记录：

- 证据归属；
- 真相解释框架；
- 照影局暴露程度；
- 照影楼坞结算。

第三章变量至少记录：

- 入城方式；
- 城市压力；
- 武籍大审结果；
- 母局权限；
- 照影局是否公开显形。
