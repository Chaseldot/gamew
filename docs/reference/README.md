# Reference Materials

本目录集中存放非 ground truth 材料。

这些内容可以作为写作蓝本、网站蓝本、资产参考、旧设计来源或历史记录，但不能直接约束后续开发。需要进入 active 设计时，必须先提炼并写入 `docs/ground-truth/`。

## Contents

| 路径 | 内容 |
|---|---|
| `story-blueprints/` | 第一章细稿、旧 story bible、旧 script。 |
| `design-blueprints/` | 游戏介绍、幻想库等非 active 设计参考。 |
| `website-blueprint/` | 旧网站代码、内容导出和站点资源。 |
| `assets/` | 探索期图片和美术资产。 |
| `plans/` | 旧计划文档。 |
| `narrative-pipeline/` | 叙事生产流程草案与根目录 planning 工作记忆。 |
| `archive/` | 历史归档。 |
