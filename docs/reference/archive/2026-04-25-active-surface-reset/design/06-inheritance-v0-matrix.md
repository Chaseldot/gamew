# 06 传承定位矩阵 v0

状态：draft / v1 返修后待复审
日期：2026-04-25
用途：从八大固定流派出发，先确定 24 个传承的玩法定位、CRPG 战斗职责、核心幻想和 9 级终局方向。本文不写具体数值技能，不处理 loadout / 经脉槽 / 装备矩阵。

## v1 返修摘要

本轮根据幻想覆盖审计与 CRPG 定位健康审计做一次返修：

- 收窄“关键动作否定”的职责轴：断势处理动作时机，点穴处理身体功能，穿杨处理远程射线打断，乱弦处理心神错拍，符禁处理路线 / 媒介禁制。
- 收窄重置循环：伏杀、暗袭、济世不再默认“成功后无代价重开”，必须保留暴露、失败、冷启动或资源代价窗口。
- 收窄针脉：不再默认同时高质量处理一敌一友，改成救人 / 截敌二选一，另一侧只能留下轻量余效。
- 强化道具、傀儡、香阵边界：道具先选主轴；傀儡只能是诱饵 / 触发载体；香术压入阵眼、机簧或药师媒介，不新增第四奇门传承。
- 暂定推荐改名：`魔音 -> 乱弦`、`阵法 -> 阵眼`、`机关 -> 机簧`，需用户后续拍板并回写 01 文档。

## 本轮约束

- 八大流派固定，不改名、不改核心资源。
- 满级 9，主修 3 选择传承，主修 6 获得流派终局，主修 9 获得传承终局。
- 旁修 1/2/3 只作为技能池与幻想测试参考；本轮不丰满旁修技能。
- 传承要服务 CRPG 战斗健康度：队伍职责清楚、循环可读、反制窗口存在、不能彼此吞并。
- 武侠幻想测试集只作为压测输入，不把幻想直接做成职业。

## 本轮待审计点

| 维度 | 需要检查 |
|---|---|
| 幻想覆盖 | active 武侠幻想库是否能自然映射到这些传承组合，是否有明显缺口。 |
| 定位健康 | 24 传承是否在 CRPG 队伍职责上过度重复，是否有纯输出 / 纯控制堆叠。 |
| 9 级适配 | 每个传承是否有清楚的 3 级初阶、5/7/8 中阶、9 级终局想象。 |
| 旁修参考 | 旁修只应启发低中阶技池，不能偷走传承高级技。 |
| 低魔边界 | 音律、奇门、药师、影踪不能滑向西幻法术或不可反制超能力。 |
