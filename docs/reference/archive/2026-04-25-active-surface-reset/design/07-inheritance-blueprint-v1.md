## 边界

- 八大流派固定：游锋、破军、拳掌、射艺、影踪、药师、音律、奇门。
- 不改八大流派定位，不改核心资源：锋势、冲势、经脉破绽、准星、藏机、药性、节拍、阵机。
- 满级 9；主修 3 级选择传承，6 级是流派终局，9 级是传承终局。
- 本文不写具体数值，不处理 loadout、经脉槽、装备矩阵、身份、同伴 / 傀儡独立战斗系统。
- 旁修只作为低中阶技能池与幻想测试参考；旁修不能获得流派高级技、传承高级技或传承身份。
- 24 个传承严格为 8 流派 × 3。

## 24 传承蓝图表

### 游锋 / 连锋

| 字段 | 内容 |
|---|---|
| 所属流派 | 游锋 |
| 传承类型 | 连段压制 |
| 推荐名 | 连锋 |
| CRPG 战斗定位 | 近身持续压迫 / 追击位。 |
| 核心幻想 | 剑势不断，贴住对手越打越快。 |
| 核心循环 | 贴步试锋，连续命中滚高锋势，用追击或连斩收束，再回到继续压步的位置。 |
| 资源关系 | 通过贴身命中、借步避招和追击窗口获得锋势；锋势用于续段、追击与高质量收束。 |
| 3 级初阶方向 | 获得传承身份：命中不断链时可以把一次普通追击转成稳定位移压迫。 |
| 5 / 7 / 8 中阶方向 | 补齐断连后的轻量回身、换位续段、收束后压步和被格挡时的节奏调整。 |
| 9 级传承高级技方向 | 高锋势收束命中后抓回贴身窗口，使连段结束不是退场，而是进入下一轮压迫。 |
| 旁修参考接口 | 游锋式贴步、短追击、低阶断连补救可供旁修借味；不得开放高锋势终局续压。 |
| 边界 | 不是刺客爆发，不是防守反伤，不靠影踪或音律才能成立。敌人可用拉距、格挡、断连破坏闭环。 |
