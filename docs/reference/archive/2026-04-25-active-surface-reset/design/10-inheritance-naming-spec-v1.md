# 10 传承命名规格 v1

状态：draft / naming layer
日期：2026-04-25
用途：解决“玩法标签不像传承名”的问题。本文只处理 24 传承的命名层级，不改八大流派、不写技能数值、不处理 loadout、经脉槽、装备矩阵、同伴或身份系统。

## 1. 命名问题

上一轮 `破阵 / 守阵 / 走射 / 缉踪` 等名字在审计上很清楚，但它们更像玩法标签，不像一个流派下流传的一支传承。

从现在开始，传承命名拆成两层：

| 层级 | 面向对象 | 用途 | 示例 |
|---|---|---|---|
| 正式传承名 | 玩家、文案、界面 | 有师承感，可以读作“某某一脉” | `破军·摧坚` |
| 玩法标签 | 设计、审计、技能池拆分 | 直说它在战斗中干什么 | `破阵` |

建议界面和文档第一次出现时写作：

> `破军·摧坚一脉`，玩法标签：破阵。

后续表格可以简写为：

> `摧坚` / `破阵`

## 2. 命名规则

| 规则 | 说明 |
|---|---|
| 传承名要像“路数” | 能自然接 `一脉`、`传承`、`门下`，而不是只像一个动作。 |
| 玩法标签要直白 | 标签可以很工程化，用来辅助审计和技能拆分。 |
| 正式名不必完全解释机制 | 只要给出气质和方向；机制由玩法标签和蓝图字段解释。 |
| 同流派三传承要成组 | 同一流派内部尽量保持语感一致。 |
| 避免抢其他流派能力 | 名字不能暗示它偷了别的能力主权。 |
| 避免太像身份 / 职业 | `镖客`、`捕快`、`猎人`、`道人` 这类应留给幻想卡，不作为传承名。 |

## 4. 重点改名说明

| 原名 / 标签 | 问题 | 正式传承名 | 玩法标签 | 说明 |
|---|---|---|---|---|
| 破阵 | 太像动作或关卡行为 | 摧坚 | 破阵 | `摧坚` 有破坚阵、破硬线的师承感。 |
| 守阵 | 太像战术命令 | 镇关 | 守阵 | `镇关` 更像一脉武学，覆盖守桥、守门、守线。 |
| 走射 | 太像操作说明 | 游矢 | 走射 | `游矢` 表示流动的投射路线，仍由标签解释移动射。 |
| 缉踪 | 太像职业行为 | 逐迹 | 缉踪 | `逐迹` 更像射艺传承，减少捕快职业感。 |
| 截锋 | 太像技能动作，且与截脉字面近 | 断势 | 破招截链 | `断势` 更像兵刃破招一脉，不碰身体功能。 |
| 截脉 | 与药师针脉冲突 | 点穴 | 精准封控 | `点穴` 是拳掌经典幻想，边界写明必须贴身读劲。 |

## 5. 正式展示格式

建议正式展示时使用：

| 展示位置 | 格式 | 示例 |
|---|---|---|
| 角色构筑摘要 | `流派:传承` | `破军:摧坚` |
| 传承详情标题 | `流派·传承一脉` | `破军·摧坚一脉` |
| 设计文档矩阵 | `正式名 / 玩法标签` | `摧坚 / 破阵` |
| 技能池拆分 | 用玩法标签 | `破阵低阶技`、`破阵中阶技` |
