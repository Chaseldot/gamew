# 11 从 v0 裁剪的 2 传承版 v1

状态：draft / two-branch inheritance
日期：2026-04-25
来源：`docs/design/06-inheritance-v0-matrix.md`
用途：从 v0 的 24 传承出发，裁剪成“默认每派 2 传承，少数流派保留 3 传承”的低设计压力版本。

## 1. 设计目标

| 项 | 内容 |
|---|---|
| 固定不改 | 八大流派；9 级里程碑；主修 3 选择传承；主修 9 获得传承终局 |
| 本轮目标 | 从 v0 三传承结构裁剪为低设计压力版本 |
| 默认规则 | 每个流派保留 2 个传承 |
| 例外规则 | 只有武侠幻想强、战斗定位独立、无法自然并入另外两条时，才保留第 3 传承 |
| 不处理 | 数值技能、loadout、经脉槽、装备矩阵、身份系统、同伴 / 兽伴系统 |

## 2. 裁剪原则

| 原则 | 说明 |
|---|---|
| 保留传承级身份 | 玩家选它后，9 级终局能形成清楚的一条宗师路线。 |
| 降级技能型方向 | 如果它更像一组动作、技巧、反制方式或中阶打法，就降级为技能池。 |
| 保留武侠幻想最强轴 | 优先保留玩家脑海里最容易成立的武侠形象。 |
| 避免为凑数而硬分 | 传承宁少勿滥；技能池可以承接大量细分玩法。 |
| 旁修保留味道 | 被裁掉的传承不消失，可以成为旁修接口、传承中级技或高阶绝艺候选。 |

## 3. 推荐总表：19 传承

| 流派 | 能力主权 | v0 三传承 | 2 传承版推荐 | 是否保留第 3 传承 | 裁剪理由 |
|---|---|---|---|---:|---|
| 游锋 | 缠斗 | 连锋 / 断势 / 藏锋 | 连锋 / 藏锋 | 否 | 连锋是持续缠斗，藏锋是蓄势转折；断势更像破招技能组，可并入游锋中阶技。 |
| 破军 | 阵线 | 冲阵 / 守阵 / 震岳 | 冲阵 / 守阵 | 否 | 冲阵、守阵已经覆盖破敌线 / 守己线；震岳更适合作为重压高阶技或 6 / 9 级绝艺。 |
| 拳掌 | 制身 | 点穴 / 擒拿 / 摧心 | 点穴 / 摧心 | 否 | 点穴管精准封控，摧心管重掌内伤；擒拿是拳掌通用控身技组，可并入点穴中段。 |
| 射艺 | 射线 | 穿杨 / 连珠 / 猎踪 | 穿杨 / 猎踪 | 否 | 穿杨是一发定局，猎踪是读路追线；连珠更像射艺通用连射 / 压头技能。 |
| 影踪 | 藏形 | 伏杀 / 暗袭 / 设伏 | 伏杀 / 暗袭 | 否 | 伏杀是孤立处决，暗袭是错位游斗；设伏容易侵入奇门，可降级为影踪 / 奇门接口技。 |
| 药师 | 药性 | 济世 / 针脉 / 蛊毒 | 济世 / 针脉 / 蛊毒 | 是 | 医、针、毒三轴都很强，且战斗职责不同；强行裁剪会损失药师核心幻想。 |
| 音律 | 节奏 | 战鼓 / 清音 / 乱弦 | 振律 / 清音 / 错律 | 是 | 振己、稳己、乱敌三轴清楚；名称采用用户已拍板的 `振律 / 清音 / 错律`。 |
| 奇门 | 布局 | 阵法 / 机关 / 符禁 | 阵法 / 机括 / 符禁 | 是 | 阵、器、符三轴是奇门脑洞核心；名称采用用户倾向的 `机括`。 |

总数：**19 个传承**。

## 4. 19 传承矩阵

| 流派 | 正式传承 | 玩法标签 | CRPG 定位 | 9 级终局方向 | 边界 |
|---|---|---|---|---|---|
| 游锋 | 连锋 | 连缠续压 | 近身持续压迫 / 追击位 | 高锋势收束后返还贴身窗口，继续压步 | 不是刺客爆发，不靠隐蔽起手 |
| 游锋 | 藏锋 | 敛势显锋 | 延迟爆发 / 单点转折位 | 一次高质量显锋造成局势转折 | 不是影踪潜行，不做处决链 |
| 破军 | 冲阵 | 破线开路 | 正面破口 / 开路前排 | 破开阵线后形成短时推进通道 | 不是无脑冲锋，不是游锋追击 |
| 破军 | 守阵 | 护线反打 | 要点防守 / 阵线护卫 | 守住关键线后反定局部战场 | 不是纯肉盾，不是嘲讽，不偷拳掌擒拿 |
| 拳掌 | 点穴 | 精准封控 | 单体功能压制 / 精英控手 | 短时封住一个已读出的身体功能 | 不隔空封脉，不做万能硬控 |
| 拳掌 | 摧心 | 重掌内伤 | 正面重创 / 延迟压力 | 高破绽重掌留下迟发内伤 | 不是药师毒伤，不是奇门咒禁 |
| 射艺 | 穿杨 | 定线点破 | 远程单点 / 关键打断 | 高质量射线惩罚暴露核心目标 | 不隔掩体，不替代影踪刺杀 |
| 射艺 | 猎踪 | 标迹追线 | 反机动 / 追逃位 | 被标迹目标越位移越暴露并进入收束窗口 | 不默认兽伴，不做奇门侦测法阵 |
| 影踪 | 伏杀 | 隐蔽处决 | 先手爆发 / 孤立处决位 | 未暴露、孤立、弱点成立时处决并抽身 | 不是不可反制隐身，不自动重隐 |
| 影踪 | 暗袭 | 错位游斗 | 中盘扰乱 / 反锁定机动 | 连续错位成功后换位收束 | 不是游锋正面连击，不取消已成型反击 |
| 药师 | 济世 | 战中急救 | 防崩稳态 / 急救逆转 | 关键救治消耗储备换稳定窗口 | 不是万能奶妈，不无代价群体复活 |
| 药师 | 针脉 | 针路调压 | 精准干预 / 取舍控制位 | 高药性针路在救人或截敌主效间取舍 | 不是拳掌翻版，不同时全额处理敌我 |
| 药师 | 蛊毒 | 毒性运营 | 持续侵蚀 / 风险换血位 | 毒性成熟后在爆毒与回收药性间收束 | 不是法术 DOT，不是济世上位版 |
| 音律 | 振律 | 主动强拍 | 团队推进 / 进攻窗口位 | 强拍成功后打开己方跟进窗口 | 不改写行动顺位，不是后排挂机 buff |
| 音律 | 清音 | 稳拍解乱 | 防崩稳场 / 解乱位 | 阻止一次节奏崩盘并重整 | 不是治疗、止血、解毒或复活 |
| 音律 | 错律 | 扰拍造隙 | 敌方扰乱 / 空门制造位 | 连续错拍后暴露关键空门 | 不是魅惑、恐惧支配或永久控制 |
| 奇门 | 阵法 | 局部改场 | 路径控制 / 局部改势位 | 成局后短时改变局部路径优劣 | 不是大范围法阵轰炸，不编辑地形 |
| 奇门 | 机括 | 器具连锁 | 装置触发 / 连锁控场位 | 连锁成功后改造旧装置入口或保留残局威胁 | 傀儡只是诱饵 / 载体，不独立战斗 |
| 奇门 | 符禁 | 媒介禁令 | 短时禁线 / 媒介反制位 | 短时锁路线、兵器或媒介之一 | 不是元素法术，不封全身功能 |

## 5. 降级表

| 原 v0 传承 | 原流派 | 降级去向 | 保留价值 |
|---|---|---|---|
| 断势 | 游锋 | 游锋中阶破招技组 / 藏锋前置判断 / 旁修接口 | 反制精英、看穿重手、断动作链。 |
| 震岳 | 破军 | 破军重压高阶技 / 冲阵或守阵的 9 级绝艺候选 | 重兵压场、震退近身阵脚。 |
| 擒拿 | 拳掌 | 点穴中段控身技组 / 拳掌基础控身包 | 锁拿、摔制、缴械、置位。 |
| 连珠 | 射艺 | 射艺中阶连射技组 / 穿杨与猎踪共用压头技 | 快射、连射、压头、换线。 |
| 设伏 | 影踪 | 影踪中阶伏点技 / 奇门接口技 | 烟幕、假身、伏点、诱敌踏入。 |

## 6. 严格 16 传承版

如果后续必须每派都只有 2 个传承，可以继续裁剪为 16，但当前不推荐。

| 流派 | 严格 16 版保留 | 被裁掉 | 风险 |
|---|---|---|---|
| 药师 | 济世 / 蛊毒 | 针脉 | 银针、飞针、针灸医武幻想会变弱。 |
| 音律 | 振律 / 错律 | 清音 | 稳心、解乱、防崩幻想会变成普通技能，音律支援面变薄。 |
| 奇门 | 阵法 / 机括 | 符禁 | 符箓道人、禁制、短令幻想损失明显。 |

结论：严格 16 可以降设计量，但会损失三个最有辨识度的武侠幻想轴。当前推荐 **19 传承版**。

## 7. 仍需拍板

| ID | 问题 | 推荐 | 影响 |
|---|---|---|---|
| TWO-001 | 是否采用 19 传承作为新基线 | 是 | 设计量从 24 降到 19，同时保留药师、音律、奇门三轴幻想。 |
| TWO-002 | 游锋是否保留 `连锋 / 藏锋`，把 `断势` 降级 | 是 | 游锋传承变成持续压迫 vs 蓄势转折；破招进入技能池。 |
| TWO-003 | 破军是否保留 `冲阵 / 守阵`，把 `震岳` 降级 | 是 | 破军传承变成破敌线 vs 守己线；重压成为高阶技。 |
| TWO-004 | 拳掌是否保留 `点穴 / 摧心`，把 `擒拿` 降级 | 是 | 拳掌传承变成控制 vs 重创；擒拿进入控身技能组。 |
| TWO-005 | 射艺是否保留 `穿杨 / 猎踪`，把 `连珠` 降级 | 是 | 射艺传承变成定线点破 vs 标迹追线；连射进入技能池。 |
| TWO-006 | 影踪是否保留 `伏杀 / 暗袭`，把 `设伏` 降级 | 是 | 影踪传承变成处决 vs 错位游斗；伏点进入技能池和奇门接口。 |

## 8. 下一步

| 优先级 | 动作 | 理由 |
|---|---|---|
| 1 | 用户拍板是否采用 19 传承版 | 这是新的设计基线。 |
| 2 | 若采用，回写传承总表并标注降级技能池 | 避免 24 传承版本继续漂移。 |
| 3 | 再跑一轮幻想测试审计 | 检查被降级的 5 条是否造成幻想缺口。 |
| 4 | 再细化 19 个传承的 3 / 5 / 7 / 8 / 9 级职责 | 比 24 个传承可控得多。 |
