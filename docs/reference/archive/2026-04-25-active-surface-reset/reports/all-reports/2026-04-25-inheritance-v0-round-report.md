## v1 返修结果

| 审计问题 | v1 处理 | 复审结论 |
|---|---|---|
| 控制职责过密 | 拆成动作断点、身体功能、射线打断、心神错拍、路线 / 媒介禁制。 | 已解决 |
| 伏杀 / 暗袭 / 济世无代价重开 | 增加暴露、失败、资源代价或自保窗口限制。 | 已解决 |
| 针脉过宽 | 改为救人或截敌二选一，另一侧只有轻量余效。 | 已解决 |
| 设伏与机簧重叠 | 设伏偏藏形诱导，机簧偏器具连锁。 | 已解决 |
| 藏锋与伏杀重叠 | 藏锋保留正面兵刃蓄势，伏杀保留隐蔽处决。 | 已解决 |
| F-024 牵丝傀儡师承诺过强 | 机簧边界写明傀儡只能是诱饵 / 载体，不独立行动。 | 已解决为 P3 |
| 连锋破局窗口不足 | 补充拉距、格挡、断连可破坏闭环。 | 已解决 |
