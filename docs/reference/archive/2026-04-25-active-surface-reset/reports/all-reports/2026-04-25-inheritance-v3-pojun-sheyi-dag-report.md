## 3. 破军返修结果

| 旧 v2 | 新 v3 | 处理 | 理由 |
|---|---|---|---|
| 陷阵 | 破阵 | 替换 | `陷阵` 容易读成莽冲或敢死；`破阵` 更直观表达正面破线、开缺口 |
| 镇阵 | 守阵 | 替换 | `镇阵` 偏静态；`守阵` 更清楚是立线、截步、反推 |
| 擎岳 | 震岳 | 替换 | `擎岳` 与守线护卫重叠；`震岳` 转为主动重压压场 |

| 传承 | 定位 | 核心循环 | 9 级终局 | 审计结论 |
|---|---|---|---|---|
| 破阵 | 正面破口 / 开路前排 | 起冲抢线 -> 探枪开口 -> 穿位击退 -> 驻住缺口 | 短时打穿推进通道，使己方沿缺口压入 | 通过；需补破口失败回收 |
| 守阵 | 要点防守 / 阵线护卫 | 立线 -> 读越线 -> 截步拦入 -> 反推出线 | 守住关键线后反定局部战场 | 通过；需防连续越线惩罚变无限光环 |
| 震岳 | 近身圈重压 / 邻近失衡位 | 稳站蓄压 -> 重步逼线 -> 重击震退 | 高冲势重击震散邻近阵脚，制造再站线窗口 | 条件通过；需防泛 AOE / 地形法术化 |

## 7. 需要补硬的边界句

| 对象 | 建议边界句 |
|---|---|
| 破阵 | 破阵只沿明确线位开缺口，不做无条件冲锋、追杀或刺杀；破口未成会冲势泄漏，需退回立线或被队友接应 |
| 守阵 | 守阵是立线截步后反推，不是嘲讽、纯承伤，也不偷拳掌擒拿；绕后、假越线、远程逼退、双线夹击都能拆守阵 |
| 震岳 | 震岳的“震”来自重兵、步法、站位与冲势，不是地震法术，也不是泛 AOE 清场；只影响近身接触或武器扫线内目标 |
| 穿杨 | 穿杨只惩罚暴露在射线上的关键目标，不隔掩体、不连锁处决、不替代影踪刺杀 |
| 走射 | 走射是移动换线后的短压制，不是无限弹幕；断视线、近身压迫、换线失败都会打断续射 |
| 缉踪 | 缉踪是标迹追线与反机动，不等于抓捕系统、兽伴战斗，也不做伏点绊索主循环 |
