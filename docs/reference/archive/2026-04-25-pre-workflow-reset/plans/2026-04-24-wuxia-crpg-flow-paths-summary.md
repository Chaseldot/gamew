# 低魔武侠 CRPG 设计摘要

日期：2026-04-24

状态说明：
- `已确定`：当前讨论中已经达成一致，可作为后续设计基线。
- `暂定`：当前方向明确，但仍可能在下一轮细化时调整。
- `待定`：已识别问题或分歧，尚未收口。

## 1. 项目目标

`已确定`

项目目标不是先做 demo，而是先完成一套可持续推进的前期设计方案，重点包括：
- 游戏设定与世界规则
- 八大流派体系
- 主修 / 精修 / 旁修规则
- 传承蓝图
- 武侠风格与低魔边界

总体方向：
- 参考《博德之门 3》《神界：原罪 2》等 CRPG 的系统深度
- 保留武侠题材的江湖感、经脉感、门派/师承感
- 避免做成西幻职业换皮
- 避免做成高武仙侠或大地图模拟器

## 2. 世界与风格方向

`已确定`

- 类型为 **低魔武侠 CRPG**
- 重点是 **角色扮演、多解任务、系统互动、回合制战斗**
- 不走仙侠飞升、法宝天劫、大范围法术轰炸路线
- 不优先做开放世界，而是更适合做 **高密度章节式区域**

`已确定` 的低魔边界：
- 奇门可以有阵法、符禁、香术、机关、障眼法
- 音律可以影响士气、心神、节奏
- 药师可以治疗、解毒、施毒、针灸、蛊药
- 影踪可以利用烟雾、阴影、视线、易容、暗器

`待定`

- 世界底层规则的最终命名与正式设定文本
  - 例如是否统一强调“内力 / 经脉 / 江湖名望 / 誓约”中的哪几个为底层规则
- 章节结构、第一章题材和主要势力尚未定稿

## 3. 八大流派

`已确定`

八大流派定版为：

1. 游锋
2. 破军
3. 拳掌
4. 射艺
5. 影踪
6. 药师
7. 音律
8. 奇门

设计原则：
- 流派是 **主修战斗体系**，不是装备锁
- 所有人可以使用基础装备
- 但只有主修才能把某类动作发展成完整战斗循环
- 流派名不再等于“职业岗位”或“单一武器类别”

`已确定` 的流派定位：

| 流派 | 主定位 |
|---|---|
| 游锋 | 近身兵刃节奏、游斗、反击、连击、破绽 |
| 破军 | 阵线改变、冲阵、扫退、拦截、破围 |
| 拳掌 | 贴身控制、点穴、擒拿、破内、缴械 |
| 射艺 | 视野、距离、投射、高地、标记 |
| 影踪 | 隐蔽、伏击、脱战、暗袭、设伏 |
| 药师 | 药、针、毒、蛊，治疗与削弱一体两面 |
| 音律 | 士气、节奏、心神、群体影响 |
| 奇门 | 阵法、符禁、机关、香术，改写局部战场规则 |

`已确定` 的主要风险：
- 游锋过宽，不能吞掉破军与影踪的生态位
- 影踪不能沦为工具人
- 药师不能变成万能奶妈
- 奇门不能滑向西幻法师
- 音律不能只是 buff 工具人

## 4. 主修 / 精修 / 旁修规则

`已确定`

建议采用 **12 级上限** 的角色成长框架。

成长节点：

| 等级 | 解锁 |
|---|---|
| 1 | 选择主修流派，获得核心资源与基础循环 |
| 3 | 选择传承 |
| 4 | 第 1 个自由修习点 |
| 6 | 传承进阶 |
| 8 | 第 2 个自由修习点 |
| 10 | 第 3 个自由修习点 |
| 11-12 | 传承终局 / 精修宗师技 |

自由修习点的用途：
- 投给其他流派：形成旁修
- 回投主修流派：形成精修

限制：
- 只能有 1 个主修流派
- 只能有 1 个传承
- 总共 3 个自由修习点
- 最多旁修 2 个流派
- 单个旁修最多 3 点
- 旁修技能要占用经脉槽 / 运功位
- 旁修拿不到传承、宗师技、完整核心循环

`已确定`

精修的意义：
- 纯主修必须有上限奖励，不能比混修亏
- 精修 1：提高资源上限或资源恢复稳定性
- 精修 2：强化主修核心动作
- 精修 3：解锁纯主修宗师技或传承终局强化

## 5. 主修核心资源

`已确定`

每个流派都需要自己的资源循环，而不是只靠技能列表：

| 流派 | 核心资源 |
|---|---|
| 游锋 | 锋势 |
| 破军 | 冲势 |
| 拳掌 | 经脉破绽 |
| 射艺 | 准星 |
| 影踪 | 藏机 |
| 药师 | 药性 |
| 音律 | 节拍 |
| 奇门 | 阵机 |

`已确定`

设计原则：
- 主修深度来自资源循环
- 传承必须从资源循环分化
- 旁修只能提供入口、接口、小循环，不能补主修缺陷

## 6. 旁修机制

`已确定`

旁修采用统一三层结构：

- 1 点：入口
- 2 点：接口
- 3 点：小循环

旁修不应再粗糙地统一为“每战一次技能”。

`已确定` 的旁修基线：

| 旁修 | 1 点：入口 | 2 点：接口 | 3 点：小循环 |
|---|---|---|---|
| 游锋 | 轻兵熟练，小幅贴近/换位 | 近战命中或闪避后获得临时锋势 | 攻守切换：移动后近战获追击窗口，敌人失手可反击 |
| 破军 | 长兵/重兵熟练，基础推开 | 命中后短距离调整目标位置 | 压阵：占关键格后首次击退/拦截增强 |
| 拳掌 | 徒手熟练，基础擒拿 | 近身命中叠失衡 | 寸劲：连续贴身攻击后，下一击附带弱封穴/击退/打断 |
| 射艺 | 投射熟练，可瞄准投掷 | 远距触发油灯、机关、阵眼、药瓶、香炉 | 借势投射：移动后投射增强；掷出主武器后拳脚/备用武器获追击窗口 |
| 影踪 | 潜行、脱战、烟丸 | 隐蔽攻击后小幅转移 | 匿踪：烟雾、阴影、遮挡中攻击后保留部分隐蔽收益 |
| 药师 | 止血、识药、基础解毒，小药囊 | 武器、投射物或拳脚附带基础药性 | 药性循环：治疗、解毒或施毒成功后返还少量药性 |
| 音律 | 小鼓舞，基础抗恐惧 | 关键命中、治疗或控制后获得小士气收益 | 换拍：小幅调整自己或一名队友行动节奏 |
| 奇门 | 识阵、拆简易机关、基础符器 | 小阵眼/简易符禁，短时区域效果 | 符位循环：站在己方小阵/符位附近，可刷新一次低阶符禁或机关触发 |

`已确定`

射艺旁修特别强调：
- 不是简单“远程熟练”
- 而是 **投射 / 投掷 / 远程触发体系**
- 支持“掷出武器 → 转拳脚 / 备用武器继续战斗”的武侠动作逻辑

`待定`

- 经脉槽 / 运功位的具体数量与装配规则尚未设计
- 旁修技能是否按“主动/反应/被动/探索”进一步分类，尚未设计

## 7. 传承设计原则

`已确定`

传承是主修循环的高阶分化，不是第二职业。

设计边界：
- 传承必须从主修核心循环分化
- 每个传承都要有纯主修闭环
- 旁修只能增强某种打法，不能成为传承必需件
- 每个传承最多强化一个主轴
- 传承之间必须改变战斗节奏，不只是换伤害类型
- 传承终局能力必须主修锁定
- 传承边界不能简单按武器分

`已确定`

传承数量方案：
- 每个流派保留 3 个传承蓝图
- 第一阶段只深度打磨每流派 2 个核心传承
- 第 3 个传承先做概念预留

## 8. 传承蓝图

`暂定`

以下命名和职责方向已较稳定，但尚未展开为完整技能与数值设计。

| 流派 | 传承 1 | 传承 2 | 传承 3 |
|---|---|---|---|
| 游锋 | 连锋 | 断势 | 藏锋 |
| 破军 | 冲阵 | 守阵 | 震岳 |
| 拳掌 | 点穴 | 擒拿 | 摧心 |
| 射艺 | 穿杨 | 连珠 | 猎踪 |
| 影踪 | 伏杀 | 暗袭 | 设伏 |
| 药师 | 济世 | 针脉 | 蛊毒 |
| 音律 | 战鼓 | 清音 | 魔音 |
| 奇门 | 阵法 | 机关 | 符禁 |

优先深挖的 16 个传承：
- 游锋：连锋、断势
- 破军：冲阵、守阵
- 拳掌：点穴、擒拿
- 射艺：穿杨、连珠
- 影踪：伏杀、暗袭
- 药师：济世、针脉
- 音律：战鼓、清音
- 奇门：阵法、机关

概念预留的 8 个传承：
- 藏锋、震岳、摧心、猎踪、设伏、蛊毒、魔音、符禁

## 9. 典型 Build 幻想

`已确定`

当前体系应该能自然 build 出以下经典武侠幻想：

- 武僧 / 隐世神僧
- 独臂剑侠
- 破戒酒僧
- 毒医圣手
- 琴魔
- 白衣琴医
- 神射侠盗
- 机关奇人
- 黑衣刺客
- 铁枪护法
- 江湖快剑
- 血刀狂客
- 奇门术士
- 飞针判官
- 边塞猎手
- 阵前军师

这说明八大流派不是在压缩幻想，而是在提供可组合的构筑骨架。

## 10. 尚未解决的问题

`待定`

1. **24 个传承的具体技能结构**
- 当前只有方向，没有展开为代表技能、反应、终局能力。

2. **经脉槽 / 运功位系统**
- 已确认需要存在，但尚未设计容量、成长、装配约束。

3. **装备熟练系统**
- 已确认“所有人可用基础装备，主修决定完整机制”。
- 但熟练层级、武器标签、回收规则仍未写。

4. **投射与投掷的完整规则**
- 射艺旁修方向已经确定。
- 但投掷武器、回收武器、投药、远程触发的具体规则仍未展开。

5. **轻功系统**
- 已明确对武侠感很重要。
- 但还未形成正式规则层。

6. **状态系统**
- 已讨论过封脉、内伤、中毒、失衡、心乱等方向。
- 但尚未定状态列表和相互关系。

7. **低魔表现边界**
- 方向已确定。
- 但仍需后续在具体技能与美术表现里严格执行。

8. **奇门中的“香术”是否独立成分支**
- 当前并入阵法 / 符禁 / 机关的蓝图中。
- 是否未来替代机关或作为额外拓展，尚未决定。

9. **射艺的“猎踪”是否加入轻量兽伴**
- 当前只是构想，尚未确认。

10. **内功/心法层**
- 已多次提到，这很可能是下一层设计重点。
- 但尚未正式进入设计文档。

## 11. 下一步建议

`已确定`

后续最合理的推进顺序：

1. 先把 16 个优先传承逐个展开为：
   - 核心循环
   - 代表技能 3 个
   - 主修强化
   - 旁修接口
   - 克制关系

2. 再设计：
   - 经脉槽 / 运功位
   - 装备熟练与投掷规则
   - 状态系统

3. 最后再进入：
   - 内功/心法层
   - 典型 build 预设
   - NPC / 队友 archetype
