# GameW 剧情资产包 v0.3

本资产包把《山水照影录》整理成可持续扩写的剧情圣经、任务大纲、分支表、剧本样例和网站内容结构。

## 设计原则

1. **低魔武侠 CRPG**：剧情、任务和场景必须服务武侠构筑、战术站位、流派表达和江湖选择。
2. **成熟 CRPG 结构拖底**：学习三章结构、强队友、起源角色、营地戏、多解任务、城市总清算、特殊黑暗起源等结构，但不复制任何既有作品的具体剧情、角色、任务或世界观。
3. **网站资产优先**：所有设定拆成可独立页面化的条目，例如章节页、阵营页、人物页、任务页、故事页、分支节点页。
4. **可分支叙事**：每个主线任务记录入口条件、关键选择、后果变量、后续回收位置。
5. **可扩写**：正文定义 canon 框架、故事方向、变量接口和扩展位。

## 命名规范

### 任务 ID

```text
A{章数}-M{主线编号}
A{章数}-S{支线编号}
A{章数}-C{队友任务编号}
A{章数}-D{无名煞任务编号}
```

示例：

- `A1-M01`：第一章主线 01。
- `A2-S06`：第二章支线 06。
- `A3-C05`：第三章队友终局任务 05。
- `A3-D01`：第三章无名煞专属任务。

### 变量 ID

```text
A{章数}_{区域或任务}_{变量名}
COMP_{队友名拼音或英文}_{变量名}
FACTION_{阵营名}_{变量名}
DARK_{无名煞变量名}
ENDING_{结局变量名}
```

示例：

- `A1_SHANSHUI_STATE`
- `A2_STONE_CAVE_TRUTH`
- `COMP_SANG_TRUST`
- `FACTION_JIWUSI_REP`
- `DARK_BODYCOUNT`
