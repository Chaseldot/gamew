# 00 叙事生产原则

状态：active draft
日期：2026-04-26

## 1. 顶级虚构文学作家的视角

### 1.1 设定必须产生人物压力

设定不是百科。设定只有在迫使人物选择时才有叙事价值。

对 GameW 来说，“照影牒针”不是一个酷概念，而是一套压力系统：

- 它让玩家必须处理身体危机；
- 它让队友暴露旧伤和立场；
- 它让官府、医脉、江湖、照影局都拥有看似合理的行动理由；
- 它把“预防未来祸端是否正当”变成可反复测试的问题。

每条世界观设定都应回答：

| 问题 | 合格标准 |
|---|---|
| 它压迫谁？ | 至少压迫一个核心角色、阵营或玩家选择。 |
| 它诱惑谁？ | 至少给一个角色带来短期利益。 |
| 它伤害谁？ | 至少制造一个可被玩家看见的代价。 |
| 它能变成任务吗？ | 能生成调查、谈判、战斗、潜入、审判或救治目标。 |

### 1.2 人物不是履历，而是矛盾

角色设计不应从“他是谁、来自哪里、学什么武功”开始，而应从矛盾开始。

推荐格式：

```text
角色相信什么？
这个信念从哪里来？
剧情怎样证明这个信念有用？
剧情怎样证明这个信念有害？
玩家能怎样改变、确认或摧毁这个信念？
```

### 1.3 文学质感来自具体场景，不来自设定堆叠

武侠味不是靠名词密度堆出来的。它来自：

- 人在具体处境里的取舍；
- 话语背后的礼、义、债、仇、面子和规矩；
- 地点对行动的限制；
- 武功、门派、官法、江湖规矩之间的摩擦。

AI 生成文本时，必须先给它“处境”和“压力”，再要求它写风格。

## 2. 资深编剧的视角

### 2.1 结构不是剧情流水账

三幕结构在 CRPG 中仍然有用，但它不应规定玩家每一步怎么走。它应规定玩家必须经历的认知转折。

GameW 的三章应分别承担：

| 章节 | 玩家认知转折 |
|---|---|
| 第一章《封境》 | 这不是普通逃亡，而是有人在用照影牒针操控局面。 |
| 第二章《黄沙照影》 | 牒针不是个案，而是一套江湖治理系统。 |
| 第三章《司命》 | 玩家不只是在反抗系统，也必须决定系统是否被摧毁、保留或改造。 |

### 2.2 Checkpoint 是认知点，不是唯一剧情结果

Checkpoint 不应写成“玩家必须救下某人”。更成熟的写法是：

```text
无论玩家怎样行动，本章结束前必须知道：
- 照影牒针能记录并诱导武人行为；
- 至少一个善意组织参与了牒针技术；
- 至少一个敌对角色有合理动机；
- 玩家选择已经改变某个地区的状态。
```

### 2.3 每个任务都要有戏剧问题

任务目标是“做什么”，戏剧问题是“为什么这件事值得被写”。

弱任务：

```text
去龙王庙取牒钥。
```

强任务：

```text
当取走牒钥会降低追查难度，但可能让水闸失控时，玩家还要不要追凶？
```

## 3. CRPG 从业者的视角

### 3.1 母版是任务网络，不是小说

小说是单线路径。CRPG 是状态机、任务网络和角色反应系统。

成熟生产顺序应是：

```text
主题 -> 世界压力 -> 章节 checkpoint -> 任务包 -> 变量表 -> 场景卡 -> 对白
```

### 3.2 分支要贵，回收要明确

不是每个选择都值得成为大分支。一个选择如果不能改变以下任一项，就不应被包装成重大选择：

- 任务路径；
- 资源；
- 阵营态度；
- 队友信任；
- 地区状态；
- 后续证词；
- 终局选项；
- 战斗或潜入条件；
- 玩家对真相的理解。

### 3.3 失败必须推进

失败不是简单关门。失败应把玩家推入更糟但仍可玩的局面：

- 被通缉；
- 证据缺失；
- 队友质疑；
- 价格上涨；
- NPC 死亡；
- 地图封锁；
- 敌人提前布防；
- 后续少一个和平入口，但多一个危险捷径。

### 3.4 每条路径都要有制作成本意识

成熟 CRPG 写作必须随时问：

| 问题 | 意义 |
|---|---|
| 这个分支需要新地图吗？ | 新地图成本最高。 |
| 是否只是对白差异？ | 成本低，适合大量角色反应。 |
| 是否改变战斗布置？ | 中等成本，适合重要选择。 |
| 是否改变后续任务入口？ | 高价值，适合章节级选择。 |
| 是否需要新动画或演出？ | 高成本，只留给关键场景。 |

## 4. GameW 的执行原则

1. 先写可玩的叙事骨架，再写小说化文本。
2. 每个重要任务至少提供武力、系统、角色三类路径。
3. 每个起源角色必须改变任务视角，而不是只改开场台词。
4. 无名煞不能只是坏人按钮，必须同时提供诱惑、抵抗、利用和后果。
5. 所有章节变量都必须承诺至少一次后续回收。
6. AI 可以扩写，但不能替代主创判断 canon。
