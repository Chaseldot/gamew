# 03 场景卡模板

状态：active draft
日期：2026-04-26
用途：把任务中的关键节点拆成可写对白、旁白、检定文本和队友反应的最小创作单元。

## 使用规则

不要跳过任务包直接写场景卡。场景卡必须来自已定义的任务目标、戏剧问题、变量和后果。

## 场景卡

```text
场景编号：
场景名：
所属任务：
章节：
地点：
场景类型：入口 / 调查 / 对质 / 战斗前 / 战斗后 / 失败推进 / 营地回响 / 结算
当前状态：outline / draft / review / canon
```

## 1. 场景目的

这个场景在玩家体验中承担什么功能？

可选目的：

- 建立目标；
- 揭示代价；
- 提供选择；
- 改变关系；
- 触发战斗；
- 回收变量；
- 暴露真相；
- 推进失败局面。

## 2. 场景进入条件

| 条件 | 值 | 影响 |
|---|---|---|
| 必需变量 | `A1_*` | 决定是否出现。 |
| 可选变量 | `DARK_ORIGIN_*` | 改变对白或选项。 |
| 队伍成员 | 角色名 | 开启插话或特殊解法。 |
| 起源主控 | 角色名 / 自定义 / 无名煞 | 改变视角。 |
| 任务状态 | before / during / after | 决定 NPC 信息量。 |

## 3. 冲突核心

```text
此刻谁想要什么？
谁阻止他？
玩家的选择会改变什么？
```

示例：

```text
桑芷想救牒针宿主，县衙想封锁证据，玩家必须决定先救人、先取证、还是利用混乱追踪牒使。
```

## 4. 角色立场

| 角色 | 公开说法 | 真正压力 | 不能说出口的事 |
|---|---|---|---|
| NPC / 队友 | 他会怎样解释自己 | 他怕失去什么 | 可用于潜台词 |

## 5. 玩家选项

| 选项类型 | 玩家意图 | 文本要求 | 后果 |
|---|---|---|---|
| 同情 | 救人、保护弱者 | 不要圣母化 | 获得信任但耗时 |
| 功利 | 追线索、拿资源 | 不要写成纯恶 | 获得效率但伤关系 |
| 法理 | 审问、交官、公开证据 | 体现规则意识 | 获得官方入口或制造官府风险 |
| 江湖 | 人情、义气、门规、比武 | 体现武侠社会逻辑 | 获得江湖支持或结仇 |
| 黑暗 | 灭证、背叛、威胁、顺煞 | 必须有诱惑和代价 | 快速解决但写入长期风险 |

## 6. 检定与系统解

| 能力 / 系统 | 可发现什么 | 可改变什么 | 失败后果 |
|---|---|---|---|
| 药师 | 病因、药引、毒性 | 救治、压制、伪装药性 | 误判或副作用 |
| 奇门 | 机关、符禁、阵眼 | 拆除、改造、反制 | 触发警报 |
| 音律 | 铃声、错拍、情绪诱导 | 稳心、扰阵、识别暗号 | 暴露或受控 |
| 影踪 | 暗门、偷听、藏物 | 潜入、偷窃、换证 | 被识破 |
| 审案 / 话术 | 证词矛盾、心理破绽 | 对质、说服、威慑 | NPC 转为敌对 |

## 7. 队友插话

| 队友 | 触发条件 | 插话作用 | 态度变化 |
|---|---|---|---|
| 队友名 | 条件 | 提供信息 / 质疑 / 支持 / 警告 / 争执 | trust + / trust - |

规则：

- 插话必须体现立场；
- 插话不要重复 NPC 已说的信息；
- 争执应来自价值冲突，不是吵闹装饰；
- 未出战队友可在营地回响中补反应。

## 8. 无名煞处理

| 选项 | 场景表现 | 短期收益 | 长期代价 |
|---|---|---|---|
| 顺煞 | 直觉给出最快杀法 | 快速清除目标 | bodycount 上升，队友恐惧 |
| 压煞 | 玩家抵抗杀意 | 保留证人和自我 | 检定更难或承受痛苦 |
| 引煞 | 假装失控诱导暗号 | 暴露幕后命令 | 失败可能真伤人 |
| 换煞 | 把杀意转向更大目标 | 改变战局 | 后果不可控 |

## 9. 文本产出清单

| 文本 | 是否需要 | 备注 |
|---|---|---|
| 场景入口旁白 | yes / no | 只写玩家能感知的信息。 |
| NPC 开场对白 | yes / no | 带目标和压力。 |
| 玩家选项 | yes / no | 清楚表达意图。 |
| 检定成功文本 | yes / no | 说明能力如何改变局面。 |
| 检定失败文本 | yes / no | 推进新局面。 |
| 队友插话 | yes / no | 体现立场。 |
| 战斗前喊话 | yes / no | 短，不解释设定。 |
| 战斗后结算 | yes / no | 写入变量和后果。 |
| 日志更新 | yes / no | 明确下一步。 |

## 10. 变量影响

| 玩家选择 / 结果 | 写入变量 | 即时反馈 | 后续回收 |
|---|---|---|---|
| 选择 A | `A1_*` | NPC / 环境 / 队友反馈 | 后续任务或终局 |

## 11. 场景审稿清单

- [ ] 场景目的明确。
- [ ] 玩家知道自己为什么在这里。
- [ ] NPC 有自己的目标。
- [ ] 选择不是假选择。
- [ ] 检定不是简单开门，而是改变局面。
- [ ] 失败文本推进新局面。
- [ ] 队友插话体现立场。
- [ ] 无名煞选项不是单纯坏人按钮。
- [ ] 文本没有提前剧透系统真相。
- [ ] 场景写入或回收的变量明确。
