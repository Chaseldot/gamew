## Existing Project Context

- GameW 当前定位是低魔武侠 CRPG。
- 现有 active 文档已经包含 `docs/story/00-story-bible.md` 和 `docs/story/02-act1-branch-matrix.md`。
- 叙事核心已经明确：照影牒针、起源角色、无名煞、三章结构、多解任务、变量回收。
- 当前最需要的不是重新写小说，而是建立可持续的叙事生产管线。

## Method Findings

- 小说适合用作语气、人物质感和关键场景样章，不适合作为多分支 CRPG 的剧情母版。
- 成熟 CRPG 叙事生产需要把创作拆成多层资产：故事圣经、章节骨架、任务包、场景卡、对白、变量表、回收表。
- AI 最适合用于扩展路径、生成变体、审计一致性、补队友反应和产出对白初稿；不适合作为无约束主创。

## A1-M01 Sample Findings

- A1-M01 适合作为样板，因为它同时包含救人、搜证、追踪、自首、灭口和无名煞诱导。
- `A1_FIRST_TIE_KEY` 在 A1-M01 阶段只能作为“牒钥线索开启”，不宜直接写入正式枚举值；正式取值仍应在 A1-M04 结算。
- 开场无队友不代表没有队友反应，应通过酒楼、医馆、牢城和营地回响回收。
- 后续需要明确 A1-M01 的行动预算：救人、搜证、追踪不应无成本全拿满。
