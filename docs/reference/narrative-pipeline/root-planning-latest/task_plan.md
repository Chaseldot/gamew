## 已做决策

| 决策 | 原因 |
|---|---|
| 先做第一章样板 | 从小到大，由点及面；第一章可验证任务、队友、阵营、变量和网站映射格式。 |
| 本切片只做文本 | 用户要求网站实现前先有足够文字资源并检验合理性。 |
| BG3 只作结构参考 | 保留高自由度、队友线、四人小队、营地戏、起源角色和三幕回收，但不照搬具体表达。 |
| 图片最后处理 | 概念 / 场景 / 战斗图后续按稳定文本重生，避免图先行导致设定反复。 |
| 网站后续改多子页面 | 首页只做门户，剧情、任务、阵营、队友、系统和美术进入对应子页面。 |
