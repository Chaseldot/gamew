# GameW 展示站设计

状态：approved
日期：2026-04-26
范围：为当前 GameW 工作成果搭建一个可本地浏览的网站展示面。

## 目标

建立一个“沉浸式游戏官网 + 结构化资料库”一体站，用来展示 GameW 当前已经形成的系统、剧情、设定和美术资源。

网站第一屏承担官网质感：全屏主视觉、清晰 IP 信号、简短定位和入口导航。主体内容承担资料库能力：系统规则、等级、八大流派、传承、队友、阵营、任务、多解规则、章节剧情和艺术资源都能快速浏览。

## 美术方向

沿用现有图片的写实电影感：低魔武侠、复杂建筑层次、强场景纵深、自然雾气、湿润材质、烟尘、火光和大量可读细节。风格不要切成二次元或纯国风插画。

明暗原则按场景走：

| 场景 | 明暗 |
|---|---|
| 山水县、水乡、药谷、山门 | 明快但有危机感，雨后湿润、青绿、灰瓦和暖灯 |
| 疫村、破庙、黑市、断因房 | 偏暗，低照度、冷色阴影、少量火光 |
| 槐安古道、黄沙、石窟 | 明亮高反差，风沙、岩壁、远景和金色天光 |
| 照影城、武籍区、母局 | 压迫、密集、暗金、朱墙、黑瓦、铜铃和冷光 |

## 图片规格

| 类型 | 规格 |
|---|---|
| 美术概念设计图 | 3840x2160，4K landscape，high quality |
| 场景展示图 | 3840x2160，4K landscape，high quality |
| 战斗展示图 | 3840x2160，4K landscape，high quality |
| 首屏 Hero | 使用 3840x2160 横版图，可压缩为浏览器友好格式 |
| 人物形象、logo、图标、UI 装饰 | 按用途确定，允许非 4K |

当前环境没有 `OPENAI_API_KEY`，所以不能使用 `gpt-image` CLI 的精确 API 路径。实施时必须把探索期图片仅作为风格参照，按 `script.md` 的具体剧情、任务和地点重新生成站点资源；概念 / 场景 / 战斗图仍统一整理为 3840x2160 浏览器资源。若后续设置了 `OPENAI_API_KEY`，可按 `gpt-image` skill 的 `3840x2160 --quality high` 规则重生关键图。

## 技术设计

使用 `site/` 下的静态站点，不引入复杂前端框架。原因：

- 仓库当前是文档与资源仓库，不是现成应用；
- 静态 HTML / CSS / JS 足以实现资料筛选、tabs、图库和 lightbox；
- 可以直接打开，也可以用本地静态服务器验收；
- 不需要网络依赖，减少对现有脏工作区的干扰。

核心文件：

| 文件 | 用途 |
|---|---|
| `site/index.html` | 页面结构和 SEO 基础 |
| `site/styles.css` | 响应式视觉系统 |
| `site/data.js` | 系统、剧情、人物、任务和图库数据 |
| `site/app.js` | tabs、筛选、渲染和图库交互 |
| `site/tests/site-content.test.mjs` | 数据、页面引用和 4K 图片规格验证 |
| `site/assets/art/` | 展示站使用的图片资源 |
| `site/assets/brand/` | logo、favicon、品牌小资源 |

## 验收标准

- 本地站点可打开，首屏是实际游戏展示，不是营销占位页。
- 系统区能展示 9 级规则、8 流派、17 传承。
- 剧情区能展示三章结构、章节目标、核心地点与多结局导向。
- 人物区能展示八名队友和无名煞。
- 阵营区能展示六大阵营的价值与阴影。
- 任务区能展示主线任务、样例任务和多解标签。
- 艺术馆有丰富配图，概念 / 场景 / 战斗类图片均为 3840x2160。
- 移动端与桌面端文本不溢出、不重叠。
- 自动测试、静态资源检查和本地浏览器截图验收通过。
