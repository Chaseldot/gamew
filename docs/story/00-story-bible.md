# 《山水照影录》故事圣经

状态：active draft
日期：2026-04-26
用途：记录 GameW 剧情资产的全局规则。与旧探索稿冲突时，以 `script.md` 和本目录后续章节文档为当前工作依据。

## 1. 核心定位

《山水照影录》是一部低魔武侠 CRPG。玩家在山水县境醒来，腕脉被植入 **照影牒针**，必须在封境、水患、疫病、山寨、官府和照影局的夹击中活下去，最终进入照影城，决定天下武人是否该被记录、预测和提前处置。

本项目使用 BG3 的成熟结构作为兜底，但不搬运具体内容：

| 结构参考 | GameW 原创转化 |
|---|---|
| 体内共同危机 | 照影牒针：药、符、音、机、档案共同构成的低魔禁制。 |
| 起源角色 | 核心队友可作为起源角色，自定义主角也可加入同一危机。 |
| 邪念式主角 | 无名煞：照影局断因房调校出的“剧情终止器”。 |
| 四人小队 | 主角 / 起源主控 + 三名队友，其他队友留营地。 |
| 营地戏 | 夜营、驿站、船坞、下坊藏身处，承载队友、牒针、阵营来访。 |
| 多解任务 | 战斗、潜入、谈判、审案、偷窃、医毒、机关、音律、奇门、队友和无名煞解法。 |
| 三幕回收 | 第一章封境牺牲、第二章真相解释权、第三章城市压力与母局裁决。 |

## 2. 三章结构

| 章节 | 地点 | 主题 | 政治问题 | 终局 | 章节作用 |
|---|---|---|---|---|---|
| 第一章《封境》 | 山水县境 | 你以为自己只是要活着离开。 | 局部崩坏时，谁有权决定牺牲？ | 龙王庙水闸 | 建立牒针危机、队友入队、阵营雏形和第一批后果变量。 |
| 第二章《黄沙照影》 | 槐安古道、龙门驿、石窟、照影楼坞 | 这不是你的病，而是整个江湖的病。 | 真相出现后，谁有权解释真相？ | 照影楼坞 | 把第一章证据推入公开政治，决定入城态势。 |
| 第三章《司命》 | 照影城 | 所有人都想书写江湖，最后轮到你决定。 | 掌握母局后，谁有权书写未来？ | 摘星楼与地下照影母局 | 通过城市压力回收前两章选择，决定母局、阵营和队友终局。 |

## 3. 世界核心：照影牒针

照影牒针不是神术，也不是西幻寄生物。它由五类技术共同构成：

| 构成 | 关联流派 | 叙事效果 |
|---|---|---|
| 牒针 | 药师 / 蛊毒 | 植入腕脉、命门或玉枕，影响痛觉、记忆、梦境和杀意。 |
| 影纹 | 奇门 / 符禁 | 记录气机、招式习惯、情绪波动和人际牵连。 |
| 照影铃 | 音律 / 机括 | 远距离触发错拍、幻听、昏厥、狂乱或短暂共感。 |
| 牒录 | 武籍 / 档案 | 记录武人过往、救人、杀人、风险预判和可控等级。 |
| 牒钥 | 阵法 / 机关 | 控制、读取或延迟牒针发作的关键物。 |

公开用途是治疗战后疯症、控制走火入魔者、审讯危险武人和追踪重犯；真实用途是记录、预测、诱导，并在必要时提前清除被判定为“未来祸端”的武人。

## 4. 政治阵营结构

本作不使用六个平级阵营。公开争夺江湖秩序的是 **缉武司** 与 **同尘盟**；**照影局** 是寄生暗线，潜伏在制度、医术、机关和黑市背后，第三章才完整显形。慈心医脉、百工坞和鬼市是关键中间势力，不是独立政治终点。

| 层级 | 势力 | 叙事功能 |
|---|---|---|
| 核心政治轴 | 缉武司 | 国家秩序、武人入册、合法暴力、预防治安。 |
| 核心政治轴 | 同尘盟 | 江湖自治、门派义气、反抗滥权、复仇风险。 |
| 寄生暗线 | 照影局 | 预测、诱导、提前处置；隐藏在多方制度和技术接口背后。 |
| 关键中间势力 | 慈心医脉 | 掌握牒针药理、治疗合法性和医脉罪证。 |
| 关键中间势力 | 百工坞 | 掌握铃阵硬件、机关图和母局改造可能。 |
| 关键中间势力 | 鬼市 | 掌握身份、证词、牒录交易、地下入口和灭证渠道。 |
| 被治理者 | 百姓、边地部族、商队、牒针宿主 | 检验每种政治方案的真实代价。 |

阵营必须写出承诺、罪责、资源、代表人物和失控形态。支持缉武司不等于支持照影母局；支持同尘盟不等于支持暴动清算；利用照影局也不等于必须继承司命。

| 阵营 | 温和 / 正当面 | 激进 / 阴影面 |
|---|---|---|
| 缉武司 | 裴照：公开律法、可质询、可翻案。 | 沈照微：预防处置，把风险当作准罪名。 |
| 同尘盟 | 楚横山：江湖自救、护乡护路。 | 陆行舟：清算革命，把复仇写成新秩序。 |
| 照影局 | 白微尘：少数牺牲，避免更大灾祸。 | 司命：风险账本，提前剪断所有祸端。 |

## 5. 四人小队与营地规则

### 5.1 出战上限

玩家当前出战队伍上限为四人：

- 自定义主角 + 三名队友；
- 起源角色主控 + 三名队友；
- 无名煞主控 + 三名队友。

队友不是背景 NPC。被招募后进入可战斗池，有等级、流派、传承、个人线、营地戏、阵营态度和终局分歧。未出战队友留在营地或阶段据点，仍可触发个人对话、队友争执、阵营来访和部分远程支援。

### 5.2 换队原则

- 关键区域入口允许换队；
- 营地长休允许换队；
- 队友个人任务会提示推荐携带角色；
- 某些任务允许未出战队友在营地提供准备项，例如药、机关、情报、伪造文书或护心调。

### 5.3 营地形态

| 章节 | 营地形态 |
|---|---|
| 第一章 | 破庙、河滩、山寨偏院、废书院。 |
| 第二章 | 黄沙驿站、商队营火、石窟外窟、百工坞客舍。 |
| 第三章 | 下坊藏身处、水巷船屋、鬼市密室、缉武司客馆。 |

营地承担五类内容：牒针梦境、队友冲突、阵营来访、个人任务触发、无名煞诱发。

## 6. 起源角色与队友池

八名核心队友都可作为起源角色候选。每个起源必须改变玩家进入任务的视角，而不只是改开场台词。

| 队友 | 流派 / 传承 | 第一入场 | 叙事矛盾 | 战斗表达 |
|---|---|---|---|---|
| 谢停云 | 游锋:截云 | 山水县酒楼 | 曾在决斗中杀错人，如今害怕再拔剑。 | 读招、破招、单体压制。 |
| 桑芷 | 药师:济世 | 疫村医棚 | 想救人，但师门参与过牒针药引。 | 救急、解毒、牒针压制。 |
| 唐小砚 | 奇门:机括 | 龙王庙水闸 / 百工坞 | 厌恶机关只被用于暗杀和控制。 | 机关、分洪、战场装置。 |
| 任无踪 | 影踪:绝影 | 清河渡鬼市 | 偷了牒钥，被三方追杀。 | 潜入、偷窃、脱战、密道。 |
| 柳听弦 | 音律:错律 | 龙王庙戏台 | 以琴复仇，但每次复仇都更像仇人。 | 扰拍、破铃、控场。 |
| 韩霜铁 | 破军:护法 | 旧镖道 | 护送过牒针试验者，后来全死了。 | 守线、护卫、冲阵。 |
| 裴照 | 拳掌:擒龙 | 县衙牢城 | 相信律法，但律法正在被照影局利用。 | 擒拿、缴械、审讯战。 |
| 霍青鸢 | 射艺:追风 | 槐安古道 | 部族被边军、缉武司和江湖势力当棋子。 | 远射、标记、机动追击。 |

## 7. 无名煞规则

无名煞是可选特殊起源。它不是恶魔附身，而是照影局断因房的长期调校结果。无名煞看到某些人时，会本能地知道怎样最快杀死他，因为这些人可能是照影局档案中被标记的“未来祸端”。

| 选择 | 设计作用 | 代价 |
|---|---|---|
| 顺煞 | 快速解决目标，跳过谈判或审案，取得短期利益。 | 队友恐惧、证据断裂、照影局认同上升。 |
| 压煞 | 抵抗杀意，保留目标，开启救赎、信息和信任。 | 检定更难，战斗或谈判压力更高。 |
| 引煞 | 假装失控，引诱幕后命令、铃声或断因暗号暴露。 | 失败时会真的伤人，队友信任受损。 |
| 换煞 | 把杀意转向更大的恶人或更关键目标。 | 可能造成不可控后果，改变任务局势。 |

无名煞不能只是“坏人按钮”。每次触发都要同时提供诱惑、抵抗方法、可利用信息和长期后果。

## 8. 任务多解标准

### 8.1 重要任务最低要求

每个主线任务、队友任务和大型支线至少提供三类路径：

1. **武力路径**：正面战斗、威慑、夺取、强闯。
2. **系统路径**：药师、奇门、音律、影踪、审案、话术、伪装、偷窃、机关或环境。
3. **角色路径**：队友、起源角色、无名煞、阵营关系或前置支线。

每个主线任务还必须回答一个政治问题。玩家不是只在选择“怎么过关”，而是在改变真相归属、阵营解释权、城市压力或母局裁决条件。

### 8.2 失败推进

失败不是简单关门。失败必须推进到新的局面：

- 被通缉；
- 封路升级；
- 阵营涨价；
- 队友信任下降；
- 证据缺失；
- 关键 NPC 死亡；
- 灾害扩大；
- 后续章节少一种入口，但多一种危险捷径。

### 8.3 检定表达

检定服务剧情，不用在文档阶段写具体数值。记录“哪类能力可解”即可：

- 药师：诊断、救治、药毒、牒针压制；
- 奇门：机关、阵法、符禁、地形改造；
- 音律：错拍、护心、识铃、扰阵；
- 影踪：潜入、偷窃、偷听、伪装；
- 游锋 / 破军 / 拳掌 / 射艺：战斗、威慑、决斗、护送、缴械、远程支援。

## 9. 变量命名与后果回收

变量按章节前缀管理：

```text
A1_* = 第一章山水县状态
A2_* = 第二章槐安古道证据、真相和盟会状态
A3_* = 第三章照影城压力、审判和母局状态
DARK_ORIGIN_* = 无名煞跨章状态
```

第一章变量必须至少影响以下任一后续内容：

- 第二章入场资源；
- 第三章证词；
- 阵营态度；
- 队友个人线；
- 终局母局选项；
- 无名煞身份揭示。

第二章变量必须至少记录证据归属、真相解释框架、照影局暴露程度和楼坞结算。第三章变量必须至少记录入城方式、城市压力、大审结果、母局权限和照影局是否公开显形。

## 10. 网站与图片顺序

当前制作顺序固定为：

1. 文本资产；
2. 文本一致性检查；
3. 网站多子页面重构；
4. 根据稳定文本生成或重生图片；
5. 浏览器与视觉验收。

图片要求：

- 美术概念设计图、场景展示、战斗展示：`3840x2160`，4K landscape，high quality；
- 人物形象、logo、阵营图标、UI 小图：按用途确定；
- 文件命名使用中文，按章节和用途统一；
- 探索期图片只能作为风格参考，不能作为最终展示资源直接复用。
