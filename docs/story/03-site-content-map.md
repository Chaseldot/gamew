# GameW 网站内容映射

状态：active draft
日期：2026-04-26
用途：把剧情与系统文本资产映射到未来多子页面网站。当前只做内容设计，不在本切片改站点代码或生成图片。

## 1. 改版原则

现有 `site/index.html` 是单页展示站。后续正式展示面应改为多子页面：

- 首页只做门户、主视觉、最新内容和导航；
- 系统、世界、章节、任务、队友、阵营、美术分别进入子页面；
- 第一章《封境》先作为完整样板上线，第二章和第三章后续滚动扩展；
- 图片生成必须等文本稳定后执行，避免场景和设定反复导致返工。

## 3. 首页 `index.html`

### 目标

首页不再承载所有资料。它只需要让用户在第一屏理解：

- 这是低魔武侠 CRPG；
- 核心危机是照影牒针；
- 当前可看的完整内容样板是第一章《封境》；
- 可以进入系统、世界、剧情、任务、队友、阵营和美术子页面。

### 推荐模块

| 模块 | 内容 | 交互 |
|---|---|---|
| Hero | 游戏名、短句、主视觉、进入第一章按钮 | 主按钮跳 `story-act1.html`，次按钮跳 `systems.html`。 |
| Current Slice | 第一章《封境》完成度 | 显示章节、任务、队友、分支数量。 |
| Navigation Tiles | 世界、系统、剧情、任务、队友、阵营、美术 | 每个 tile 跳子页面。 |
| Latest Art | 后续美术阶段选 3-6 张 | 只展示最终资源，不混探索期图。 |

## 10. 美术页 `art.html`

### 内容来源

- 稳定后的章节文本；
- 后续 `site/assets/prompts/*.md`；
- 后续最终图片目录。

### 分类

| 分类 | 规格 |
|---|---|
| 概念设计 | 3840x2160，high quality。 |
| 场景展示 | 3840x2160，high quality。 |
| 战斗展示 | 3840x2160，high quality。 |
| 人物形象 | 按页面用途，优先保持统一风格。 |
| 阵营徽记 | 按 UI 用途，可透明背景。 |
| 道具 / 牒针 / 牒钥 | 按展示用途，可做特写。 |

### 命名规则

图片文件名统一中文，建议：

```text
章节-类型-内容.png
```

示例：

```text
第一章-场景-清河渡雨夜醒牒.png
第一章-战斗-龙王庙水闸阵眼.png
第一章-人物-桑芷疫村医棚.png
第二章-场景-槐安古道风沙驿站.png
第三章-场景-照影城武籍大审.png
```

### 延后规则

本轮不生成新图。等第一章文本验收后，再基于最终文档写 prompts。概念 / 场景 / 战斗展示统一 3840x2160；人物、logo、阵营、UI 资源按用途即可。

## 11. 后续实施建议

多子页面改版建议分三步：

1. 先把现有 `site/data.js` 拆成可复用内容模块；
2. 再创建 `world.html`、`systems.html`、`story-act1.html`、`quests.html`、`companions.html`、`factions.html`、`art.html`；
3. 最后补图片 manifest、中文文件名规范、浏览器验收和移动端截图。

第一版多页面不需要把所有章节做完整。只要第一章《封境》作为完整样板成立，第二章和第三章可以先用概要页承接。
