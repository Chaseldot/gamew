- 结论口径：
  - **Pass** = 现有主修 / 传承 / 旁修 / 表现标签已足以解释该 fantasy，且不需要回到职业根节点或出身/身份层。

  - **Block** = 当前层级里仍不存在必要构筑接口，或必须依赖 deferred 规则才能成立。
