# History

本目录集中存放非 canon 的历史和参考材料。

这些内容可以作为写作蓝本、探索来源、旧站点依据或过程档案，但不能直接约束后续开发。需要重新生效时，必须先提炼并写入 `canon/`。

## Contents

| 路径 | 内容 |
|---|---|
| `story-blueprints/` | 第一章细稿、旧 story bible、旧 script。 |
| `design-blueprints/` | 游戏介绍、幻想库等非 active 设计参考。 |
| `exploratory-assets/` | 探索期图片和早期美术资产。 |
| `plans/` | 旧计划文档。 |
| `narrative-pipeline/` | 叙事生产流程草案与根目录 planning 工作记忆。 |
| `archive/` | 历史归档。 |
