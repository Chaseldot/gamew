# 00 构筑系统总览

状态：active 重构基线
来源：从 `docs/archive/2026-04-25-pre-workflow-reset/` 中提炼重写
用途：定义当前构筑系统的基础，不再依赖归档报告作为日常入口。

## 设计目标

GameW 的构筑系统服务于一个**低魔武侠 CRPG**。它要让玩家自然拼出熟悉的武侠幻想，但不能把这些幻想直接做成固定职业。

当前构筑哲学是：**主修主导型**。

- 主修是角色的战斗身份核心。
- 传承是主修内部的专精方向。
- 精修表示继续练深主修。
- 旁修表示接入副武学。
- 武僧、琴魔、毒医、侠盗、游侠等角色形象是组合结果，不是系统根节点。

## 固定基线

当前可作为 active 基线的内容：

- 等级上限：12 级。
- 1 级：选择一个主修流派。
- 3 级：选择一个传承。
- 4 / 8 / 10 级：获得 3 个自由修习点。
- 11-12 级：进入传承终局 / 精修宗师技阶段。
- 角色只能有 1 个主修流派。
- 角色只能有 1 个传承。
- 角色总共有 3 个自由修习点。
- 自由修习点可以回投主修，形成精修。
- 自由修习点可以投向非主修流派，形成旁修。
- 最多旁修 2 个流派。
- 单个旁修流派最多投入 3 点。

最终的 loadout、经脉槽、运功位、装配矩阵、可携带技能数量等规则还没有完成。

## 构筑层级

| 层级 | 含义 | 当前状态 |
|---|---|---|
| 主修流派 | 角色的核心战斗语法、资源循环、动作骨架和战斗职责。 | 八大流派固定。 |
| 传承 | 主修内部的专精路线。 | 24 个当前版本可用，但未来仍可被测试驱动修订。 |
| 精修 | 将自由修习点回投主修。 | active 基线。 |
| 旁修 | 将自由修习点投入非主修流派。 | active 基线。 |
| 角色形象 | 玩家幻想或 NPC 表现，如武僧、琴魔、毒医、刺客。 | 作为表现层和测试输入启用。 |
| 出身 / 身份 | 属性加成、社会身份、门派关系、背景、权限和叙事钩子。 | 暂缓。 |
| Loadout / 经脉槽 | 构筑内容的最终携带、装配、运功或槽位系统。 | 暂缓，待设计。 |

## 通用模板

主修流派使用 5 项模板：

1. 基础职责一句话。
2. 主资源循环。
3. 三段式动作骨架：起手、推进、收束。
4. 纯主修终局落点。
5. 旁修影响范围 / 主修核心保留区 / 非目标。

传承使用 7 项模板：

1. 定位一句话。
2. 核心战斗幻想。
3. 核心循环。
4. 资源关系。
5. 代表动作 / 机制。
6. 边界定义。
7. 旁修影响面。

旁修使用统一的 1 / 2 / 3 点语法：

| 点数 | 含义 |
|---:|---|
| 1 | 入口：轻量接入、基础熟练、基础触发或探索 / 战斗接触。 |
| 2 | 接口：旁修收益开始与主修动作发生结构连接；可以影响资源流速，但不能改写资源规则。 |
| 3 | 小循环：形成副套路、副节奏或小收束；可以有完成感，但不能超过主修主体。 |

精修使用统一的 1 / 2 / 3 点语法：

| 点数 | 含义 |
|---:|---|
| 1 | 主资源上限、回收稳定性或起手顺滑度提升。 |
| 2 | 主修核心动作强化，循环容错增强。 |
| 3 | 宗师技强化或体系完成奖励。 |

## 暂缓接口协议

凡是跨到 loadout、经脉槽、运功位、装配矩阵或最终携带限制的内容，都必须明确标记为未完成。必要时使用以下占位符：

- `LOADOUT_INTERFACE_PENDING`
- `MERIDIAN_SLOT_COUNT_PENDING`
- `SLOT_PRESSURE_ASSUMPTION_ONLY`

允许的说法：

- 某个表达依赖未来 loadout 接口落地。
- 当前测试只是在槽位压力假设下验证不崩。
- 旁修未来可能占用经脉 / loadout 预算。

禁止的说法：

- 现在就定义最终槽位数量。
- 现在就定义最终装配矩阵。
- 让某个传承或旁修依赖未完成的槽位规则才能成立。
- 用一个过于宽松的未来槽位假设证明 build 成立。

## 核心红线

- 不得用角色形象名称重新引入固定职业。
- 不得让旁修补齐主修本体缺口。
- 不得让精修伪装成第二传承。
- 不得让传承身份依赖旁修或 loadout。
- 不得突破低魔武侠边界。
- 不得把奇门写成西幻施法者、把音律写成法术吟唱职业、把药师写成万能奶妈 / 万能 debuff 机。
- 不得用出身 / 身份解决当前战斗系统缺口。
