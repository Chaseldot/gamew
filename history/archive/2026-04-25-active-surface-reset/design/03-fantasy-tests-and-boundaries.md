# 03 幻想测试与边界

状态：active 重构基线
用途：保留有价值的武侠幻想回归测试、角色形象规则和硬边界，不携带旧 worker 报告过程。

## 测试原则

熟悉的武侠幻想应从**角色形象**进入系统，而不是作为职业进入系统。

每个幻想都应能写成：

```text
角色形象 = 主修流派 + 传承倾向 + 旁修工具 + 表现标签
```

如果一个幻想只能靠新增职业根、固定出身、未完成槽位规则或新行动经济系统成立，就应判为 revise 或 deferred。

## 角色形象规则

角色形象可以承载：

- 外观表现；
- 服饰、姿态、可见工具和武器展示；
- NPC 模板；
- 推荐 build 标签；
- 江湖称谓和传闻。

角色形象不能承载：

- 唯一职业规则；
- 不可替代的数值优势；
- 传承成立前提；
- 隐藏 loadout 规则；
- 用于补战斗身份缺口的出身 / 势力特权。

## Hybrid 可见道具规则

伞、扇、拂尘、手杖、藏刃、匣器、软绫、傀儡载体等可见道具，必须先声明主轴归属。

合法读法：

- **游锋归属**：道具是近身兵刃。开合、格拦、缠压、藏锋、抽刃都服务贴身压迫、锋势、断势、藏锋和追击。
- **奇门归属**：道具是器具 / 载体。开合、暗仓、挂符、触发、抛件都服务布置、诱敌、阵机、机关链或符禁。
- **射艺 / 影踪接口**：道具可补远端触发、隐蔽切入、揭示、换位或时机。

非法读法：

- 一件道具不能同时领取近身护身、连续远射、机关布置、藏器奇招和两套主循环。

当一个道具承担过多功能时，问题是归属失败，不是需要新增流派。

## 组织称谓与身份边界

丐帮、帮主、捕快、医谷、杀手楼、道门、门派弟子等名称，不是当前战斗职业。

它们未来可以支持：

- 剧情钩子；
- 势力关系；
- 声望；
- 初始资源；
- 推荐构筑；
- 对话与世界反应。

它们当前不能：

- 锁死唯一流派；
- 提供不可替代的战斗特权；
- 定义传承；
- 在战斗闭环缺失时让幻想通过测试。

## 评审词汇

| 结论 | 含义 |
|---|---|
| Pass | 当前系统可表达该幻想，且不触犯层级边界。 |
| Revise | 幻想接近成立，但文案、归属或旁修压力需要修正。 |
| Deferred | 幻想需要未来系统，不能补丁进当前层级。 |
| Block | 幻想破坏低魔边界、行动经济或主修主导构筑逻辑。 |

## 常见失败信号

- 幻想需要新增职业根。
- 某个旁修变成熟悉幻想的强制税。
- 一个可见道具同时承载多个主循环。
- 战斗同伴或傀儡在没有独立行动经济系统时进入战斗。
- 一个 build 只能在假设未来槽位很宽松时成立。
- 低魔武学表达滑向法术。
- 治疗、控制或布置流派变成全能最优。
