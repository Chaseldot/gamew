# 山水照影录 Canon Overview

## 0. 创作目标

《山水照影录》是 GameW 的第一部主线战役。目标是做一个 **低魔武侠 CRPG**：玩家在强分支、高自由度、多队友、多阵营、多结局的江湖世界中，用武侠流派和队伍关系解决问题。

本作采用成熟 CRPG 的结构拖底：

- 三章推进；
- 体内危机作为共同主线钩子；
- 队友可成为起源角色；
- 特殊黑暗起源提供高度差异化重玩；
- 第一章局部沙盒；
- 第二章危险旅途与中型阵营展开；
- 第三章大城市总清算；
- 任务多解；
- 阵营、队友、个人道德共同影响结局。

但所有具体世界观、人物、任务、桥段和剧本均为原创武侠语境，不复制任何既有西幻作品的具体内容。

---

# 1. 一句话设定

玩家在山水县境醒来，体内被植入名为 **照影牒针** 的低魔禁制。为了解除牒针、找回身份、决定自己是否仍然自由，玩家从水患与疫病交织的山水县境出发，穿越黄沙古道与千佛石窟，最终进入皇城脚下的照影城，决定天下武人的命运。

---

# 2. 核心主题

## 2.1 自由与秩序

江湖自由带来侠义，也带来私刑、门派仇杀和强者凌弱。朝廷秩序带来治安，也带来监控、入册、预防性处决。

玩家不是在“好人与坏人”之间选择，而是在以下问题中选择立场：

> 谁有资格决定一个尚未犯罪的人是否会成为祸端？

## 2.2 救人和控制的边界

牒针最初源自医术，用于治疗战后疯症、走火入魔和心神失控。后来它变成记录、审判、操控武人的工具。

问题不是技术本身是否邪恶，而是：

> 当救人的工具可以控制人时，谁来决定它的使用边界？

## 2.3 江湖债

本作所有主线都应有“债”的逻辑：

- 救命债；
- 杀人债；
- 门派债；
- 官府债；
- 技术债；
- 旧案债；
- 队友之间的信任债。

第三章照影城不是新故事，而是前两章所有债务的集中兑现。

# 3. 低魔武侠边界

本作可以出现奇门、符禁、音律、药师、机关、蛊毒、牒针、照影铃、纸人、傀儡、低魔幻觉等元素，但必须遵守以下边界。

| 项 | 允许 | 禁止或慎用 |
|---|---|---|
| 药师 | 救急、稳态、毒性、药性转移、牒针压制 | 无限复活、万能治疗、无代价净化一切 |
| 音律 | 稳心、鼓舞、扰拍、破铃、诱导节奏 | 大规模无媒介心控、无条件魅惑所有人 |
| 奇门 | 局部阵法、机关、符禁、改变地形优势 | 大范围法术轰炸、凭空传送、无媒介造物 |
| 影踪 | 潜入、暗杀、脱战、伪装、偷换证据 | 无视所有防守的万能潜行 |
| 牒针 | 影响记忆、梦境、痛觉、杀意、共感 | 完全剥夺玩家选择 |
| 照影局 | 情报、预测、诱导、操控 | 全知全能、永远正确 |

**关键规则：** 所有低魔能力必须有媒介、限制、代价和反制方法。

# 4. 核心禁物：照影牒针

## 4.1 定义

照影牒针是由药师、奇门、音律、符禁、机括共同发展出的禁制系统。它不是单一毒物，而是一套由身体植入、气机记录、音律触发、档案牵引组成的控制网络。

| 构成 | 来源 | 功能 |
|---|---|---|
| 牒针 | 药师 / 蛊毒 | 植入腕脉、命门或玉枕，影响梦境、痛觉、杀意、记忆。 |
| 影纹 | 奇门 / 符禁 | 在皮肤、经脉或气机上留下可被追踪的纹路。 |
| 照影铃 | 音律 / 机括 | 以特定频率触发牒针，引发错拍、幻听、昏厥或狂乱。 |
| 牒录 | 武籍 / 档案 | 记录宿主身份、招式、罪名、功绩、关系网和风险判词。 |
| 母局 | 阵法 / 机关 / 档案系统 | 汇总所有牒针数据，作为照影局的最终控制中枢。 |

## 4.2 起源

牒针最早不是武器，而是慈心医脉为了治疗战后疯症和走火入魔而研究出的“稳心针”。后来，照影局发现稳心针可以记录和干预武人的气机与选择，于是将其改造成牒针。

## 4.3 现状

大雍末年，缉武司以“武人入册”为名管理江湖，照影局在幕后把牒针、武籍、档案、铃阵和断因房结合成一套预防性审判系统。

---

# 5. 照影局简史

照影局并非大雍朝新建机构。它曾在不同朝代改名、断代、重组。

| 时代 | 名称 | 功能 |
|---|---|---|
| 前朝边乱时期 | 照壁旧院 | 在边塞石窟记录可能引发大乱的强人、宗师、军阀。 |
| 前朝末年 | 断因房 | 培养无名杀手，提前斩断被判定为“未来祸端”的人。 |
| 大雍初年 | 无相牒房 | 被开国皇权短暂收编，部分档案被销毁。 |
| 大雍中期 | 照影局 | 转入地下，借医脉、书院、工坊、鬼市延续技术。 |
| 大雍末年 | 照影局 + 缉武司 | 与官府合作，把古法现代化为牒针、武籍和照影母局。 |

石窟只揭开这一历史的一角。完整前史可留给前传。

# 6. 三章总览

## 第一章：《封境》

- **区域：** 山水县境。
- **视觉：** 雨夜、水患、疫村、县城、山寨、旧镖道、龙王庙水闸。
- **主题：** 活着离开。
- **冲突：** 县衙封境、疫病蔓延、山寨夺路、照影牒使试验铃阵。
- **终局：** 龙王庙水闸。
- **关键问题：** 你愿意为了离开牺牲谁？

## 第二章：《黄沙照影》

- **区域：** 黄沙古道。
- **视觉：** 大漠、驿路、风沙、龙门驿、镜湖书院、百工坞、鬼市、千佛石窟、照影楼坞。
- **主题：** 发现整个江湖都病了。
- **冲突：** 缉武司、同尘盟、鬼市、百工坞、慈心医脉、边地部族、照影局争夺牒录和石窟真相。
- **终局：** 照影楼坞。
- **关键问题：** 真相应当交给谁？

## 第三章：《司命》

- **区域：** 照影城。
- **视觉：** 皇城远景、外郭难民、下坊江湖、水巷鬼市、武籍区、慈心总馆、百工坊、花坊乐署、摘星楼、地下母局。
- **主题：** 决定谁来书写江湖。
- **冲突：** 缉武司要入册天下，同尘盟要推翻武籍，照影局要启动母局，玩家可摧毁、接管、公开或改造母局。
- **终局：** 地下照影母局。
- **关键问题：** 自由、秩序、真相、救人和控制，你保留哪一个？

# 7. 照影城定位

照影城不是完整皇城，而是 **皇城脚下的武籍都城**。

## 7.1 可玩核心

玩家主要活动在：

- 外郭；
- 下坊；
- 水巷；
- 武籍区；
- 慈心总馆；
- 百工坊；
- 花坊乐署；
- 镜台书院；
- 九门城防；
- 摘星楼；
- 地下照影母局。

## 7.2 皇城作用

皇城本体作为：

- 远景压迫；
- 皇命来源；
- 有限副本；
- 武籍大审场地；
- 续作或资料片空间。

**原则：** 玩家主要在江湖人能进入、潜入、破坏、结盟的城市肌理中活动，而不是完全开放皇权核心。

# 8. 术语表

| 术语 | 定义 |
|---|---|
| 照影牒针 | 植入武人体内的药符禁制，用于记录、诱导和触发宿主。 |
| 影纹 | 牒针外显或隐性的气机纹路。 |
| 照影铃 | 触发牒针的音律机关，可造成错拍、幻听、狂乱或共感。 |
| 牒录 | 记录武人身份、招式、功罪和未来风险的档案。 |
| 武籍 | 缉武司官方武人登记系统。 |
| 牒钥 | 开启、读取、改写牒录或牒针的钥匙媒介。 |
| 阵钥 | 操控照影母局机关和阵法的硬件钥匙。 |
| 心钥 | 人证、信任、队友关系和公开证据构成的社会钥匙。 |
| 照影母局 | 照影局最终控制中枢。 |
| 断因房 | 照影局培养预防性刺杀者的古老机构。 |
| 无名煞 | 特殊起源主角，断因房最高成功品之一。 |
| 缉武司 | 朝廷武人管理机构。 |
| 同尘盟 | 反抗武籍秩序的江湖联盟。 |
| 慈心医脉 | 牒针早期医术源头之一。 |
| 百工坞 | 机关与硬件技术来源。 |
| 鬼市 | 信息、身份、牒钥、黑市交易网络。 |
