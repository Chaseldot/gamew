# 章节、阵营与人物定义

本文定义《山水照影录》的章节结构、主要地区、阵营关系、核心人物、队友与起源角色。后续所有任务、故事、网站页面和分支剧本应以此为基础。

---

# 1. 章节定义

## 1.1 第一章：封境

| 项 | 内容 |
|---|---|
| 章节 ID | `ACT_1_SHANSHUI` |
| 章节名 | 封境 |
| 主要区域 | 山水县境 |
| 核心地点 | 清河渡、山水县城、疫村、山神寨、旧镖道、废书院、龙王庙水闸 |
| 视觉主题 | 雨夜、水患、湿冷县城、旧庙、山寨、疫病 |
| 叙事主题 | 生存、身份、封锁、小地方的大阴谋 |
| 核心问题 | 玩家要如何离开山水县？愿意为了离开牺牲什么？ |
| 章末大任务 | 龙王庙水闸 |
| 进入下一章条件 | 玩家取得或得知牒钥线索，离开山水县，前往黄沙古道。 |

### 第一章设计目标

第一章是“高密度小沙盒”。玩家应在有限县境中感受到：

- 每个 NPC 都可能知道一点真相；
- 每条离境路线都牵涉阵营代价；
- 队友招募与主线强绑定；
- 牒针既是威胁，也是剧情钥匙；
- 玩家选择会改变县城、疫村、山寨、县衙和水闸的命运。

| 视觉主题 | 风沙、驼铃、古道、边塞、石窟、商队、机关坞堡 |

### 第二章设计目标

第二章是“中型开放路径 + 多阵营展开”。它应完成三件事：

1. 把照影牒针从玩家个人危机扩大为江湖系统危机；
2. 通过千佛石窟揭示照影局的古老源头；
3. 通过武林盟会和照影楼坞决定玩家第三章的入城方式和阵营关系。

### 第三章设计目标

第三章是“城市总清算”。所有第一、二章变量都应在第三章获得至少一次可见回收：

- 被救的人出现；
- 被害的人家属出现；
- 被放走的敌人回归；
- 阵营好感改变入城方式；
- 队友信任改变终局方案；
- 证据改变武籍大审结果；
- 无名煞杀戮改变断因房态度。

# 2. 地区定义

## 2.1 山水县境

山水县位于江南水路与西去古道的交界处。它不是大城，却是试验场：水路、山路、官道都足以封锁，也足以隐藏罪证。

| 地点 | 功能 | 相关任务 |
|---|---|---|
| 清河渡 | 开场翻车、第一批幸存者、牒针线索 | A1-M01 |
| 山水县城 | 县衙、酒楼、医馆、牢城、黑市 | A1-M02, A1-S03 |
| 疫村 | 牒针试验后遗症、桑芷线 | A1-M02, A1-S01 |
| 山神寨 | 江湖反官府路线、山路出县 | A1-M03, A1-S02 |
| 旧镖道 | 韩霜铁线、尸车旧案 | A1-S04 |
| 废书院 | 牒录残页、奇门/音律解谜 | A1-S06 |
| 龙王庙水闸 | 第一章终局 | A1-M04 |

## 2.2 黄沙古道

黄沙古道连接山水县以西的商路、边塞、书院、工坊和石窟。这里的江湖不只讲门派，也讲商路、水源、军令、部族、驿站和风沙。

| 地点 | 功能 | 相关任务 |
|---|---|---|
| 龙门驿 | 第二章中心营地，各阵营首次集中招揽玩家 | A2-M01 |
| 黄沙客栈 | 封闭盒子任务，多阵营困局 | A2-S06 |
| 镜湖书院 | 牒针历史、失卷案 | A2-M02 |
| 百工坞 | 照影铃阵硬件来源，唐小砚线 | A2-M03 |
| 鬼市 | 牒钥、黑医、伪造身份、任无踪线 | A2-S01, A2-S05 |
| 千佛石窟 | 照影局古老源头，石窟真相 | A2-M04 |
| 武林盟会 | 第二章政治高潮 | A2-M05 |
| 照影楼坞 | 第二章终局副本 | A2-M06 |

照影城是皇城脚下的武籍都城，是缉武司、武籍库、百工坊、慈心总馆、花坊乐署、鬼市水巷与照影母局的交汇处。

| 武籍区 | 缉武司、武籍库、武籍大审 | A3-M03, A3-S09 |

# 3. 阵营定义

## 3.1 缉武司

| 项 | 内容 |
|---|---|
| 阵营 ID | `FACTION_JIWUSI` |
| 口号 | 武人入册，天下止戈。 |
| 表面目标 | 管理武人、减少江湖仇杀、维护治安。 |
| 深层目标 | 把江湖纳入可记录、可预测、可处罚的秩序。 |
| 优点 | 有组织、有资源、能保护普通百姓免受江湖私斗。 |
| 阴影 | 监控、入册、预防性处决、与照影局合作。 |
| 代表人物 | 沈照微、裴照、缉武司西线校尉。 |
| 玩家关系 | 可合作、可利用、可揭露、可推翻。 |

缉武司不是纯反派。它对江湖暴力有真实回应能力。问题在于它相信“还未发生的罪”也可以被记录和处理。

## 3.2 同尘盟

| 项 | 内容 |
|---|---|
| 阵营 ID | `FACTION_TONGCHEN` |
| 口号 | 江湖事，江湖了。 |
| 表面目标 | 反抗武人入册，保护江湖自治。 |
| 深层目标 | 推翻缉武司对江湖的控制。 |
| 优点 | 侠义、自由、敢反抗官府滥权。 |
| 阴影 | 内部混杂，有侠士、山寨、黑帮、复仇者和野心家。 |
| 代表人物 | 陆行舟、楚横山、韩霜铁可分支加入。 |
| 玩家关系 | 可引导成侠义联盟，也可放任其激进化。 |

同尘盟代表江湖自由，但不代表江湖清白。玩家需要不断判断：反抗官府的人是否一定值得支持？

# 4. 玩家主角定义

## 4.1 自定义主角

自定义主角没有固定门派或旧案，但拥有完整流派构筑自由。剧情默认主角是翻覆车队的幸存者之一，体内被植入异常牒针。

### 自定义主角叙事优势

- 玩家可自由投射身份；
- 阵营选择最开放；
- 与每名队友的关系更像“外来变量”；
- 可通过流派、选择和阵营塑造个人传奇。

## 4.2 起源队友主角

八名队友均可设计为起源角色。选择起源时，玩家直接从该角色视角开始故事，其个人线变为主线内在动机。

## 4.3 特殊起源：无名煞

| 项 | 内容 |
|---|---|
| 起源 ID | `ORIGIN_DARK_NAMELESS_SHA` |
| 起源名 | 无名煞 |
| 核心设定 | 断因房培养出的预防性刺杀者。 |
| 初始状态 | 失忆、无名、体内异常牒针、看见关键人物会产生精确杀意。 |
| 核心诱惑 | 杀掉某人可以立刻解决复杂问题。 |
| 核心代价 | 队友恐惧、证据断裂、照影局认同、断因房靠近。 |
| 终局方向 | 继承、斩断、失控、被审判、自我牺牲。 |

### 无名煞四种选择语言

| 选择 | 剧情含义 |
|---|---|
| 顺煞 | 接受杀意，迅速解决问题。 |
| 压煞 | 抵抗杀意，保留目标和后续分支。 |
| 引煞 | 假装失控，引诱幕后命令。 |
| 换煞 | 将杀意转向更大恶人，承担不可控后果。 |
