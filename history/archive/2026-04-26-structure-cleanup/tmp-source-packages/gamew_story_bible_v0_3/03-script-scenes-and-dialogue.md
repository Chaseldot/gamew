# 剧本、场景与对话样例

本文提供《山水照影录》的剧本格式、关键场景样例、玩家选项、分支后果和 galgame 化展示参考。后续可在此基础上扩写为小说、漫画脚本、互动剧情或游戏内对话。

---

# 0. 剧本格式规范

## 0.1 场景头格式

```md
## SCENE_ID 场景名

- 章节：
- 地点：
- 任务：
- 登场人物：
- 触发条件：
- 叙事目的：
- 可选变量：
```

## 0.2 对话格式

```md
**人物名：** 具体台词。

**玩家选项：**
1. 普通选项。
2. 【流派】流派专属选项。
3. 【队友】队友介入选项。
4. 【无名煞】特殊起源选项。

**分支后果：**
- 变量变化；
- 阵营变化；
- 队友态度变化；
- 后续任务解锁/关闭。
```

## 0.3 旁白原则

旁白应保持武侠质感，避免现代解释腔。它可以描述感官、气氛、身体反应和心魔，但不替玩家决定立场。

# 1. 开场剧本：雨夜醒牒

## SCENE_A1_M01_001 雨夜清河渡

- 章节：第一章《封境》
- 地点：清河渡
- 任务：A1-M01 雨夜醒牒
- 登场人物：玩家、押车兵、幸存者、濒死牒使
- 触发条件：新游戏开场
- 叙事目的：建立体内危机、失忆/身份疑问、照影牒针和第一组选择。
- 可选变量：`A1_SURVIVORS_SAVED`、`A1_TIE_RECORD_FRAGMENT`、`DARK_BODYCOUNT`

### 正文

雨声先回来。

然后是铁锈味。

最后是你自己的心跳。

它不太像你的心跳，更像有人隔着一面鼓，在替你数命。

你睁开眼。车轮半陷在泥里，囚车翻倒，镖旗被血水压在车辕下。河面火光摇晃，像一群快要熄灭的眼睛。

你的腕脉上有一道细黑线。它在皮下轻轻一跳，仿佛认出了这个地方。

一个押车兵靠在断木旁，握刀的手一直在抖。

**押车兵：** 别过来。你腕上也有黑线。你也是他们的人？

**玩家选项：**

1. “我不知道这是什么。先止血。”
2. “他们是谁？”
3. “把刀放下，否则你会死得更快。”
4. 【药师】“别动。你中的是散脉粉，不是致命伤。”
5. 【影踪】观察泥里的脚印，判断袭击者离开的方向。
6. 【奇门】检查囚车残留符钉和断裂机簧。
7. 【无名煞】你忽然知道，只要割开他的喉咙，就没人知道你醒过。

### 分支：选择 1 / 药师救人

**押车兵：** 你……你不是他们的人？

他想把刀放下，却因为疼痛差点昏过去。

**旁白：** 你按住他的伤口。血很热，雨很冷。腕上的黑线在皮下停了一瞬，像是不满你浪费时间。

**后果：**

- `A1_SURVIVORS_SAVED = true`
- 山水县后续出现证人。
- 桑芷招募时初始信任小幅增加。

### 分支：选择 7 无名煞

**旁白：**

那念头来得太熟。

不是愤怒，不是恐惧，甚至不是恶意。

像手知道怎样握筷，舌知道怎样抵住牙。

杀人，对你来说，也许曾经只是一个习惯。

**玩家二级选项：**

1. 【压煞】后退一步，把刀踢远。
2. 【顺煞】照着脑中那条最短的线出手。
3. 【引煞】假装出手，看押车兵是否喊出幕后之人的名字。

**后果：**

- 压煞：`DARK_RESISTANCE += 1`
- 顺煞：`DARK_BODYCOUNT += 1`，`A1_SURVIVORS_SAVED = false`
- 引煞：若成功，获得“白微尘”名号线索。

# 2. 队友招募：桑芷

## SCENE_A1_M02_003 疫村医棚

- 章节：第一章《封境》
- 地点：疫村医棚
- 任务：A1-M02 医馆问针
- 登场人物：玩家、桑芷、疫村病人
- 触发条件：玩家进入疫村并展示腕脉黑线
- 叙事目的：介绍药师队友、牒针不可硬拔、慈心医脉罪债。

### 正文

医棚没有门。

只是几根竹竿撑着破布，布上全是雨水、药渍和手指抓出来的褶痕。

桑芷跪在泥地里，左手按着病人的脉，右手用银针封住对方肩井。她没有抬头。

**桑芷：** 要问路，去村口。要买药，药柜空了。要杀人，排队。这里每个人都快死了，不差你一个。

**玩家：** 我腕上有黑线。

桑芷终于抬头。

她看见影纹，脸色变了。

**桑芷：** 谁给你种的？

**玩家：** 我正想问你。

**桑芷：** 那你问错人了。我只会拔刺、接骨、救命。这种东西……是把人当药炉。

**玩家选项：**

1. “你能治吗？”
2. “你见过？”
3. “你在害怕。为什么？”
4. 【药师】“牒针用了三味药引，其中一味来自你们医脉。”
5. 【威胁】“你不说，我就让这棚子里的人一起陪葬。”
6. 【无名煞】她认识这东西。杀了她，搜她的药箱。

### 分支：药师识破

**桑芷：** 你也懂药？那你该知道，懂药的人最怕看见药被做成锁。

**玩家：** 所以这是锁？

**桑芷：** 是锁，也是账本。它记你疼过什么，怕过什么，杀过谁。等有人敲对了铃，它就替你记起来。

**后果：**

- 解锁牒针解释条目；
- `COMP_SANG_TRUST += 1`；
- 开启支线 `A1-S01 疫井`。

### 分支：威胁

桑芷把针拔出半寸。

病人猛地抽搐。

**桑芷：** 你可以杀我。但你最好先想清楚，你腕上那东西下一次发作时，谁替你按住脉？

**后果：**

- 桑芷暂时不加入；
- 可通过救疫村重新获得信任；
- `COMP_SANG_TRUST -= 1`。

# 3. 第一章终局：龙王庙水闸

## SCENE_A1_M04_007 阵眼闸室

- 章节：第一章《封境》
- 地点：龙王庙水闸阵眼
- 任务：A1-M04 龙王庙水闸
- 登场人物：玩家、白微尘、何其庸、楚横山、桑芷、唐小砚、牒针宿主
- 触发条件：玩家进入水闸核心
- 叙事目的：第一章核心价值选择。

### 正文

水声在脚下翻滚。

铜铃悬在闸梁上，每一只都被细线连着，线穿过符钉、机簧和木轮，最后汇到白微尘手中的小铃上。

闸室另一侧，十几名牒针宿主被绑在柱边。他们腕上的黑线和你的黑线一起跳动。

**白微尘：** 你来得正好。山水县太小，容不下这么多不该活的人。

**桑芷：** 他们是病人！

**白微尘：** 不。他们是未来的凶手、叛徒、疯子，或被疯子杀死的无用证人。照影局只是让结局提前一点。

**唐小砚：** 他把水闸机簧接进铃阵了。给我时间，我能改分洪，但你们得拖住他。

闸门开始震动。

城里的灯火在远处晃了一下。

### 玩家大选择

1. “先救城。”
2. “先救这些宿主。”
3. “白微尘不能走。”
4. “县令何其庸，你欠山水县一个真相。”
5. 【唐小砚】“小砚，改闸。我们替你争时间。”
6. 【桑芷】“先压住牒针，水闸我来想办法。”
7. 【山神寨盟友】“楚横山，夺闸。”
8. 【无名煞】杀掉所有知道真相的人，让它变成一场天灾。

### 关键台词：追凶优先

**玩家：** 白微尘不能走。

**桑芷：** 那城里的人呢？

**白微尘：** 你看。选择从来不用我逼。只要把刀和人命摆在一起，你们自己就会替我证明江湖是什么。

**后果：**

- 白微尘可能被杀或逃亡；
- 县城部分受灾；
- 玩家获得第一枚完整牒钥或关键线索；
- 桑芷信任视救援行为变化。

# 4. 第二章盒子任务：黄沙客栈

## SCENE_A2_S06_002 风沙封门

- 章节：第二章《黄沙照影》
- 地点：黄沙客栈
- 任务：A2-S06 黄沙客栈
- 登场人物：玩家、缉武司校尉、同尘盟信使、鬼市买家、书吏、霍青鸢族人、百工机关师、照影牒使、失明画僧
- 触发条件：玩家在风沙夜进入客栈
- 叙事目的：展示多阵营、查案、伪装、投毒、潜入、无名煞分支。

### 正文

风沙把门拍得像有人在外面敲棺材。

客栈掌柜把门闩压下，说今夜谁也走不了。

于是所有人都看见了所有人。

缉武司校尉的刀放在桌上。同尘盟信使的袖口藏着血。鬼市买家戴着银面。百工坞机关师一边喝汤，一边把三枚机簧压在碗底。

角落里，失明画僧摸着一卷空白画轴。

**画僧：** 风沙关门，不是坏事。门一关，人心就比路清楚。

午夜，书吏死了。

他的门从里面扣着。窗没开。桌上墨迹未干，只写了四个字：

> 不要听铃。

### 玩家调查选项

1. 检查门窗。
2. 盘问所有人。
3. 搜书吏身上的牒录拓本。
4. 【药师】验尸，判断是否死于牒针暴发。
5. 【奇门】检查窗栓与机关线。
6. 【音律】回忆午夜是否听见错拍铃声。
7. 【影踪】潜入各房间搜证。
8. 【无名煞】你知道谁最可能在明日背叛你。

### 真相揭示

**玩家：** 他不是被刀杀的。

**药师/桑芷：** 他的脉像是被人从里面剪断。牒针暴发。

**奇门/唐小砚：** 门锁是假的。有人用机线让它死后才扣上。

**音律/柳听弦：** 午夜的风声里混着铃。很轻，但够了。

画僧低声笑了一下。

**画僧：** 我说过，门一关，人心就清楚。可你们偏偏都在听门外的风。

# 5. 第二章石窟：千佛无面窟

## SCENE_A2_M04_005 无面佛龛

- 章节：第二章《黄沙照影》
- 地点：千佛石窟深处
- 任务：A2-M04 千佛石窟
- 登场人物：玩家、失明画僧、霍青鸢、照影旧部、无名煞幻影
- 触发条件：玩家通过壁画廊、回音窟、药香窟、砂机关窟
- 叙事目的：揭示照影局古老源头与断因房。

### 正文

无面佛龛里没有佛脸。

每一尊佛的脸都被刮掉，只剩空白的石面。石面下刻着密密麻麻的名字，有些被朱砂圈住，有些被黑线划断。

失明画僧伸手摸过一行刻字。

**画僧：** 这里供的不是佛。是被提前判死的人。

**霍青鸢：** 谁判的？

画僧没有回答。他把手移到龛底，摸到一个旧字。

**画僧：** 照。

风从石缝里钻进来，所有被刮掉脸的佛像同时发出低低的回声。

**回声：** 此人若活，三年后血流七里。断。

### 无名煞专属

如果玩家是无名煞：

**旁白：**

你跪在这里。

不止一次。

有人把一张牒牌放在你面前。牌上没有名字，只有判词。

你听见自己的声音，很年轻，也很平静。

**年轻的你：** 领命。

**玩家选项：**

1. 【压煞】“这不是我。至少不再是。”
2. 【顺煞】“若血流七里，一刀断因，有何不对？”
3. 【引煞】假装接受判词，等待幕后声音继续下令。
4. 【换煞】“判词不该对准被判的人，该对准写判词的人。”

### 后果

- 压煞：`DARK_RESISTANCE += 2`；画僧信任上升。
- 顺煞：`DARK_AWAKENING = revealed`；断因房第三章接触提前。
- 引煞：获得司命早期声纹线索。
- 换煞：解锁第三章断因房反杀路线。

# 6. 第三章：武籍大审

## SCENE_A3_M03_004 皇城外朝审台

- 章节：第三章《司命》
- 地点：皇城外朝边缘，武籍审台
- 任务：A3-M03 武籍大审
- 登场人物：玩家、沈照微、裴照、桑芷、霍青鸢、陆行舟、山水县证人、石窟画僧、百工证人
- 触发条件：玩家取得至少一类证据或被强制传唤
- 叙事目的：回收前两章证据，决定城市权力走向。

### 正文

皇城的墙在审台之后。

它没有说话，却比在场所有人都像一个裁判。

沈照微站在武籍台前，身后是成排牒牌。每一枚牒牌都刻着一个武人的名字。

**沈照微：** 江湖要自由，百姓要活命。二者若不能并存，我选百姓。

台下有人叫好，也有人拔刀。

裴照站在你身侧，拳头握得很紧。

**裴照：** 今日若没有证据，律法就会变成她的刀。若有证据，却没人敢说，律法就会变成我们的罪。

### 玩家可提交证据

1. 山水县水闸证词。
2. 白微尘牒钥。
3. 镜湖失卷。
4. 石窟壁画拓片。
5. 百工机关图。
6. 楼坞牒针宿主名单。
7. 慈心医脉药方。

### 关键对话：桑芷公开医脉罪证

**桑芷：** 牒针的第一味药引，来自慈心医脉。

人群哗然。

**桑芷：** 我说这句话，不是为了让你们原谅医者。是为了让你们知道，救人的手若不被看见，也会被人借去杀人。

**沈照微：** 你承认医脉有罪？

**桑芷：** 承认。但罪证不该交给另一个不受审的人。

### 关键对话：霍青鸢作证

**霍青鸢：** 你们说入册是为了天下。那我的族人算不算天下？

她把一枚断箭钉在审台木板上。

**霍青鸢：** 这箭上有牒针药粉。边军说是江湖人下的，江湖人说是边地人下的。石窟壁画说，写判词的人早就在墙后面了。

### 审判分支

| 分支 | 条件 | 后果 |
|---|---|---|
| 举证成功 | 至少 4 项强证据 + 心钥高 | 沈照微动摇，照影局提前启动母局。 |
| 官方胜出 | 证据不足或玩家支持官方 | 武籍天下路线增强。 |
| 同尘暴动 | 陆行舟激进且玩家纵容 | 城市街垒战。 |
| 证人被刺杀 | 玩家或照影局干预 | 真相残缺，结局变暗。 |
| 医者路线开启 | 桑芷公开罪证且信任高 | 慈心残卷结局解锁。 |

# 7. 营地戏：无名煞夜醒

## SCENE_CAMP_DARK_002 针尖在侧

- 章节：任意，建议第一章后半或第二章前半
- 地点：夜营
- 登场人物：玩家、桑芷
- 触发条件：无名煞玩家；桑芷在队；`DARK_AWAKENING >= stirred`
- 叙事目的：让无名煞的杀意威胁队友关系，而不是只影响外部 NPC。

### 正文

你醒来时没有睁眼。

你先闻到药味，然后听见另一个人的呼吸。

桑芷睡在火堆另一侧。你的手里握着一根银针，针尖对着她颈侧三寸。

**旁白：**

这一针下去，她不会叫出声。

她知道太多牒针的事。她活着，会让路变复杂。

桑芷睁开眼。

**桑芷：** 你要杀我？

**玩家选项：**

1. “我不知道我为什么在这里。”
2. “快走，离我远点。”
3. “我不会让它控制我。”
4. “你知道得太多了。”
5. 【药师】把针反刺自己穴位，压住杀意。
6. 【音律】哼起柳听弦教过的护心调。
7. 【无名煞：顺煞】杀了她。

### 后果

- 选择 1/2/3：桑芷恐惧但留下，开启研究无名煞支线。
- 药师/音律成功：`DARK_RESISTANCE += 1`，`COMP_SANG_TRUST += 1`。
- 威胁：`COMP_SANG_TRUST -= 2`。
- 顺煞：桑芷死亡，慈心路线关闭，`DARK_BODYCOUNT += 1`。

# 8. 最终对峙：司命

## SCENE_A3_M05_010 地下照影母局

- 章节：第三章《司命》
- 地点：地下照影母局
- 任务：A3-M05 照影母局
- 登场人物：玩家、司命、存活队友、阵营代表
- 触发条件：玩家进入母局核心
- 叙事目的：最终价值辩论与结局选择。

### 正文

无数铜铃悬在黑暗中。

铃下是一枚枚牒牌。每一枚牒牌都刻着一个武人的姓名、门派、救过的人、杀过的人，以及尚未发生的罪。

司命站在阵心，像一个疲惫的账房先生。

**司命：** 你一路走到这里，杀了不少人，也救了不少人。所以你比任何人都清楚，江湖从来不是干净的。

**玩家：** 你把人做成账。

**司命：** 不是我。他们先把自己活成了账。一条人命换一场名声。一场复仇换十年血仇。一个大侠放过一个恶人，第二天便有十户人家戴孝。我只是把这些账提前算完。

**玩家选项：**

1. “账可以算，人不能被写死。”
2. “你说得对，但你不该是执笔的人。”
3. “把母局交给我。”
4. “我要毁了它。”
5. “我要公开它，让天下人自己看。”
6. “我要保留治疗功能，废掉控制功能。”
7. 【缉武司】“交给律法，哪怕律法还不够干净。”
8. 【同尘盟】“江湖自己承担江湖的代价。”
9. 【无名煞】“你不是在等我阻止你。你是在等我继承你。”

### 无名煞专属

司命看向无名煞玩家。

**司命：** 断因七号。你一直是我最好的答案。

他抬手，黑暗中亮起一排旧牒牌。

**司命：** 他们辩论，他们迟疑，他们被情义拖住手。只有你知道，世上许多灾祸，本来只需一刀。

**玩家选项：**

1. 【继承】“把牒牌给我。”
2. 【斩断】“我不是你的答案。”
3. 【反杀】假装接过牒牌，在阵心反向改写断因命令。
4. 【自审】“把我的牒牌也放上去。让他们审我。”
