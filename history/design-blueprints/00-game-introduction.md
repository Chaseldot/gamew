# 00 游戏介绍

状态：active
用途：说明 GameW 要做什么游戏，以及最终预期体验。

## 一句话

GameW 是一个低魔武侠 CRPG：玩家用主修流派、传承和旁修组合出经典武侠形象，在可读、可反制、重定位的战术战斗中体验江湖人物成长。

## 要做什么

GameW 的核心不是做固定职业表，而是做一个能表达武侠幻想的构筑系统。

玩家不直接选择“毒医”“刺客”“琴魔”“侠盗”这类职业标签，而是通过：

- 主修流派：决定战斗语法；
- 传承：决定主修内的成长路线；
- 旁修：接入少量副武学；
- 技能池：承载具体招式、风味和战斗工具；
- 武侠幻想库：用经典形象持续压测构筑是否能表达玩家想象。

## 预期体验

| 方向 | 预期 |
|---|---|
| 武侠味 | 玩家能自然拼出飞刀浪子、毒医圣手、黑衣刺客、破阵先锋、玉箫行客等形象。 |
| CRPG 味 | 战斗有站位、资源、反制窗口、队伍职责和成长选择。 |
| 构筑感 | 满级构筑能表达纯主修、单旁修、双旁修，而不是所有角色趋同。 |
| 低魔边界 | 奇门、音律、药师可以有奇异表现，但不滑向西幻法师、神术职业或万能解题器。 |
| 可复用资源 | 武侠幻想既用于玩家构筑，也可复用于 NPC、队友、敌人和支线人物。 |

## 设计参照

系统结构会参考 D&D / BG3 的成熟设计：

- 流派参考 class 的能力领域；
- 传承参考 subclass 或成熟玩法底盘；
- 旁修参考 multiclass 的低阶接入；
- 但最终表达必须是武侠化的，不照搬宗教、种族、西幻法术或召唤兽世界观。
