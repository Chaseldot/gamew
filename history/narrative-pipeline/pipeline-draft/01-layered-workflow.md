# 01 分层叙事工作流

状态：active draft
日期：2026-04-26

## 总览

GameW 的剧情生产分为七层。越上层越像主创判断，越下层越适合交给 AI 扩写和变体生成。

```text
L0 创作北极星
L1 世界压力与主题问题
L2 章节 checkpoint
L3 任务网络
L4 任务包
L5 场景卡
L6 对白、旁白、检查文本
```

## L0 创作北极星

目标：用极短文本定义玩家最终体验。

GameW 当前北极星：

```text
玩家在低魔武侠世界中被照影牒针卷入江湖治理系统，既要活下去，也要决定武人是否应被记录、预测和提前处置。
```

主创检查问题：

- 这句话是否能解释所有主线冲突？
- 队友线是否都能从这句话延伸？
- 终局选择是否真正在回答这句话？
- 如果删掉某条支线，北极星是否更清楚？

交付物：

- 一句话定位；
- 三个核心主题词；
- 三个玩家承诺。

## L1 世界压力与主题问题

目标：把设定转化为可反复制造任务的压力源。

推荐模板：

| 压力源 | 诱惑 | 代价 | 受害者 | 获益者 | 可生成任务 |
|---|---|---|---|---|---|
| 照影牒针 | 治疗疯症、追踪重犯、预测祸端 | 控制、诱导、误判、灭证 | 宿主、武人、边缘门派 | 照影局、官府、部分医脉 | 救治、审案、潜入、销毁档案、夺钥 |

主创检查问题：

- 这个设定是否能被好人合理使用？
- 这个设定是否会被坏人滥用？
- 玩家能否亲眼看见它的好处和伤害？
- 是否存在没有完美答案的任务？

交付物：

- 核心设定压力表；
- 阵营动机表；
- 禁止使用的万能解法列表。

## L2 章节 Checkpoint

目标：定义每章必须完成的认知、关系和状态推进。

每章需要三类 checkpoint：

| 类型 | 说明 | 示例 |
|---|---|---|
| 真相 checkpoint | 玩家必须知道的新事实 | 牒针能记录并诱导行为。 |
| 关系 checkpoint | 队友或阵营必须发生的态度变化 | 桑芷开始怀疑师门参与牒针药引。 |
| 世界状态 checkpoint | 地区或势力必须写入的变量 | 山水县 saved / flooded / occupied / abandoned。 |

主创检查问题：

- 玩家是否可以通过不同路径抵达同一认知？
- 本章终局是否改变下一章入口？
- 本章是否至少产生一个终局可回收证据？
- 是否有起源角色专属视角？

交付物：

- 章节概要；
- 地区状态表；
- 必达真相表；
- 跨章变量清单。

## L3 任务网络

目标：把章节拆成主线、大型支线、队友任务和阵营任务的网络，而不是线性大纲。

推荐结构：

```text
主线任务：推进章节 checkpoint。
大型支线：改变主线资源、证据、阵营态度或地区状态。
队友任务：改变队友信念、信任和终局可能。
阵营任务：改变势力入口、价格、敌对状态和结局支持。
营地场景：回收选择、制造关系冲突、触发个人线。
```

任务网络检查问题：

- 如果玩家跳过这条支线，主线是否仍可推进？
- 如果玩家完成这条支线，主线是否真的改变？
- 是否存在三条以上进入终局地点的方式？
- 每个队友是否至少有一次“带他来会改变局面”的任务？
- 每个任务是否至少支持武力、系统、角色三类路径中的两类，重要任务支持三类？

交付物：

- 章节任务地图；
- 任务依赖关系；
- 可选入口和替代入口；
- 阵营冲突表。

## L4 任务包

目标：把每个任务变成可制作、可审稿、可交给 AI 扩展的任务资产。

任务包必须回答：

- 玩家为什么来？
- 任务真正的戏剧问题是什么？
- 有哪些解法？
- 失败如何推进？
- 写入哪些变量？
- 后续在哪里回收？

使用 `02-quest-packet-template.md`。

## L5 场景卡

目标：把任务中的关键节点拆成可写对白和演出的最小单元。

场景卡适用于：

- 任务入口；
- 关键 NPC 对质；
- 队友争执；
- 阵营选择；
- 战斗前后；
- 失败后果；
- 营地回响；
- 章节结算。

使用 `03-scene-card-template.md`。

## L6 对白、旁白、检查文本

目标：在结构稳定后写具体文本。

文本类型：

| 类型 | 作用 |
|---|---|
| 对白 | 角色表达、选择呈现、关系变化。 |
| 旁白 | 感官、动作、环境反馈。 |
| 检定成功文本 | 告诉玩家能力如何改变局面。 |
| 检定失败文本 | 推进失败后果，不嘲讽玩家。 |
| 队友插话 | 表现立场和关系。 |
| 日志文本 | 清楚记录任务目标和后果。 |

写作检查问题：

- 玩家是否知道自己在选什么？
- 选择文本是否隐含后果但不剧透？
- NPC 是否有自己的动机，而不是只给玩家解释设定？
- 队友插话是否体现立场，而不是重复信息？
- 失败文本是否开启新局面？

## 推荐推进节奏

1. 每章先完成 L2。
2. 每章列出 L3 任务网络。
3. 只对主线和大型支线先写 L4 任务包。
4. 只对关键节点写 L5 场景卡。
5. 等任务包通过审稿后再写 L6。
6. 每完成一批任务包，回到 L2 检查 checkpoint 是否仍成立。
