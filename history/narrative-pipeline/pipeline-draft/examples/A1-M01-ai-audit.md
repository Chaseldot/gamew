## 2. 严重问题

当前样板未发现会阻断任务成立的严重问题。

保留风险：

- `A1_FIRST_TIE_KEY` 在现有矩阵中正式枚举为 `obtained / lost / destroyed`，但 A1-M01 只写“线索开启”。如果后续要让 A1-M01 写入正式变量，应拆成单独线索变量，或明确这只是 `A1_FIRST_TIE_KEY` 的前置线索，不是正式取值。

建议：

```text
不要在 A1-M01 直接写入 A1_FIRST_TIE_KEY=obtained。
保留为“牒钥线索开启”，正式取值仍在 A1-M04 写入。
```

## 3. 中等问题

| 问题 | 影响 | 建议 |
|---|---|---|
| 起源角色入口只列了部分起源的独特信息 | 八名起源都应改变视角 | 后续补齐谢停云、柳听弦、韩霜铁、霍青鸢的开场感知差异 |
| 县衙追兵的到达时间尚未量化 | 任务节奏可能不清 | 不写具体秒数，但可定义“最多完成两类行动” |
| 伪造现场没有正式变量 | 后续回收可能丢失 | 若只影响少量审问对白，可作为局部 flag，不必加入章节变量表 |
| 无名煞引煞的成功结果偏抽象 | 实装时难写 | 场景卡阶段要明确可获得“断因暗号残片”还是“铃声方向” |

## 4. 可优化项

- 在 A1-M01-SC01 增加“行动预算”概念：救人、搜证、追踪三者不能全拿满，除非起源或高能力提供额外窗口。
- 把“押车兵”和“民夫”承担的证词区分开：押车兵提供官府流程矛盾，民夫提供黑衣牒使方向和民间证词。
- 开场无队友是合理的，但后续营地回响应尽快补上，否则队友对开场重大选择的态度回收会太晚。
- 黑衣牒使最好不在开场直接正面对话，避免过早解释照影局。

## 5. 变量一致性检查

| 变量 | 检查结果 | 说明 |
|---|---|---|
| `A1_DARK_ORIGIN_WITNESSES` | 通过 | `spared / mixed / killed` 与现有矩阵一致。 |
| `DARK_ORIGIN_AWAKENING` | 通过 | `stirred` 来自追踪、铃声、引煞，合理。 |
| `DARK_ORIGIN_BODYCOUNT` | 通过 | 顺煞灭口导致上升，符合无名煞规则。 |
| `DARK_ORIGIN_RESISTANCE` | 通过 | 压煞成功导致上升，符合无名煞规则。 |
| `A1_FIRST_TIE_KEY` | 需限定 | A1-M01 只能开启线索，不能写入正式枚举值。 |

## 6. 分支制作成本检查

| 内容 | 成本 | 判断 |
|---|---|---|
| 清河渡开场地图 | 高 | 必要。开场必须有强记忆点。 |
| 救人 / 搜证 / 追踪分支 | 低到中 | 主要通过交互物、日志、变量和少量场景差异实现。 |
| 无名煞诱导 | 中 | 需要独特 UI / 文本 / 音效提示，但价值高。 |
| 县衙接管失败推进 | 中 | 可复用牢城审问场景，值得保留。 |
| 每个起源专属演出 | 高 | 不建议全做演出。优先文本、检定和镜头重点差异。 |

## 7. 极端玩家压测

| 玩家类型 | 是否可推进 | 风险 | 回收 |
|---|---|---|---|
| 侠义玩家 | yes | 线索可能少于追踪路线 | 证词强、裴照和桑芷更易正面 |
| 功利玩家 | yes | 证人可能死亡或信任低 | 物证强、县衙怀疑盗尸 |
| 法理玩家 | yes | 被官府入册，失去现场主动权 | 官府路线和裴照线提前 |
| 混乱玩家 | yes | 证据、证人和县衙关系都可能恶化 | 牢城入口或黑市逃亡入口兜底 |
| 无名煞顺煞玩家 | yes | 证词缺失、bodycount 上升 | 断因房暗线增强 |
| 无名煞压煞玩家 | yes | 行动窗口缩短，开场压力更高 | 抵抗线和救赎线增强 |
