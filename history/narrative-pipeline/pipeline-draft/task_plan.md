## Decisions

| Decision | Rationale |
|---|---|
| 新工作区放在 `docs/narrative-pipeline/` | 与现有 `docs/story/` canon 内容分离，先建设生产方法，再逐步迁移到正式剧情资产。 |
| 不以小说作为母版 | GameW 是多起源、多路径 CRPG，母版应是任务网络、变量回收和场景卡。小说化文本只用于语气样章与关键场景。 |
| 采用“主题 -> 章节 -> 任务包 -> 场景卡 -> 对白”的层级 | 便于控制分支复杂度，也便于 AI 分工生成和人工审稿。 |
