“BG3式拖底”我会放在**结构、自由度、任务多解、队友个人线、营地戏、起源角色、邪念式特殊主角、三幕推进、城市总清算**这些层面，而不是照搬具体角色、任务和桥段。GameW 既然已经确定是低魔武侠 CRPG，核心表达应围绕主修流派、传承、旁修、技能池和武侠幻想库来展开，而不是变成西幻皮下的武侠翻译版。 现有 canon 中八大流派、九级构筑和 17 个传承已经定型，下面的剧情资产会尽量让每个流派都有剧情解法、战斗舞台和队友表达空间。 武侠幻想库中的白衣剑神、龙门护送客、毒医圣手、六指琴魔、唐门机巧客、铁枪护法、回疆飞羽女帅等形象，会被转化为队友、敌人、支线 NPC 和构筑测试资产。

# GameW 战役圣经 v0.1

## 《山水照影录》

## 1. 核心设计目标

### 一句话

玩家在山水县境醒来，体内被植入名为 **照影牒针** 的低魔禁制。为了活下去、找回身份、解除牒针，玩家从山水县境出发，穿越槐安古道与石窟秘境，最终进入照影城，决定天下武人的未来。

### 核心体验

这是一个 **BG3式高自由度武侠 CRPG**：

* 玩家可以自定义主角，也可以选择带有强叙事钩子的起源角色。
* 队友不是战斗单位，而是拥有门派债、血仇、旧案、信念和终局分歧的叙事角色。
* 每章都有大型阵营冲突和沙盒任务。
* 任务支持战斗、潜入、谈判、审案、偷窃、医毒、机关、音律、奇门、队友专属、无名煞专属等多解。
* 前两章的选择会在第三章照影城集中回收。
* “邪念式”特殊主角不照搬，改造成武侠语境下的 **无名煞** 起源。
* 主线不是“拯救世界”，而是“谁有资格替天下武人决定命运”。

# 3. 世界观总纲

## 3.1 时代背景

大雍末年，天下承平表面尚在，实则江湖、边军、商路、官府、门派都在失控。

江湖曾经承担民间秩序：

* 镖局护商路；
* 山寨护乡里；
* 医馆救疫病；
* 门派镇地方；
* 游侠补官府之不足。

但近二十年，门派仇杀、黑道坐大、边军私贩、官府失信、帮会割据，让朝廷越来越无法容忍“未入册武人”。

于是朝廷设立 **缉武司**。

缉武司公开目标：

> 武人入册，天下止戈。

但缉武司背后还有一个更隐秘的组织：

> **照影局。**

照影局不只是缉武司的暗部。它有更古老的源头，只是在大雍末年被重新启用、行政化、军事化。

---

## 3.2 核心禁物：照影牒针

照影牒针是低魔武侠版的核心危机。

它不是神术，不是西幻寄生物，而是由 **药师、奇门、音律、符禁、机括** 共同制造的禁制。

| 构成  | 来源      | 效果                              |
| --- | ------- | ------------------------------- |
| 牒针  | 药师 / 蛊毒 | 植入腕脉、命门或玉枕，影响痛觉、梦境、记忆、杀意。       |
| 影纹  | 奇门 / 符禁 | 记录宿主气机、招式习惯、情绪波动和人际牵连。          |
| 照影铃 | 音律 / 机括 | 远距离触发牒针，引发错拍、幻听、昏厥、狂乱或短暂共感。     |
| 牒录  | 武籍 / 档案 | 把每个武人的过往、罪名、救人记录、杀人记录、预判风险写入册中。 |

牒针公开用途：

* 治疗战后疯症；
* 控制走火入魔者；
* 审讯危险武人；
* 追踪重犯。

牒针真实用途：

> 记录、预测、诱导、必要时提前清除那些“可能造成大乱”的武人。

# 4. 三章总览

## 第一章：《封境》

**地点：** 山水县境。
**主题：** 你以为自己只是要活着离开。
**政治问题：** 局部崩坏时，谁有权决定牺牲？
**核心冲突：** 山水县被封，疫病、水患、山寨、县衙和隐藏的照影局同时压来。县衙要维持封境，山寨要夺回山路，医者要救牒针宿主，照影局外勤则在暗中筛选“可控武人”。
**终局场景：** 龙王庙水闸。
**章节目标：**

1. 弄清自己体内黑线是什么；
2. 找到懂牒针的人；
3. 在山水县封境中选择站队或独行；
4. 取得第一枚牒钥；
5. 离开山水县，前往槐安古道。

---

## 第二章：《黄沙照影》

**地点：** 槐安古道、龙门驿、镜湖书院、百工坞、鬼市、石窟、武林盟会、照影楼坞。
**主题：** 你发现这不是你的病，而是整个江湖的病。
**政治问题：** 真相出现后，谁有权解释真相？
**核心冲突：** 玩家手中的山水县证据、牒钥、失卷和石窟拓片，足以改变槐安古道的政治平衡。缉武司要把证据纳入武籍秩序，同尘盟要把证据烧成反旗，慈心医脉、百工坞和鬼市则掌握治疗、机关和身份入口。照影局不公开站队，只在各方背后篡改证据、触发铃阵、清除证人。
**终局场景：** 照影楼坞。
**章节目标：**

1. 追查牒针来源；
2. 找到进入照影城的身份、密道或证据；
3. 决定山水县真相交给谁、公开多少、保留什么；
4. 在石窟发现照影局不是缉武司暗部，而是古老控制系统；
5. 在武林盟会和照影楼坞中决定第三章入城时的政治态势。

---

## 第三章：《司命》

**地点：** 照影城。
**主题：** 所有人都想书写江湖，最后轮到你决定。
**政治问题：** 掌握母局后，谁有权书写未来？
**核心冲突：** 缉武司要把天下武人彻底入册，同尘盟要推翻武籍秩序，照影局终于显形并准备启动照影母局。玩家进入的不是静态城市，而是一座会识别、搜捕、戒严、交易、审判和暴动的武籍都城。
**终局场景：** 摘星楼与地下照影母局。
**章节目标：**

1. 进入照影城；
2. 收集牒钥、阵钥、心钥；
3. 完成队友终局；
4. 参与或破坏武籍大审；
5. 决定照影母局和天下江湖的未来。

---

# 5. 第三章城市定位：照影城与皇城

照影城不直接等于皇城。

更合适的定位是：

> **照影城是皇城脚下的武籍都城，是缉武司、武籍库、百工坊、慈心总馆、花坊乐署、鬼市水巷与照影母局所在之地。皇城本体在远景中压迫城市，但不是常规开放区。**

这样既能保留 BG3式“第三章城市沙盒”，又不让叙事滑向完整宫斗。

## 可玩区域

| 区域     | 玩法功能                      |

| 外郭     | 难民、山水县幸存者、黄沙商队、边地部族、旧敌回流。 |

| 水巷     | 任无踪、鬼市、潜入、走私、地下入口。        |
| 武籍区    | 缉武司、武籍库、审判、裴照线、沈照微线。      |
| 慈心总馆   | 桑芷线、牒针治疗、医脉罪证。            |
| 百工坊    | 唐小砚线、机关、城市控制节点。           |
| 花坊乐署   | 柳听弦线、音律阵、情报交易、贵人社交。       |

# 6. 核心阵营

本作政治结构不再是六个平级阵营。真正公开争夺江湖秩序的是 **缉武司** 与 **同尘盟**；**照影局** 是寄生暗线，潜伏在制度、医术、机关和黑市背后，第三章才完整显形。慈心医脉、百工坞和鬼市不是第三、第四、第五条政治路线，而是所有路线都要争夺的关键中间势力。

## 6.1 阵营层级

| 层级 | 势力 | 叙事功能 |
| --- | --- | --- |
| 核心政治轴 | 缉武司 | 国家秩序、武人入册、合法暴力、预防治安。 |
| 核心政治轴 | 同尘盟 | 江湖自治、门派义气、反抗滥权、复仇风险。 |
| 寄生暗线 | 照影局 | 预测、诱导、提前处置；隐藏在多方制度和技术接口背后。 |
| 关键中间势力 | 慈心医脉 | 掌握牒针药理、治疗合法性和医脉罪证。 |
| 关键中间势力 | 百工坞 | 掌握铃阵硬件、机关图和母局改造可能。 |
| 关键中间势力 | 鬼市 | 掌握身份、证词、牒录交易、地下入口和灭证渠道。 |
| 被治理者 | 山水县百姓、边地部族、商路镖盟、牒针宿主 | 检验每种政治方案的真实代价。 |

每个主线任务都要回答一个政治问题，而不只是给玩家战斗、潜入或谈判入口。玩家每救一个人、毁一份证据、偷一把钥匙，都会改变“谁有资格管理武人”的答案。

---

## 6.2 缉武司

**口号：** 武人入册，天下止戈。
**价值：** 秩序、律法、治安、预防暴力。
**阴影：** 监控、先罪化、预防性处决。
**资源：** 官道文书、武籍库、牢城、城防、合法审判权。
**代表人物：** 裴照，沈照微。

缉武司的承诺是：弱者不能永远等强者讲义气，武人必须被公开记录、约束和追责。它的罪责是：一旦“风险”被写进武籍，未犯罪者也会先被当成祸端处理。

内部分裂：

| 路线 | 代表 | 立场 | 失控形态 |
| --- | --- | --- | --- |
| 公开律法 | 裴照 | 所有入册、审判和拘捕都必须可质询、可举证、可翻案。 | 证据链不足时行动迟缓，救不了眼前人。 |
| 预防处置 | 沈照微 | 江湖暴力已经失控，危险武人必须提前约束。 | 把风险当罪，把秩序变成先罪化机器。 |

玩家可以支持缉武司，但不等于支持照影母局；也可以推动裴照路线，使缉武司从“控制武人”转向“公开追责”。

---

## 6.3 同尘盟

**口号：** 江湖事，江湖了。
**价值：** 自由、义气、反抗官府滥权。
**阴影：** 内部混杂，有侠士，也有恶徒、复仇狂和机会主义帮派。
**资源：** 山路、镖局、门派人脉、地下护送、武林盟会话语权。
**代表人物：** 楚横山，陆行舟。

同尘盟的承诺是：官府没有资格把所有武人预先写成犯人，江湖必须保留自治和反抗的空间。它的罪责是：没有公开程序的江湖义气，很容易滑成私刑、报复和帮派割据。

内部分裂：

| 路线 | 代表 | 立场 | 失控形态 |
| --- | --- | --- | --- |
| 江湖自救 | 楚横山 | 护乡、护路、救人，不把所有官府都当仇人。 | 地方主义强，容易包庇“自己人”。 |
| 清算革命 | 陆行舟 | 武籍秩序必须被烧掉，旧账必须一起清。 | 把复仇当正义，把暴动当新秩序。 |

玩家可以把同尘盟推向侠义自治，也可能让它成为照影城第三章暴动和清算的发动机。

---

## 6.4 照影局

**口号：** 照见人心，先断祸端。
**价值：** 预判灾祸，提前止乱。
**阴影：** 剥夺选择，把人当成未来罪犯。
**资源：** 牒针、影纹、照影铃、断因房、母局旧档、各势力中的隐线。
**代表人物：** 白微尘，司命。

照影局不是常规公开投靠路线。第一章它只以外勤、铃阵和灭证出现；第二章它潜伏在失卷、客栈密室、石窟旧史和盟会失控背后；第三章才完整显形，并要求玩家决定是否继承、公开、改造或摧毁母局。

照影局最可怕之处不在于它邪恶，而在于它有一套看似合理的逻辑：

> 律法总在尸体之后才到。
> 江湖总让强者替弱者决定生死。
> 那么，为什么不能提前阻止灾祸？

内部分裂：

| 路线 | 代表 | 立场 | 失控形态 |
| --- | --- | --- | --- |
| 少数牺牲 | 白微尘 | 牺牲可控少数，避免更大灾祸。 | 为了证明自己正确，会制造“必要牺牲”。 |
| 风险账本 | 司命 | 人是一串可能性，未来祸端应被提前剪断。 | 彻底取消选择，把天下写成可清算档案。 |

无名煞是照影局逻辑的人形终点：如果未来灾祸可以被提前计算，那么最有效的答案就是提前杀掉关键节点。

---

## 6.5 慈心医脉

**口号：** 先救眼前人。
**价值：** 医者仁心、救命、赎罪。
**阴影：** 牒针技术最早有医脉参与。
**资源：** 牒针药理、宿主救治、药方罪证、保留医疗功能结局。
**代表人物：** 阮清辞，桑芷。

慈心医脉最初是为了治疗战后疯症，后来技术被照影局与缉武司改造成控制武人的工具。

慈心不是平级政治阵营，而是所有政治路线都必须争取或压制的治疗入口。没有慈心医脉，玩家很难证明“保留治疗、废除控制”的结局可行；慈心若选择隐瞒罪证，则缉武司和照影局都能继续把牒针包装成医术。

---

## 6.6 百工坞

**口号：** 机关无善恶，看谁扣机簧。
**价值：** 工匠、技术、中立、实用主义。
**阴影：** 他们为照影铃阵、母局机关、武籍库暗门提供过硬件。
**资源：** 铃阵硬件、机关图、城市控制节点、母局改造能力。
**代表人物：** 唐叙白，唐小砚。

百工坞不相信“技术有罪”，但他们的中立让很多罪恶变得可执行。

百工不是大政治阵营，而是母局能否被关闭、改造、公开或夺取的硬件钥匙。没有百工支持，玩家仍可硬闯摘星楼，但很难做出低代价改造。

---

## 6.7 鬼市

**口号：** 天下没有不能买的命，只有开不起的价。
**价值：** 信息、伪造、走私、避难。
**阴影：** 人命、牒针、身份、证词都能被交易。
**资源：** 假身份、牒录买卖、地下水道、证人藏匿、灭证服务。
**代表人物：** 鬼市掌柜“阎三更”，队友任无踪。

鬼市是玩家自由度的黑色接口：伪造文书、买卖牒录、偷钥匙、找密道、雇刺客、洗身份。

鬼市不是政治理想，而是所有政治理想都绕不开的地下接口。它可以救被追捕的武人，也可以出售宿主名单；可以让玩家公开真相，也可以让玩家把真相卖给出价最高的人。

| 群体 | 检验的问题 |
| --- | --- |

| 边地部族 | 武籍制度是否会把边地武人长期写成可疑对象。 |

# 7. 可选特殊起源：无名煞

## 7.1 概念

无名煞是 GameW 的特殊起源主角。

你醒来时没有姓名，没有门派，没有旧物。你唯一确定的是：

> 看见某些人时，你会本能地知道怎样最快杀死他。

这不是神明召唤，也不是恶魔低语，而是照影局“断因房”的杀手调校。

断因房培养的不是普通刺客，而是：

> **剧情终止器。**

当某个人被照影局判断为未来祸端时，无名煞就被派去斩断这条因果。

# 10. 第二章详细大纲：《黄沙照影》

第二章不再只是“扩大地图”。它的章节功能是把玩家从个人求生推到政治中心：山水县真相、牒钥、失卷、石窟旧史和宿主名单都足以改变江湖。问题不再是“真相是什么”，而是 **谁有权解释真相**。

## 10.1 第二章地图

| 地点 | 功能 |

| 百工坞 | 铃阵硬件和母局机关来源；决定第三章能否改造而非只摧毁。 |
| 鬼市 | 假身份、牒录买卖、证人藏匿；决定真相能公开、被卖掉或被洗白。 |

## 10.3 第二章主线

### A2-M01：龙门驿聚证

玩家抵达槐安古道上的龙门驿。这里不是普通补给点，而是第一章后果第一次聚集的政治场。

找玩家的人：

* 缉武司西线校尉，要把山水县证据纳入武籍档案；
* 同尘盟信使，要玩家公开山水县真相，作为反武籍旗帜；
* 鬼市掌柜，要购买牒钥、证词或玩家身份；
* 慈心医脉旧人，要确认牒针药方是否泄露；
* 百工坞使者，要回收水闸机关件线索；
* 霍青鸢，要确认牒针是否被用于控制边地部族；
* 一个没有名号的牒使，只负责确认谁接触过玩家。

玩家可以正式入册、假意投靠、暗中联络同尘盟、把证据卖给鬼市、藏起关键证人、独立调查，或用无名煞方式让某条证词永远缺席。

**政治回答：** 玩家第一次决定真相是交给制度、交给江湖、卖给地下，还是保留在自己手里。

---

### A2-M02：黄沙客栈

风沙封路，龙门驿外的黄沙客栈一夜不能出入。客栈里有八组人：

1. 缉武司校尉；
2. 同尘盟信使；
3. 鬼市买家；
4. 携带牒录拓本的书吏；
5. 霍青鸢的族人；
6. 百工坞机关师；
7. 伪装成商人的照影牒使；
8. 一个知道石窟入口的失明画僧。

午夜，书吏暴毙，牒录拓本失踪。表面像密室杀人，真相是照影牒使远程触发牒针，再用机关线制造密室。

玩家可查案、偷拓本、嫁祸、保护画僧、放火脱身、杀掉某方代表、让同尘盟抢走拓本、把拓本卖给鬼市、交给缉武司归档，或用无名煞提前处置“未来会背叛的人”。

**政治回答：** 同一份证据在不同人手里会变成罪证、檄文、商品或死人的遗物。

---

### A2-M03：镜湖失卷

镜湖书院保存着“二十八宿牒录”，记录早期牒针宿主和禁术源流。失卷案不是单纯偷书，而是各方争夺“牒针到底是医术、治安工具，还是预防性处决系统”的定义权。

解法：

* 正常查案，保住书院中立；
* 夜入藏书楼偷卷；
* 和书院辩论，证明缉武司无权封卷；
* 帮鬼市偷卷，再决定是否黑吃黑；
* 让慈心医脉旧人辨认药方来源；
* 柳听弦用音律破解藏书楼错拍机关；
* 奇门角色重排灯阵；
* 无名煞认出自己曾刺杀过上一任藏书人。

**政治回答：** 历史档案由谁保管，谁就能决定这门技术曾经是救人还是杀人。

---

### A2-M04：百工机簧债

百工坞制造过照影铃阵部件，但声称“不知用途”。唐小砚的个人线在这里爆发。

玩家可以：

1. 曝光百工坞，让他们在盟会上承担技术责任；
2. 逼他们修复牒针，换取第三章阵钥；
3. 帮唐小砚夺取工坊话语权；
4. 让缉武司接管百工坞，换合法入城便利；
5. 与百工坞交易，获得第三章城市机关图；
6. 摧毁工坊，导致第三章部分机关路线消失；
7. 隐瞒证据，使百工继续作为所有阵营的军火商。

**政治回答：** 技术中立是否能免罪，取决于工匠是否愿意承担后果。

---

### A2-M05：千佛石窟

千佛石窟表面是商旅祈福之地，深处却藏着照影局前身留下的照壁、铃道、药香窟和无面佛龛。

石窟结构：

| 区域 | 玩法 |
| --- | --- |
| 外窟 | 僧人、商旅、边民、逃亡武人聚集，可社交和交易。 |
| 壁画廊 | 记录前朝武林大案，玩家辨认真假历史。 |
| 回音窟 | 声音误导方向和敌我判断，音律有优势。 |
| 药香窟 | 古香影响牒针宿主，药师可压制或利用。 |
| 砂机关窟 | 流沙、石门、机关佛像，奇门和机括有优势。 |
| 无面佛龛 | 揭示照影局古老源头，无名煞强触发。 |

核心发现：

* 照影局不是缉武司新建的组织；
* 它的前身曾在边塞乱世中记录“未来祸端”；
* 断因房的杀手体系早于大雍；
* 玩家体内的异常牒针和石窟深处的旧照壁有共鸣。

**政治回答：** 如果照影局早于缉武司，那么当前官府只是继承了一个更古老的控制系统，而不是发明了它。

### A2-M06：武林盟会

槐安古道各方召开盟会，讨论是否公开山水县、客栈密室、镜湖失卷和石窟旧史。

参与者：

* 缉武司西线；
* 同尘盟；
* 边军守将；
* 商路镖盟；
* 鬼市；
* 慈心医脉；
* 百工坞；
* 石窟僧人；
* 霍青鸢代表的边地部族。

照影局暗中启动铃阵，让牒针宿主失控，制造“江湖无法自治”和“官府无法监管”的双重证据。

玩家可以：

1. 暴露铃阵，救下盟会；
2. 支持缉武司镇压，但阻止照影局接管；
3. 帮同尘盟夺取话语权，但压住陆行舟的清算路线；
4. 让霍青鸢公开边地证词；
5. 用石窟壁画拓片证明照影局历史；
6. 让鬼市偷换证据，保留自己筹码；
7. 刺杀关键领袖，让真相失去解释者；
8. 无名煞顺煞，杀死一个未来可能引发大战的人。

**政治回答：** 真相公开本身不能自动带来正义，解释真相的人同样危险。

### A2-M07：照影楼坞

第二章终局。

照影楼坞是照影局在槐安古道的外部据点，表面是驿路仓城，地下是牒针校验房、铃阵控制室和牒录档案库。它证明照影局一直寄生在缉武司、医脉、百工和鬼市交易链上。

终局揭示：

* 照影城地下有照影母局；
* 所有牒针最终都会被母局唤醒；
* 玩家体内牒针是异常型号；
* 玩家不只会被控制，也可能反向控制母局；
* 无名煞玩家得知旧编号：**断因七号**。

终局选择：

| 选择 | 第三章影响 |
| --- | --- |
| 救出牒针宿主 | 第三章获得民间证人和起义者，慈心路线增强。 |
| 夺走牒录 | 第三章可威胁缉武司、同尘盟或照影局。 |
| 交给缉武司 | 合法入城，但城市监控更强，同尘盟敌对。 |
| 交给同尘盟 | 叛乱路线增强，照影城提前戒严。 |
| 交给鬼市保管 | 入城路线更隐蔽，但关键证据可被拍卖。 |
| 烧毁楼坞 | 照影局受创，但证据链缺失，第三章大审难度上升。 |
| 秘密接管楼坞 | 玩家获得牒针反制能力，照影局更早显形。 |
| 无名煞继承断因密令 | 断因房旧部主动接触，第三章可走黑令入城。 |

**政治回答：** 玩家决定带着哪一种真相进入照影城：合法档案、江湖檄文、地下筹码、残缺废墟、私有权限，或断因旧令。

# 11. 第三章详细大纲：《司命》

第三章不再是“进城后收钥匙再选结局”。照影城必须像一个会反应的城市：它识别玩家、追踪证据、升级戒严、逼迫队友站队，并把第一、二章的所有债推进武籍大审和母局裁决。

## 11.1 城市压力阶梯

| 阶段 | 城市状态 | 玩家压力 |
| --- | --- | --- |
| 入城识别 | 城门、武籍、旧证人和地下线人同时识别玩家。 | 前两章选择先进城，玩家无法空白开局。 |
| 戒严 / 搜捕 / 地下交易 | 缉武司查验、同尘盟串联、鬼市涨价、照影局灭证。 | 每次公开行动都会改变街区控制权。 |
| 三钥争夺 | 牒钥、阵钥、心钥分散在慈心、百工、武籍库和地下交易中。 | 少钥匙可硬闯，但结局选择减少。 |
| 武籍大审 | 沈照微试图合法化武籍体系，照影局准备借审判显形。 | 玩家必须决定公开证据、扭曲证据或摧毁审判。 |
| 街区暴动或镇压 | 同尘盟、缉武司、鬼市和难民区爆发连锁反应。 | 城市状态决定摘星楼入口和终局盟友。 |
| 摘星楼封锁 | 母局入口关闭，阵营领袖争夺最后权限。 | 队友终局和阵营关系进入不可逆。 |
| 母局裁决 | 司命显形，照影局完整暴露。 | 玩家决定谁有资格书写未来。 |

---

## 11.2 入城方式

玩家进入照影城的方式由前两章决定。

| 入城方式 | 条件 | 后果 |
| --- | --- | --- |
| 缉武司文书 | 支持官方或交出牒录 | 合法入城，但全程被监控，武籍区初始友好。 |
| 鬼市水道 | 任无踪 / 鬼市好感 | 避开审查，但欠鬼市债，证据可被转卖。 |
| 同尘盟密车 | 支持同尘盟 | 进入叛乱据点，但城市戒严更早升级。 |
| 百工坞机关车 | 帮过唐小砚或百工坞 | 可带特殊机关入城，百工坊线提前开启。 |
| 黄沙商队 | 救过商队或霍青鸢 | 外郭边民支持玩家，边地证词更强。 |
| 强攻九门 | 高战斗路线 | 城市初期直接敌对，部分社交线关闭。 |
| 无名煞旧令 | 无名煞身份觉醒 | 断因房旧部开门，但会索要继承承诺。 |

## 11.3 三钥结构

接近照影母局需要三类钥匙。

| 钥匙 | 来源 | 玩法 | 政治含义 |
| --- | --- | --- | --- |
| 牒钥 | 慈心总馆、鬼市、照影刺客 | 医毒、潜入、交易、队友任务。 | 是否能把治疗功能和控制功能分开。 |
| 阵钥 | 百工坊、摘星楼外阵 | 奇门、机括、机关战。 | 是否能改造母局硬件，而不是只毁掉它。 |
| 心钥 | 人证、队友信任、阵营支持 | 社交、审判、阵营声望。 | 是否有人相信玩家有资格裁决母局。 |

玩家不必集齐三钥。少钥匙也能硬闯，但会减少终局选项，增加牺牲。

## 11.4 第三章主线

### A3-M01：入城识别

玩家入城后第一件事不是战斗，而是被城市系统识别。

可能遭遇：

* 缉武司查验武籍；
* 山水县幸存者认出玩家；
* 黄沙商队求玩家帮忙；
* 鬼市派人索债；
* 百工坊暗门识别水闸机关件；
* 慈心总馆认出牒针药性；
* 断因房旧部递来黑令；
* 队友个人线同时触发。

**政治回答：** 玩家不是进了一座新城，而是带着前两章所有债进入总账。

---

### A3-M02：街区升压

照影城分区会根据玩家入城方式和第二章结算进入不同压力状态。

| 区域 | 升压事件 |
| --- | --- |
| 外郭 | 山水县难民、边地部族、商队证人互相争夺发声机会。 |
| 下坊 | 同尘盟串联，帮派索价，普通武人开始藏匿武籍。 |
| 水巷 | 鬼市拍卖牒录、宿主名单和假身份。 |
| 武籍区 | 缉武司查验升级，沈照微推动武籍大审。 |
| 慈心总馆 | 宿主求治，医脉旧罪被迫公开或继续掩盖。 |
| 百工坊 | 城市机关节点被争夺，唐小砚线进入终局。 |

**政治回答：** 城市不是结局菜单，城市本身会把玩家推向公开、镇压、交易或暴动。

---

### A3-M03：三钥争夺

玩家需要决定从哪里下手。

路线：

1. 慈心总馆线：治疗牒针，取得牒钥；
2. 百工坊线：掌握城市机关，取得阵钥；
3. 武籍库线：取得人证和档案，取得心钥；
4. 鬼市线：偷钥匙或买钥匙；
5. 同尘盟线：暴动夺钥匙；
6. 缉武司线：合法调用钥匙；
7. 无名煞线：杀掉钥匙持有人，夺取黑令。

**政治回答：** 钥匙不是道具，而是治疗权、硬件权和信任权。

---

### A3-M04：武籍大审

沈照微召开武籍大审，准备公开审判未入册武人，并把照影母局包装成“防止江湖再乱”的合法工具。

玩家可提交证据：

| 证据 | 来源 | 作用 |
| --- | --- | --- |
| 山水县水闸证词 | 第一章救人 | 证明缉武司隐瞒试验。 |
| 白微尘牒钥 | 第一章追凶 | 指向照影局外勤。 |
| 黄沙客栈密室真相 | 第二章客栈 | 证明照影局可远程灭证。 |
| 镜湖失卷 | 第二章书院 | 证明牒针历史。 |
| 石窟壁画拓片 | 第二章石窟 | 证明照影局早于缉武司。 |
| 百工机关图 | 第二章百工坞 | 证明铃阵硬件来源。 |
| 牒针宿主名单 | 第二章楼坞 | 证明大规模控制。 |
| 慈心医脉药方 | 桑芷线 | 证明医术被滥用。 |

玩家可以在法庭上用证据击败沈照微、支持她合法化武籍、让裴照公开缉武司罪证、让同尘盟袭击大审、让任无踪偷换证据、让柳听弦破除会场铃音、刺杀关键证人，或让照影局启动牒针，证明所有阵营都已被操控。

**政治回答：** 法庭既能公开真相，也能把真相写成新的统治工具。

---

### A3-M05：街区暴动或镇压

武籍大审后，照影城进入不可逆升压。

| 大审结果 | 城市后果 |
| --- | --- |
| 玩家举证成功 | 缉武司内部裂开，裴照路线增强，照影局提前灭证。 |
| 缉武司胜出 | 合法戒严，未入册武人被集中清查。 |
| 同尘盟暴动 | 下坊和外郭起火，陆行舟路线增强。 |
| 证据被偷换 | 鬼市价格暴涨，所有阵营开始买证人。 |
| 关键证人被刺杀 | 真相缺口扩大，无名煞和断因房线增强。 |
| 照影铃启动 | 所有阵营暴露被渗透，照影局从暗线变成明线。 |

**政治回答：** 当公开制度失效，城市会在戒严、暴动和地下交易之间选择。

---

### A3-M06：摘星楼封锁

摘星楼表面是观星、藏书、审武之地，地下是真正的照影母局。武籍大审后，摘星楼封锁，进入方式由城市状态决定：

* 缉武司正规军护送；
* 同尘盟江湖人强攻；
* 鬼市盗贼开水道；
* 百工机关队关闭外阵；
* 慈心医馆救援队护送宿主；
* 槐安边骑冲开外郭；
* 玩家小队独行；
* 无名煞带断因房旧部进入。

**政治回答：** 玩家带谁进入摘星楼，就等于承认谁有资格站在母局前。

---

### A3-M07：地下照影母局

最终副本。

母局不是单一 Boss 房，而是三层选择结构。

#### 第一层：城市选择

谁掌握城市？

* 裴照路线缉武司；
* 沈照微路线缉武司；
* 楚横山路线同尘盟；
* 陆行舟路线同尘盟；
* 鬼市暂时掌握证据流；
* 玩家临时联盟；
* 城市陷入混乱。

#### 第二层：队友选择

每名队友会提出自己的方案：

| 队友 | 方案 |
| --- | --- |
| 桑芷 | 先救宿主，再摧毁控制功能。 |
| 唐小砚 | 改造母局为只读档案库。 |
| 任无踪 | 偷走核心牒钥，让所有势力失控。 |
| 柳听弦 | 用护心曲反制照影铃。 |
| 韩霜铁 | 守住入口，让玩家去做最后决定。 |
| 裴照 | 把母局交给公开律法审判。 |
| 谢停云 | 斩断阵眼，不问代价。 |
| 霍青鸢 | 摧毁边地控制节点，保住族人。 |

#### 第三层：司命选择

司命的最终论点：

> 江湖说自由，可自由常常只是强者杀弱者的借口。
> 官府说律法，可律法总在尸体之后才到。
> 我只是把迟到的审判提前。

玩家最终决定照影母局命运。

**政治回答：** 最终问题不再是谁赢得城市，而是谁有资格把天下武人的过去、现在和未来写进制度。

# 14. 重点任务样例 1：开场《雨夜醒牒》

## 场景

清河渡。雨夜。翻覆囚车。河水浑浊，镖旗被血水浸透。玩家从车厢残骸中醒来，腕脉浮现一道细黑线。

## 剧本片段

**旁白：**
雨声先回来。
然后是铁锈味。
最后是你自己的心跳。
它不太像你的心跳，更像有人隔着一面鼓，在替你数命。

一个受伤的押车兵用刀指着你。

**押车兵：**
别过来。你腕上也有黑线。你也是他们的人？

**玩家选项：**

1. “我不知道这是什么。先止血。”
2. “他们是谁？”
3. “把刀放下，否则你会死得更快。”
4. 【药师】“别动，你中的是散脉粉，不是致命伤。”
5. 【影踪】观察脚印，判断袭击者去向。
6. 【奇门】检查囚车残留符钉。
7. 【无名煞】你忽然知道，只要割开他的喉咙，就没人知道你醒过。

**若选择压制无名煞：**

**旁白：**
那念头来得太熟。
不是愤怒，不是恐惧，甚至不是恶意。
像手知道怎样握筷，舌知道怎样抵住牙。
杀人，对你来说，也许曾经只是一个习惯。

# 15. 重点任务样例 2：第一章终局《龙王庙水闸》

## 任务目标

阻止照影铃阵，处理即将崩坏的水闸，并决定救谁、牺牲谁、追谁。

## 场景结构

| 区域    | 内容                    |
| ----- | --------------------- |
| 庙前戏台  | 敌人伪装香客和戏班，柳听弦可识别错拍鼓点。 |
| 香火偏殿  | 县令密会照影牒使，玩家可偷听或直接揭发。  |
| 水闸机关廊 | 三层路径：梁道、水廊、机关廊。       |
| 阵眼闸室  | 照影铃、水闸、牒针宿主同时失控。      |

## 关键 NPC

* 白微尘：照影局牒使。
* 何其庸：山水县令。
* 楚横山：山神寨主。
* 桑芷：坚持先救牒针宿主。
* 唐小砚：能改机关，但需要玩家拖时间。

## 解决路线

| 路线    | 做法            | 后果            |
| ----- | ------------- | ------------- |
| 侠义救城  | 稳住水闸，停铃，放走白微尘 | 县城存活，线索减少。    |
| 追凶优先  | 追杀白微尘，夺牒钥     | 获得强线索，县城受灾。   |
| 官府合作  | 帮县令掩盖试验       | 获得通行，桑芷可能离队。  |
| 山寨夺闸  | 帮山神寨控制水路      | 江湖路线开启，县衙敌对。  |
| 机关改闸  | 唐小砚分洪         | 代价最小，需要前置。    |
| 医者救针  | 桑芷压制宿主        | 救下大量被牒者，水闸损坏。 |
| 无名煞灭证 | 杀掉所有关键证人      | 隐藏真相，断因房关注玩家。 |

# 16. 重点任务样例 3：第二章主线盒子任务《黄沙客栈》

## 任务定位

第二章的高自由度标志任务，也是“真相解释权”主题的第一场高压演示。它类似大型 CRPG 中的“封闭空间多阵营盒子”：同一份牒录在一夜之内可以变成官府档案、江湖檄文、鬼市商品或照影局必须抹掉的证据。

## 背景

风沙封路，龙门驿外的黄沙客栈一夜不能出入。客栈里有八组人：

1. 缉武司校尉；
2. 同尘盟信使；
3. 鬼市买家；
4. 携带牒录拓本的书吏；
5. 霍青鸢的族人；
6. 百工坞机关师；
7. 伪装成商人的照影牒使；
8. 一个知道石窟入口的失明画僧。

午夜，书吏被杀，牒录拓本失踪。

## 玩家可做

* 查案找真凶；
* 偷走拓本嫁祸他人；
* 保护画僧去石窟；
* 杀掉缉武司校尉；
* 帮缉武司清场；
* 让同尘盟抢走拓本；
* 和鬼市交易；
* 放火制造混乱逃离；
* 用音律识别谁的脚步错拍；
* 用药师判断死者不是被刀杀，而是牒针暴毙；
* 用奇门发现窗栓被机关线牵动；
* 无名煞可顺煞，提前杀掉“未来会背叛的人”。

## 真相

书吏不是被客栈里的人直接杀死，而是照影牒使远程触发他体内牒针，让他暴毙，再用机关线制造密室。

## 结局变量

```text
A2_INN_SCRIBE_SAVED
A2_INN_SCROLL_OBTAINED
A2_INN_MONK_SAVED
A2_INN_FRAMED_FACTION
A2_INN_EXPOSED_TIE_AGENT
A2_INN_DARK_ORIGIN_KILL
```

# 17. 重点任务样例 4：第二章石窟《千佛无面窟》

## 任务定位

替代旧战场，作为照影局古老化的核心揭示副本。

## 开场

玩家跟随失明画僧进入石窟。风沙被挡在窟外，里面只有滴水声、铃声和壁画上的眼睛。

## 剧本片段

**失明画僧：**
我看不见佛。
但我听得见。
这窟里每一尊佛，都在替一个死人闭嘴。

**玩家：**
“死人？”

**失明画僧：**
被救的人，被杀的人，被提前定罪的人。
他们都在墙上。只是后来有人把脸刮掉了。

## 石窟玩法

| 区域   | 玩法             |
| ---- | -------------- |
| 壁画廊  | 玩家从壁画推断前朝旧案真相。 |
| 回音窟  | 错误声音会引导玩家走入伏击。 |
| 药香窟  | 药香触发牒针幻觉。      |
| 砂机关窟 | 流沙与石门形成地形解谜。   |
| 无面佛龛 | 断因房旧史揭示。       |

## 无名煞场景

无名煞玩家触摸无面佛龛时，进入短暂回忆。

**旁白：**
你跪在这里。
不止一次。
有人把一张牒牌放在你面前。
牌上没有名字，只有一句判词：

> 此人若活，三年后血流七里。
> 断。

你听见自己的声音，很年轻，也很平静。

**年轻的你：**
领命。

# 18. 重点任务样例 5：第三章《武籍大审》

## 任务定位

第三章政治高潮，回收第一、二章证据。

皇城外朝边缘的武籍审台。缉武司、门派、商帮、边军、医脉、百工、鬼市、难民、武人都在场。皇城本体只在高墙之后，不直接开放。

## 玩家可提交证据

| 证据      | 来源     | 作用          |
| ------- | ------ | ----------- |
| 山水县水闸证词 | 第一章救人  | 证明缉武司隐瞒试验。  |
| 白微尘牒钥   | 第一章追凶  | 指向照影局外勤。    |
| 黄沙客栈密室真相 | 第二章客栈 | 证明照影局能远程灭证并嫁祸各方。 |
| 镜湖失卷    | 第二章书院  | 证明牒针历史。     |
| 石窟壁画拓片  | 第二章石窟  | 证明照影局早于缉武司。 |
| 百工机关图   | 第二章百工坞 | 证明铃阵硬件来源。   |
| 牒针宿主名单  | 第二章楼坞  | 证明大规模控制。    |
| 慈心医脉药方  | 桑芷线    | 证明医术被滥用。    |

* 让唐小砚关闭审台机关；
* 让同尘盟暴动；
* 刺杀沈照微；

# 19. 最终对峙剧本样例：《司命》

## 场景

地下照影母局。无数铜铃悬在黑暗中，铃下是一枚枚牒牌。每一枚牒牌都刻着一个武人的姓名、门派、救过的人、杀过的人、未来风险。

司命站在阵心，像一个疲惫的账房先生。

**司命：**
你一路走到这里，杀了不少人，也救了不少人。
所以你比任何人都清楚，江湖从来不是干净的。

**玩家：**
“你把人做成账。”

**司命：**
不是我。
他们先把自己活成了账。
一条人命换一场名声。
一场复仇换十年血仇。
一个大侠放过一个恶人，第二天便有十户人家戴孝。
我只是把这些账提前算完。

**玩家选项：**

1. “账可以算，人不能被写死。”
2. “你说得对，但你不该是执笔的人。”
3. “把母局交给我。”
4. “我要毁了它。”
5. “我要公开它，让天下人自己看。”
6. “我要保留治疗功能，废掉控制功能。”
7. 【无名煞】“你不是在等我阻止你。你是在等我继承你。”

**司命看向无名煞玩家：**

**司命：**
断因七号。
你一直是我最好的答案。
他们辩论，他们迟疑，他们被情义拖住手。
只有你知道，世上许多灾祸，本来只需一刀。

# 21. 营地戏样例：无名煞与队友

## 场景

夜营。所有人睡了。玩家醒来，发现自己站在桑芷身边，手中握着一根银针，针尖对准她的颈侧。

**旁白：**
你不记得自己何时起身。
你只知道这一针下去，她不会叫出声。
她知道太多牒针的事。
她活着，会让路变复杂。

桑芷睁开眼。

**桑芷：**
你要杀我？

**玩家选项：**

1. “我不知道我为什么在这里。”
2. “快走，离我远点。”
3. “我不会让它控制我。”
4. “你知道得太多了。”
5. 【药师】把针反刺自己穴位，压住杀意。
6. 【音律】哼起白天柳听弦教你的护心调。
7. 【无名煞：顺煞】杀了她。

后果：

* 压制成功：桑芷信任上升，但开始研究你的杀意来源。
* 失败但未杀：桑芷恐惧，后续治疗线变难。
* 杀死桑芷：慈心医脉主线关闭，但无名煞路线加深。

# 24. 最终版本的核心判断

这版最适合 GameW 的原因是：

1. **结构足够 BG3式。**
   三章推进、体内危机、起源角色、强队友、营地戏、多阵营、多解任务、第三章城市总清算都有。

2. **内容是武侠原创。**
   山水县、水闸、槐安古道、石窟、武籍大审、照影母局、断因房，都服务低魔武侠，不会显得像西幻任务换中文名。

3. **八大流派都有剧情用武之地。**
   游锋适合决斗和破招；破军适合护送和守线；拳掌适合擒拿审案；射艺适合黄沙和城防；影踪适合鬼市和水巷；药师适合牒针和疫病；音律适合照影铃；奇门适合机关、阵法和母局。

4. **槐安古道和石窟增强第二章辨识度。**
