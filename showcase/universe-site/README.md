# GameW 宇宙官网

独立的新官网原型，不复用旧 `showcase/site` 的页面结构。

## 模块

- `首页`：人物设定卡轮播、最新内容、章节精选图。
- `设定`：八大流派、九级构筑、旁修规则和三张队伍镜头。
- `武人`：正式官网人物设定卡，按主修分类。
- `章节`：三章档案与成熟章节图片图库。
- `帮派`：六方主势力与地方势力。
- `故事`：《明档线》官网样章。

## 开发

```bash
npm run build
npm test
npm run serve
```

构建产物输出到 `dist/`。图片源文件仍只维护在仓库根目录的 `assets/`；`dist/assets/media/` 中的预览图和缩略图是可重建产物。
