# GameW 龙王庙水闸 Playable Slice

独立本地演示原型，不依赖现有 `showcase/site` 数据管线。

## Run

```bash
cd showcase/vertical-slice
npm test
npm run serve
```

Then open:

```text
http://127.0.0.1:5175/showcase/vertical-slice/
```

## Scope

- 三选第一章前置成果
- 战前短营地
- 可见 d20 检定
- 四人小队回合战斗
- 停铃、分洪、救宿主、夺牒钥四个并行目标
- 白微尘终局抉择与部分成功结算
