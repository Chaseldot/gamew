# Prompt Patterns

Use these as compact starting points. Keep one prompt per distinct asset.

## Location Concept

```text
Use case: stylized-concept
Asset type: GameW chapter <N> location concept art, final project asset
Primary request: Generate a clean 3840x2160 4K landscape concept art image for the map location "<地点>" in "<大区>".
Scene/backdrop: <one sentence from ground truth plus mined script motifs: architecture, weather, props, conflict residue>.
Style/medium: high quality AAA wuxia CRPG environment concept art, painterly realism, matching the chapter key visual: <palette, light, atmosphere>.
Composition/framing: wide exterior establishing shot, 16:9 cinematic landscape, the location readable as a map point, not an interior room or battle scene.
Lighting/mood: <chapter mood and emotional tension>.
Strict constraints: no text, no letters, no readable signage, no labels, no UI, no watermark, no logo, no signature, no close-up characters; only tiny scale figures if needed.
```

## Scene Image

```text
Use case: stylized-concept
Asset type: GameW chapter <N> representative scene art
Primary request: Generate a clean 3840x2160 4K landscape image for "<场景名>" inside/near "<地点>".
Scene/backdrop: <script-grounded interior/exterior scene with specific props and spatial relation>.
Style/medium: high quality wuxia CRPG scene concept art, matching <chapter/location reference>.
Composition/framing: cinematic playable-space view, clear foreground/midground/background, no UI.
Lighting/mood: <scene-specific mood>.
Strict constraints: no text, no readable signage, no watermark, no logo.
```

## Battle Image

```text
Use case: stylized-concept
Asset type: GameW chapter <N> battle concept art
Primary request: Generate a clean 3840x2160 4K landscape battle setup image for "<战斗名>" at "<地点>".
Scene/backdrop: <terrain, cover, choke points, hazards, faction visual identity>.
Style/medium: high quality wuxia CRPG encounter concept art, grounded and tactical, matching <chapter reference>.
Composition/framing: readable combat arena layout from a cinematic oblique angle; no UI, no damage numbers.
Lighting/mood: <combat tension>.
Strict constraints: no gore focus, no text, no labels, no watermark, no logo.
```
