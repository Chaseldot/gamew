# GameW 人物设计

## 用途

使用本 skill，把松散的武侠输入转成可复用的 GameW 武侠人物原型表条目。

默认数据目标：`character-production/wuxia-character-archetypes.md`。

主职责是人物生产：把参考人物、器物、战斗幻想、场景片段或 NPC 需求，转成稳定的人物原型，并确保它符合 GameW 的低魔武侠 CRPG 调性和当前构筑系统 ground truth。维护、查重和审计是辅助模式。


## 必读 Ground Truth

设计或实质修订条目前，先读：

- `00-game-introduction.md`：确认调性、低魔边界、CRPG 体验和人物幻想目标。
- `canon/01-build-system-milestone.md`：确认当前八流派、构筑规则、旁修限制。

不要自动依赖 `history/`；只有用户明确要求历史上下文时才读取。

不要为了学习 schema 而读取整张幻想库。使用定向读取和下面的 references。

## 工作流程

1. 读取 `00-game-introduction.md` 和 `canon/01-build-system-milestone.md`。
2. 判断输入类型：参考人物、战斗循环、武器 / 器物、低魔媒介、场景片段、NPC 需求或混合想法。
3. 提炼稳定武侠原型：这个人是谁，怎么打，记忆点是什么。
4. 拒绝或改写只属于职业、门派、身份等级、剧情背景、单个招式或一次性场景的输入。
5. 用当前八流派+旁修规则归类构筑，注意八大流派代表八种战斗能力，不要被其名称影响构筑合理性，如太极宗师涉及控制+机制上的反制能力，对应“拳掌”+“游锋”，同理如涉及投掷等远程能力要旁修射艺、涉及群体buff能力要旁修音律。
6. 按需求输出七列表格行、before/after 修订、简短字段 diff 或审计报告。
7. 修改表格前，必须做定向查重和 ID 检查；除非用户要求全表处理，否则只更新相关行。

## 输出契约及优秀例子

新增或修订条目时，严格输出当前七列表格格式：

```markdown
| ID | 人物原型 | 构筑 | 定位 | 关键爽点 | 经典场景 | 参考人物 |
|---|---|---|---|---|---|---|
| F-041 | 毒医圣手 | 9药师 | 医毒双修战场支援 | 同一回合在救人与下毒间取舍，用药性逼敌付出行动代价 | 荒村疫夜，医者一针稳住同伴，又让追兵药性发作 | 程灵素；胡青牛；王难姑 |
| F-033 | 飞刀浪子 | 6射艺+2影踪+1游锋 | 远程单体爆发 | 等到唯一窗口才出手，一刀命中后直接挪转身位 | 夜雨客栈，浪子倚柱饮酒，袖中飞刀忽然定住生死线 | 李寻欢 |
| F-073 | 驭鹰游侠 | 6射艺+3奇门 | 兽伴侦察射手 | 鹰影标出逃路和高点视野，本体据此补射或逼停移动目标 | 绝壁风口，鹰盘旋三圈，游侠抬弓封住山道出口 | - |
| F-057 | 符禁道人 | 9奇门 | 区域封锁控场 | 贴符划线短时封步、封门或封兵器，把敌人逼停在禁线外 | 山道石门前，道士一符拍下，追兵脚步硬生生止在线前 | - |
| F-046 | 药傀毒师 | 6药师+2奇门+1破军 | 召物控场支援 | 让药傀占住通道并携毒前压，作为肉盾压住阵线 | 药傀迈入巷口封住退路，腹中药炉一热，追兵不得不分散换气 | - |
| F-002 | 太极宗师 | 7拳掌+2游锋 | 控制反制位 | 用圆转卸掉强攻，让敌人的前冲变成失衡破绽 | 老道袖袍一圈，引来拳掌都落空，反让来敌自失重心 | 张三丰；张君宝 |
```

修订条目时，展示 before/after 行或简短字段 diff。审计时，按保留、修订、合并 / 归档、构筑归类风险分组报告。

## 边界

- 不把门派、身份、社会地位、出身或势力变成系统根节点。
- 不声称幻想表证明某个子系统已经成立；它是测试资源和生产资源。
- 如果当前 canon 无法支撑某个幻想，写 `待定` 并说明缺少什么支持，不要发明新子系统。
