# 流派归类

归类时看人物原型真正解决的战斗问题，而不是旧标签、名气、阵营或表面装束。

## 主修流派

| 流派 | 什么时候作为主修 |
|---|---|
| 游锋 | 近身兵刃、读招、决斗、近战机动、反应式兵器交锋。 |
| 破军 | 守线、冲阵、护卫、重压、阵型、前排承压。 |
| 拳掌 | 身体控制、擒拿、拳掌、贴身无兵控制、身体破绽干扰。 |
| 射艺 | 远程、投射 / 射击武器、射线、标记、追击、距离控制。 |
| 影踪 | 潜行、视线、刺杀、伏击、脱战、隐蔽移动。 |
| 药师 | 医术、毒、伤病、疫症、急救、消耗战、生死取舍。 |
| 音律 | 节奏、士气、恐惧、意志、拍点、乐器、呼喝、情绪 / 心理压力。 |
| 奇门 | 地形、阵法、机关、符禁、陷阱、傀儡、民俗术、局部规则改变。 |

优先选择一个清楚的主修流派。主修必须承载该条目的身份和主要战斗循环。

## 旁修规则

- 只有幻想成立必须依赖第二能力时，才加入旁修。
- 使用 `+1流派`、`+2流派` 或 `+3流派`。
- 当前 milestone 下最多加入两个旁修流派。
- 旁修只是低阶接入，不能获得第二套完整主身份。
- 宁可一个主轴清楚，也不要堆混合感。

示例：

| 构筑 | 读法 |
|---|---|
| `游锋` | 纯主修。 |
| `影踪+2游锋` | 潜行身份为主，获得足够兵器能力支撑贴身处决。 |
| `奇门+2音律+1药师` | 地形 / 改局为主，音律和药性只是支撑媒介。 |

## 低魔边界

低魔幻想可以奇异，但必须有可见媒介、代价、时机和反制。

| 媒介 | 必须保持具体 |
|---|---|
| 药毒 | 草药、毒物、诊断、暴露方式、解毒窗口、伤病取舍。 |
| 音律 | 乐器、呼喝、节奏、士气、恐惧、拍点、可打断性。 |
| 奇门 | 地形、机关、符纸、陷阱、傀儡、布置过程、局部限制。 |
| 傀儡 / 兽 / 民俗术 | 身体、控制方式、维护成本、可见性、破坏或绕开的方式。 |

不要把这些效果写成自由法术、神术、召唤职业身份或万能解题器。

## 什么时候写 `待定`

以下情况写 `待定`，不要硬凑构筑：

- 幻想需要 canon 明确暂不处理的子系统；
- 当前没有任何流派能承载该战斗问题，除非发明新系统根节点。

写 `待定` 时，用一句话说明缺少什么支持；如果可以，给出最接近的改写方向。

## 传承边界

当前传承仍为 WIP。不要把条目写成 `流派:传承`，不要要求某个传承名成立，也不要用 WIP 传承证明人物原型可行。
