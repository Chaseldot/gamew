# Schema 与条目规则

## 当前表格

当前表格固定为七列：

```markdown
| ID | 形象 | 构筑 | 定位 | 关键爽点 | 经典场景 | 参考人物 |
|---|---|---|---|---|---|---|
```

默认目标：`character-production/wuxia-fantasy-suite.md`。

## 字段规则

| 字段 | 规则 |
|---|---|
| ID | 使用 `F-001` 格式。不要复用已删除或已归档 ID。新增前必须定向检查现有 ID。 |
| 人物原型 | 短、具体、有武侠味的人物原型名。必须可复用，不能只是一次性场景、身份等级、门派、职业或著名人物换名。 |
| 构筑 | 以当前 ground truth 为准。传承仍为 WIP 时，写作 `主修流派+N旁修流派+N旁修流派`，不要写 `流派:传承`。 |
| 定位 | CRPG 可读的战斗 / 队伍职责，例如 `前排击退控制`、`远程单体爆发`、`战场急救支援`、`区域封锁控场`。 |
| 关键爽点 | 玩家在战斗中想感受到的动作、节奏、取舍、压迫或反制。不要写纯剧情爽点。 |
| 经典场景 | 一个能展示该原型行动方式的代表性武侠瞬间。保持具体、可视化。 |
| 参考人物 | 经典参考人物用中文分号分隔。没有明确参考时使用 `-`。 |

## 定向读取

除非用户要求全表审计，否则不要读取整张幻想库。

常用命令：

```bash
rg -n "形象名|参考人物" character-production/wuxia-fantasy-suite.md
rg -o "F-[0-9]{3}" character-production/wuxia-fantasy-suite.md
rg -n "F-046|药傀毒师" character-production/wuxia-fantasy-suite.md
sed -n '1,25p' character-production/wuxia-fantasy-suite.md
```

只有在编辑相邻行、比较局部质量或排序时，才读取更大的片段。

## 输出模式

新增或修订行：

```markdown
| ID | 人物原型 | 构筑 | 定位 | 关键爽点 | 经典场景 | 参考人物 |
|---|---|---|---|---|---|---|
| F-099 | 斗转借力客 | 拳掌+2游锋+1奇门 | 借力反制前排 | 把敌方强招导偏或反掷回去，靠借力让高威胁目标暴露空门 | 公子侧身引过重掌，借势一带，强攻者反被自己的力道逼退 | 慕容复 |
```

修订：

- 多字段改动时展示 before/after 行；
- 一两个字段改动时展示简短字段 diff；
- 除非用户明确要求归档或拆分，否则保留原 ID。

表格编辑：

- 先查重形象名和参考人物；
- 再检查现有 ID；
- 除非用户要求更大范围处理，否则只更新相关行。
