# Wuxia Fantasy Suite

## 用途

当用户需要处理“武侠幻想”时使用本 skill：

- 从天马行空的想法、意象、场景或人设碎片中提炼武侠幻想；
- 判断一个幻想是否适合进入幻想测试集；
- 新增、查看、修改、归档幻想测试集条目；
- 从金庸、古龙、梁羽生、温瑞安、黄易等经典武侠小说，以及经典影视 / 武侠游戏中提炼可复用形象；
- 收录低魔奇术、符禁、傀儡、兽伴、蛊虫、纸人、机关兽等幻想，作为未来系统压力测试；
- 为构筑系统、NPC、队友、敌人、支线人物等复用幻想资源。

本 skill 不设计流派、传承、技能、数值、loadout 或经脉槽。

收录低魔奇术或独立召物幻想时，只写形象、参考人物、战斗爽点和经典场景；不要擅自定义行动经济、召物属性、回合规则或完整 companion / minion / puppet 系统。

默认维护仓库内 active 库：`character-production/wuxia-fantasy-suite.md`。

## 定义

**武侠幻想** 是有武侠味、可被玩家一眼理解、能反复复用的固定形象与人设。

它应回答：

- 这个人是谁；
- 参考了哪些经典人物；
- 他的江湖气质是什么；
- 玩家在战斗中想体验什么；
- 战斗或剧情中最有代表性的一幕是什么。

好幻想例子：

- 毒医圣手；
- 驭鹰孤侠；
- 飞刀浪子；
- 机关奇人；
- 游侠；
- 武僧；
- 玉箫行客。

形象命名风格：

- 像幻想库旧版那样短、具体、有武侠味；
- 优先写成可复用构筑测试名，例如“快剑游侠”“独臂剑侠”“飞刀浪子”“毒医圣手”；
- 避免宽泛主题名，例如“侠之大者”“魔师”“正义之侠”；
- 避免直接把参考人物名或人物称号当作形象，除非该称号本身已经是可复用武侠 archetype。

低魔与召物边界：

- 可以收录“符禁道人”“符爆术士”“牵丝傀儡师”“驭鹰游侠”“纸人符兵师”等幻想；
- 低魔表达优先落在符纸、朱砂、火药、香雾、机簧、蛊虫、纸人、傀儡、兽伴、民俗仪式等可见媒介；
- 关键爽点要写清楚战斗中的封步、逼位、打断、诱导、承压、夹线、侦查或牵制；
- 独立召物可以作为幻想库压力输入，但在系统未实现前不要声称当前构筑已经支持独立移动、占格、承伤、夹击或共享行动经济。

不合格原始输入例子：

- 巷尾短兵恶斗：这是场景，不是固定人设；
- 酒楼掀桌侠：这是一次动作或笑点，不是可复用幻想；
- 老镖师护车：太职业 / 场景化，需要提炼成更固定的人设，例如“铁肩镖客”。

## 幻想索引表

索引表只使用三列，且 `参考人物` 必须紧跟在 `形象` 后面：

| ID | 形象 | 参考人物 |
|---|---|---|
| F-001 | 毒医圣手 | 程灵素；胡青牛 |

ID 规则：

- 使用 `F-001`、`F-002`、`F-003` 递增；
- 默认不复用已归档或删除过的 ID；
- 如果用户明确要求“清空 / 重建幻想库”，可以重置 ID，并在库文件中记录这次重建；
- 如果用户已有编号体系，沿用用户体系。

参考人物规则：

- 优先写最能支撑该形象的经典人物；
- 可写多个参考人物，用中文分号分隔；
- 如果实在没有明确参考人物，写 `-`；
- 参考人物是提炼依据，不等于直接照搬人物或剧情。

## 幻想卡字段

每个幻想卡只使用以下字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| ID | 唯一编号 | F-001 |
| 形象 | 有武侠味的固定形象 / 人设 | 毒医圣手 |
| 参考人物 | 经典人物依据；没有则写 `-` | 程灵素；胡青牛 |
| 构筑 | 固定格式：`流派:传承+辅修`；未定时写 `待定` | `药师:蛊毒+2影踪+1音律` |
| 定位 | 战斗或队伍中的直观位置 | 医毒控制位 |
| 关键爽点 | 玩家在战斗中最想体验到的动作、节奏、取舍或压迫感 | 同一回合在救人与下毒间取舍，用药性逼敌付出行动代价 |
| 经典场景 | 最能代表这个幻想的一幕 | 荒村疫夜，白衣人以针封毒，反救中毒队友 |

构筑格式：

```text
主修流派:传承+N辅修流派+N辅修流派
```

示例：

```text
药师:蛊毒+2影踪+1音律
射艺:穿杨+2影踪+1游锋
音律:清音+2游锋+1药师
```

若构筑暂未确定，可写 `待定`，但进入正式构筑回归测试前应补齐。

## 质量判断

收到一个想法后，先判断它属于哪类：

| 类型 | 处理 |
|---|---|
| 合格幻想 | 可直接生成幻想卡。 |
| 场景碎片 | 提炼成固定人设后再入库。 |
| 动作笑点 | 通常不入库，除非能提炼成人设。 |
| 职业 / 身份 | 去掉职业绑定，提炼为构筑可表达的人设。 |
| 机制方案 | 不作为幻想入库，可转写为“关键爽点”。 |
| 重复幻想 | 建议合并或修改已有幻想。 |

判断标准：

- 形象有武侠味；
- 不是一次性事件；
- 不是纯职业名；
- 有清楚的人设和爽点；
- 关键爽点必须能落到战斗中的动作、节奏、取舍或压迫感；
- 低魔 / 召物幻想必须有可见媒介和反制方式，不能滑成无代价法术；
- 有明确参考人物，或能说明为什么参考人物为 `-`；
- 可以用构筑字段表达；
- 可被 NPC / 敌人 / 队友 / 构筑测试复用。

## 整理与合并

当用户要求整理、归纳、合并同类项或控制比例时：

- 不要先替用户做固定类型分桶，也不要输出硬性类型配额；
- 选择优先级：合理性第一，经典代表性第二，CRPG 战斗表现性第三；
- 合并同一战斗循环、同一武器爽点或同一低魔媒介的重复条目；
- 代表人物合并到 `参考人物`，不要为每个经典人物单独保留一条；
- 不为比例平均保留弱形象，也不为补齐类型而新增空泛形象；
- 比例只做事后审计，用来发现明显偏科，不作为入库配额；
- 保留有代表性的低魔 / 符禁 / 傀儡 / 兽伴压力测试，但前提是能提供清楚的 CRPG 战斗表现；
- 如果重排 ID，必须在库文件中说明这是整理后的 active 编号。

## CRUD

### Create：新增

从用户输入中提炼幻想卡，并加入索引表。

输出格式：

```markdown
## 新增幻想

| 字段 | 内容 |
|---|---|
| ID | F-008 |
| 形象 | 飞刀浪子 |
| 参考人物 | 李寻欢 |
| 构筑 | `射艺:穿杨+2影踪+1游锋` |
| 定位 | 远程点杀位 |
| 关键爽点 | 等到唯一窗口才出手，一刀命中后直接改写敌方行动线 |
| 经典场景 | 夜雨客栈，浪子倚柱饮酒，抬手一镖钉住欲逃之人 |

## 索引更新

| ID | 形象 | 参考人物 |
|---|---|---|
| F-008 | 飞刀浪子 | 李寻欢 |
```

如果输入不合格，先输出“提炼建议”，不要直接入库。

### Read：查看

支持：

- 查看全部索引；
- 按 ID 查看幻想卡；
- 按形象模糊查找幻想卡；
- 按参考人物查找幻想卡。

索引输出只使用：

| ID | 形象 | 参考人物 |
|---|---|---|

查看单卡时输出完整幻想卡字段。

### Update：修改

可修改：

- 形象；
- 参考人物；
- 构筑；
- 定位；
- 关键爽点；
- 经典场景。

输出修改前后对照：

| 字段 | 修改前 | 修改后 |
|---|---|---|

如果用户只是表达不满或方向感，先给修改建议；除非用户明确确认，否则不要声称已落库。

### Delete：归档

默认不硬删，改为归档。只有用户明确要求清空 / 重建库时，才整体替换 active 库。

归档输出：

| ID | 形象 | 参考人物 | 操作 | 原因 |
|---|---|---|---|---|
| F-006 | 护寺武僧 | - | 归档 | 与武僧重复 |

归档后：

- ID 不复用；
- 报告或历史引用仍可追溯；
- 用户可要求恢复。

## 输出原则

- 表格优先；
- 保留用户原意，但要提炼成固定人设；
- 不把场景、动作、职业、机制误当幻想；
- 不擅自设计数值或技能；
- 不把构筑字段扩展成完整系统设计；
- 可以用幻想库记录未来 companion / minion / puppet 压力测试，但要明确这不是当前系统实现声明；
- 参考人物用于校准经典感，不替代原创形象；
- 遇到多个可能形象时，给出推荐名和 1-2 个备选名。
